# 笔刷显现 `brush_reveal`

使用多道互相重叠、带刷毛缺口和粗糙前沿的笔刷覆盖，将起始图片连续过渡到目标图片。对应现有特效 `fx.draw.brushReveal`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "brush_reveal",
  "data": {
    "size": 0.12,
    "roughness": 0.35,
    "progress": 1
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `size` | 是 | 数字 `0.005..1`，步长 `0.005`，相对画布 | 越大笔刷覆盖越宽 |
| `roughness` | 是 | 数字 `0..1`，步长 `0.01` | 越大边缘越破碎、手工感越强 |
| `progress` | 是 | 数字 `0..1`，步长 `0.01`，默认 `1` | 整段视频结束时的目标覆盖率；`0` 未显现，`1` 完全显现 |

## 参数选择规则

- “细笔刷、窄刷痕”降低 `size`；“大刷子、宽幅涂抹”提高 `size`。
- “干净、平滑边缘”降低 `roughness`；“干刷、毛糙、破边”提高它。
- 用户给出“最终只显现 N%”时，将百分比除以 `100` 映射到 `progress`；普通的笔刷转场必须使用 `progress=1`。
- 宽度由 `size` 优先控制，边缘质感由 `roughness` 控制；不要用高粗糙度代替大尺寸。
- 未明确强度时采用默认笔刷尺寸和粗糙度，并保持 `progress=1`，让转场结束时完整显示目标图片。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 用细而干净的笔刷显现三成 | `{"size":0.04,"roughness":0.1,"progress":0.3}` |
| 大刷子粗糙地刷到一半 | `{"size":0.3,"roughness":0.7,"progress":0.5}` |
| 宽幅平滑刷过，完成八成 | `{"size":0.45,"roughness":0.08,"progress":0.8}` |
| 很细的干刷，只露出开头 | `{"size":0.02,"roughness":0.85,"progress":0.1}` |
| 默认笔触，从第一张图完整刷到第二张图 | `{"size":0.12,"roughness":0.35,"progress":1}` |

## 推荐档位

| 表达 | `size` | `roughness` | `progress` |
| --- | ---: | ---: | ---: |
| 细/平滑/初段 | `0.04` | `0.1` | `0.2` |
| 中等/自然/半程 | `0.12` | `0.35` | `0.5` |
| 宽/粗糙/近完成 | `0.35` | `0.75` | `0.9` |

默认值为 `size=0.12`、`roughness=0.35`、`progress=1`。`roughness=0` 是最平滑边缘，`progress=0` 与 `1` 是结束时未显现和完全显现；`size=1`、`roughness=1` 是最大支持边界，通常只用于明确的超宽或极粗糙效果。

笔刷会从画面顶部开始逐道往返横向扫过，第二张图片只在笔刷实际经过的位置覆盖第一张图片。活动刷头及刚刷过的区域保留刷毛分叉、干刷缺口、纤维条纹和不规则边缘；较早刷过的区域再逐渐沉降填实，因此能持续看见“刷过”的过程而不会突然整带切换。视频第一帧只显示起始图片；默认 `progress=1` 时最后一帧完整显示目标图片。

服务端绑定的真实笔刷覆盖由服务器派生，不生成 `brushTexture`、纹理、资源 ID、路径或 URL。本工具不创建新笔刷素材，也不用于手写笔压、墨水扩散或粉笔颗粒。

## 服务器输入槽（不进入模型 `data`）

- `source_frame`（必需，`image`，单个）：用户上传的起始图片，前端显示为“起始图片”。
- `target_frame`（必需，`image`，单个）：用户上传的目标图片，前端显示为“目标图片”。
- `brush_texture`（必需，`texture`，单个）：服务器为本次请求派生确定性的刷毛覆盖，不要求用户上传笔刷素材。

两张图片的身份按前端素材位和换位结果绑定，不进入模型 `data`，模型不得输出资源字段或根据文件名臆测素材身份。
