# 体积光束 `volumetric_ray`

对服务端授权的遮挡蒙版执行径向散射采样，在线性色彩空间生成可含 HDR 值的体积光。只输出 JSON，不要附加解释、Markdown 或代码块：

```json
{"type":"volumetric_ray","data":{"density":0.65,"sampleCount":48,"decay":0.96,"exposure":0.8,"weight":0.18,"lightX":0.5,"lightY":0.2,"color":"#FFE9B0","flowSpeed":0.35,"beamWidth":0.55}}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `density` | 否 | `0..1.5`，默认 `0.65` | 沿光源方向的采样跨度 |
| `sampleCount` | 否 | 整数 `8..128`，默认 `48` | 质量与成本；最终输出可提高 |
| `decay` | 否 | `0.8..1`，默认 `0.96` | 光沿射线保留率，越接近 1 尾部越长 |
| `exposure` | 否 | `0..5`，默认 `0.8` | 最终线性光曝光强度 |
| `weight` | 否 | `0..1`，默认 `0.18` | 每个采样点贡献量 |
| `lightX` | 否 | `-0.5..1.5`，默认 `0.5` | 光源归一化横坐标，可在画外 |
| `lightY` | 否 | `-0.5..1.5`，默认 `0.2` | 光源归一化纵坐标，可在画外 |
| `color` | 否 | `#RRGGBB`，默认 `#FFE9B0` | 光束颜色，严格使用用户指定颜色 |
| `flowSpeed` | 否 | `-5..5`，默认 `0.35` | 光束内部尘埃流动速度，正负控制方向，`0` 静止 |
| `beamWidth` | 否 | `0.05..1.5`，默认 `0.55` | 光束宽度；越小越窄且更集中 |

## 参数选择规则

1. 先定位 `lightX/lightY`，再用 `density` 和 `decay` 决定光束长度。
2. 亮度主要调整 `exposure`；`weight` 用于每步能量，避免两者同时大幅提高。
3. 预览优先 `sampleCount=24..48`，高质量输出用 `64..128`，采样数不代表效果强度。

| 自然语言 | 参数对应 |
| --- | --- |
| 光从画面正上方中间照下 | `lightX=0.5, lightY=-0.1` |
| 左上角柔和窗光 | `lightX=0.15, lightY=0.05, density=0.4, exposure=0.55` |
| 射线更长但逐渐衰减 | `density=1, decay=0.97` |
| 强烈舞台光柱 | `exposure=1.5, weight=0.25, density=0.85` |
| 快速低采样预览 | `sampleCount=24` |
| 高质量细腻天光 | `sampleCount=96, decay=0.985, exposure=1.1` |

| 程度 | `exposure` | `density` |
| --- | ---: | ---: |
| 轻微 | `0.3` | `0.3` |
| 中等 | `0.8` | `0.65` |
| 明显 | `1.5` | `0.95` |
| 强烈 | `2.8` | `1.3` |

默认值为示例中的完整 `data`。关闭效果的中性值是 `exposure=0` 或 `weight=0`；光源居中为 `lightX=0.5, lightY=0.5`。随请求提供的授权图片仅用于定位光源坐标，且必须作为清晰可见的底图保留；光束不能替换或盖住原图。不适用于三维真实雾体、镜头光晕或无蒙版泛光。

## 服务器输入槽

- `source_image`：必需的授权背景图片，始终保留在光束下方。
- `occlusion_mask`：服务器从同一授权图片派生的遮挡亮度蒙版，不由前端上传，也不进入模型参数。
