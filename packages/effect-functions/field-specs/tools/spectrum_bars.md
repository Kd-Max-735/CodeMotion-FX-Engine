# 频谱柱 `spectrum_bars`

## 1. 工具作用

把服务端已授权并归一化的频域分析 bins 聚合成频谱柱。可选择线性或近似对数频段，并与上一分析帧混合平滑；模型不接触音频文件。

## 2. 输出要求

模型只输出 `type/data` JSON，`type` 必须为 `spectrum_bars`。`data` 只能是视觉参数，绝不能包含音频、分析数据、资源 ID、文件路径或 URL。

## 3. 合法 JSON 示例

```json
{"type":"spectrum_bars","data":{"barCount":48,"gain":1,"smoothing":0.55,"falloff":1.1,"logarithmic":true,"barColor":"#00F5D4","backgroundColor":"#001219"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `barCount` | 整数 | 8–128 | 48 | 柱数和横向密度 |
| `gain` | 数值 | 0.1–4 | 1 | 整体响应增益 |
| `smoothing` | 数值 | 0–0.95 | 0.55 | 越高越稳定，越低越灵敏 |
| `falloff` | 数值 | 0.25–4 | 1.1 | 响应曲线；高值压低弱信号 |
| `logarithmic` | 布尔 | `true` / `false` | `true` | 对数聚合突出低频分布，线性聚合保持均匀 bins |
| `barColor` | `#RRGGBB` | 六位十六进制 | `#00F5D4` | 柱体颜色 |
| `backgroundColor` | `#RRGGBB` | 六位十六进制 | `#001219` | 背景颜色 |

用户必须上传一份音频，服务端将其绑定到 `audio_analysis` 输入槽（`kind: audio`），解码真实 PCM 并逐帧计算频谱。绑定是 owner-scoped、已锁定的精确 `audio-analysis-v1` 对象。该槽不属于模型参数；没有真实授权音频时直接拒绝，不生成替代频谱。

## 5. 表达映射

“更多/更密的柱”提高 `barCount`；“更跳动/更敏感”提高 `gain` 并降低 `smoothing`；“更平稳”提高 `smoothing`；“突出强峰”提高 `falloff`；颜色只用直接色值。用户说“平滑度高”时优先调整 `smoothing`。

## 6. 自然语言例子

- “做 64 根响应灵敏的俱乐部频谱柱” → 高柱数、较高增益、低平滑度。
- “柔和稳定的监听频谱” → 高 `smoothing`、中低 `gain`。
- “突出低频区域” → `logarithmic` 为 `true`。
- “保持频段均匀分布” → `logarithmic` 为 `false`。
- “只让强信号明显” → 提高 `falloff`。
- “青色柱配深色背景” → 设置两个直接颜色值。

## 7. 推荐档位

| 档位 | `barCount` | `gain` | `smoothing` | `falloff` |
| --- | ---: | ---: | ---: | ---: |
| 平稳 | 16–40 | 0.5–1 | 0.7–0.9 | 1–1.8 |
| 均衡 | 40–72 | 0.8–1.5 | 0.4–0.7 | 0.8–1.3 |
| 灵敏 | 64–128 | 1.3–3 | 0–0.4 | 0.4–1 |

## 8. 默认值与中性行为

默认值使用 48 根柱、中性增益、适度平滑和对数频段，能稳定呈现常见音乐频谱而不过度抖动。

## 9. 不能处理的内容

模型不能接收或定位音频文件，不能输出 `audio_analysis` 数据、资源 ID、路径或 URL；用户上传的音频只由服务器授权、解码和分析。不能替代波形工具，也不能调用其他效果。
