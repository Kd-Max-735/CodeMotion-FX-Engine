# 旋转进入 `rotate_in`

让服务端绑定的画面围绕指定支点旋转进入，并可附带运动模糊与额外整圈旋转。对应现有特效 `fx.motion.rotateIn`。

需要调用时只输出以下 JSON，不要附加解释或代码块：

```json
{
  "type": "rotate_in",
  "data": {
    "angle": -90,
    "pivot": [0.5, 0.5],
    "blur": 0.08,
    "turns": 2,
    "duration": 1.2
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `angle` | 是 | 数字 `-720..720` 度，步长 `1`，默认 `-90` | 起始角度；负值与正值产生相反旋向 |
| `pivot` | 是 | 两元素数组 `[x,y]`，每项 `0..1`、步长 `0.01`，默认 `[0.5,0.5]` | 旋转支点；用户提到角落或边缘时调整 |
| `blur` | 是 | 数字 `0..1`，步长 `0.01`，默认 `0.08` | 旋转初期的附加模糊感；清晰利落时设 `0` |
| `turns` | 是 | 数字 `-4..4` 圈，步长 `0.25`，默认 `2` | 完整圈数；符号影响旋向。未指定圈数时保留默认多圈旋转 |
| `duration` | 是 | 数字 `0.05..60` 秒，步长 `0.05`，默认 `1.2` | 整个旋转进入的持续时间；只改变速度，不减少圈数 |

## 参数选择优先级

实际起始旋转量为 `angle + turns×360`。`duration` 决定完成这段总旋转量所需的时间：时间越长旋转越慢，时间越短旋转越快，不能通过减少圈数表达慢速。未提及圈数时使用默认 `turns=2`，保证至少完成多圈旋转。

旋转速度由 `duration` 控制：旋转在指定时间内完成，不要通过减少总旋转量表达慢速。不要用 `blur` 表达速度；它只改变拖影感。只有用户明确要求“只转指定角度”时才将 `turns` 设为 `0`。

| 用户提示词 | 应输出的 `data` 参数 |
| --- | --- |
| 逆时针转 90 度进入 | `angle=-90, pivot=[0.5,0.5], blur=0.08, turns=0` |
| 顺时针半圈进入 | `angle=180, pivot=[0.5,0.5], blur=0.08, turns=0` |
| 从左下角旋入 | `angle=-90, pivot=[0,1], blur=0.06, turns=0` |
| 清晰地转两圈进入 | `angle=0, pivot=[0.5,0.5], blur=0, turns=2` |
| 强烈旋转并带明显拖影感 | `angle=-180, pivot=[0.5,0.5], blur=0.35, turns=-1` |
| 慢速逆时针旋转 3 秒进入 | `angle=0, pivot=[0.5,0.5], blur=0.04, turns=-2, duration=3` |
| 快速顺时针旋转 0.6 秒进入 | `angle=0, pivot=[0.5,0.5], blur=0.12, turns=1, duration=0.6` |
| 很快地逆时针转两圈 | `angle=0, pivot=[0.5,0.5], blur=0.18, turns=-2, duration=0.6` |

总旋转量由 `angle` 和 `turns` 决定，速度由 `duration` 决定。`blur` 推荐为清晰 `0`、轻微 `0.05`、中等 `0.12`、明显 `0.3`。默认围绕中心完成两圈进入；如果明确要求只转指定角度，可将 `turns` 设为 `0`。

素材由服务端绑定。本工具不处理三维旋转、持续自转、方向模糊滤镜、镜头旋转或路径运动，也不要输出资源参数。

## 服务器输入槽（不进入模型 `data`）

- `source_layer`（必需，`data`，单个）：服务端解析并栅格化的真实主图层。模型不得输出该槽或任何资源身份；缺失时必须停止执行。
