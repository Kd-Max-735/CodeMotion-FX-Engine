# 沃罗诺伊图 `voronoi`

## 1. 工具作用

使用确定性 seed 生成有限站点，并在有界网格上计算最近站点与边缘，形成细胞、马赛克、石纹类动态图案。

## 2. 输出要求

模型只输出 `{"type":"voronoi","data":{...}}`。不要输出 Markdown 说明、外部数据、调色板 ID、图片路径、URL 或额外顶层字段。

## 3. 合法 JSON 示例

```json
{"type":"voronoi","data":{"seed":52,"pointCount":72,"gridSize":48,"jitter":1,"speed":0.3,"edgeWidth":0.035,"cellColor":"#90E0EF","edgeColor":"#023E8A"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `seed` | 整数 | 0–2147483647 | 23 | 控制可复现的站点布局 |
| `pointCount` | 整数 | 4–128 | 24 | 细胞数量和密度 |
| `gridSize` | 整数 | 8–64 | 32 | 最近点场的采样精度 |
| `jitter` | 数值 | 0–1 | 0.8 | 0 更规则，1 更自然随机 |
| `speed` | 数值 | -2–2 | 0.2 | 站点运动速度与方向 |
| `edgeWidth` | 数值 | 0.005–0.3 | 0.08 | 细胞边缘宽度 |
| `cellColor` | `#RRGGBB` | 六位十六进制 | `#90E0EF` | 细胞主体颜色 |
| `edgeColor` | `#RRGGBB` | 六位十六进制 | `#023E8A` | 边缘颜色 |

最近站点计算预算为 `gridSize² × pointCount ≤ 524288`，网格输出最多包含 4096 个 cell 索引和 4096 个边缘标记。

## 5. 表达映射

“更多/更密的格子”提高 `pointCount`，需要更平滑边缘时提高 `gridSize`；“规整蜂窝感”降低 `jitter`，“自然石纹”提高它；“边更粗”提高 `edgeWidth`；“快/慢/反向”调整 `speed`；色彩只用两个直接色值。

## 6. 自然语言例子

- “做规则的大块细胞” → 低 `pointCount`、低 `jitter`。
- “细密随机马赛克” → 高 `pointCount`、高 `jitter`、较高 `gridSize`。
- “缓慢变化的灰色石纹” → 中低点数、低速、灰色主体和深色边。
- “边线更细” → 降低 `edgeWidth`。
- “换一种可复现的分布” → 只更改 `seed`。
- “让细胞反方向流动” → 使用负 `speed`。

## 7. 推荐档位

| 档位 | `pointCount` | `gridSize` | `jitter` |
| --- | ---: | ---: | ---: |
| 大块 | 4–16 | 16–32 | 0–0.5 |
| 均衡 | 20–48 | 32–48 | 0.5–0.85 |
| 细密 | 56–128 | 48–64 | 0.8–1 |

## 8. 默认值与中性行为

默认值生成 24 个较自然但仍均匀分布的细胞，边缘适中并轻微移动，适合作为通用抽象背景。

## 9. 不能处理的内容

服务器可选绑定一张 `background_image` 图片并通过单元折射显示，但站点仍由受限算法生成。模型不能从地图、图片或外部点集读取站点；不能输出数据资源 ID、路径、URL、纹理或调色板资源；不能进行三维 Voronoi 或多工具合成。
