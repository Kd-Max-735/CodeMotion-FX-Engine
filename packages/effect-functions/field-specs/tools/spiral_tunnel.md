# 螺旋隧道 `spiral_tunnel`

## 1. 工具作用

用有界点列生成带透视衰减的阿基米德式螺旋隧道，适合穿梭、旋转光轨和纵深通道。最大输出为 24 × 96 = 2304 个点。

## 2. 输出要求

模型只能输出 `{"type":"spiral_tunnel","data":{...}}` JSON。不要输出说明、资源 ID、纹理、路径、URL、相机设置或第二个效果。

## 3. 合法 JSON 示例

```json
{"type":"spiral_tunnel","data":{"turns":10,"pointsPerTurn":48,"radius":0.85,"depth":2.2,"twist":20,"speed":0.8,"strokeColor":"#FEE440","backgroundColor":"#001219"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `turns` | 整数 | 2–24 | 10 | 隧道圈数和纵向重复量 |
| `pointsPerTurn` | 整数 | 12–96 | 48 | 每圈采样密度和线条平滑度 |
| `radius` | 数值 | 0.1–2 | 0.85 | 隧道入口宽度 |
| `depth` | 数值 | 0.25–4 | 2.2 | 透视收缩强度 |
| `twist` | 数值 | -180–180 度 | 20 | 沿深度附加扭转 |
| `speed` | 数值 | -4–4 | 0.8 | 旋转速度，负值反向 |
| `strokeColor` | `#RRGGBB` | 六位十六进制 | `#FEE440` | 光轨颜色 |
| `backgroundColor` | `#RRGGBB` | 六位十六进制 | `#001219` | 背景颜色 |

## 5. 表达映射

“更密”提高 `turns` 或 `pointsPerTurn`，前者增加圈数，后者只提升单圈平滑度；“隧道更宽”提高 `radius`；“纵深更强”提高 `depth`；“扭曲/反扭”调整 `twist`；“更快/倒转”调整 `speed`；颜色直接给出。

## 6. 自然语言例子

- “做一个黄色光轨隧道” → 使用默认结构和黄色 `strokeColor`。
- “圈数更多、更细腻” → 同时提高 `turns` 和 `pointsPerTurn`。
- “入口宽、远端快速收缩” → 高 `radius`、高 `depth`。
- “向反方向缓慢旋转” → 小幅负 `speed`。
- “带明显左扭的隧道” → 使用负的较大 `twist`。
- “降低复杂度但保持圈数” → 降低 `pointsPerTurn`。

## 7. 推荐档位

| 档位 | `turns` | `pointsPerTurn` | `depth` |
| --- | ---: | ---: | ---: |
| 轻量 | 3–7 | 12–32 | 0.5–1.5 |
| 均衡 | 8–14 | 36–64 | 1.5–3 |
| 密集 | 15–24 | 64–96 | 2.5–4 |

## 8. 默认值与中性行为

默认值生成十圈、标准平滑度、适中入口和纵深的轻微右扭隧道，以中速正向旋转。

## 9. 不能处理的内容

服务器可选绑定一张 `background_image` 图片作为隧道底图。模型不能接收三维模型、纹理、相机资源、图片、视频、文件路径、URL 或资源 ID；不能输出真实相机运动或多效果组合。
