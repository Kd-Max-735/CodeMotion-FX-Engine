# 马克笔涂抹 `marker_stroke`

在用户上传的一张图片上，根据用户点名的可见部位生成重叠的确定性马克笔笔头印迹，模拟透明叠色、渗色和纸面边缘。模型会在服务端受控地读取该图片并输出目标的简短英文名称；服务器随后用 SAM3.1 分割该目标，按照目标遮罩的实际范围生成多行涂抹，所有马克笔像素都被限制在精确目标 mask 内。只输出 JSON，不要附加解释、Markdown 或代码块：

视频由服务端在前 1.4 秒沿笔迹逐步落笔，之后保留完整涂抹结果；该显现时间不是模型参数。

```json
{"type":"marker_stroke","data":{"target":"main subject","width":28,"opacity":0.82,"overlap":0.35,"bleed":0.12,"edgeRoughness":0.08,"spacing":0.3,"color":"#ff4e76","startX":0.2,"startY":0.55,"endX":0.8,"endY":0.55,"curve":0}}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `target` | 否 | 1–80 个英文字符，默认 `main subject` | 把用户点名的可见对象翻译为 SAM3.1 可识别的简短英文名，例如 `car license plate`、`person's left eye` |
| `width` | 否 | `1..400` px，默认 `28` | 笔触宽度 |
| `opacity` | 否 | `0..1`，默认 `0.82` | 单次笔头透明度 |
| `overlap` | 否 | `0..1`，默认 `0.35` | 笔头覆盖密度和叠色程度 |
| `bleed` | 否 | `0..1`，默认 `0.12` | 边缘随机外扩程度 |
| `edgeRoughness` | 否 | `0..0.5`，默认 `0.08` | 中心线横向细小扰动 |
| `spacing` | 否 | `0.05..1`，默认 `0.3` | 相对笔宽的印迹间距 |
| `color` | 否 | `#RRGGBB`，默认 `#ff4e76` | 马克笔颜色 |
| `startX` | 否 | `0..1`，默认 `0.2` | 笔迹起点横向坐标，0 为左、1 为右 |
| `startY` | 否 | `0..1`，默认 `0.55` | 笔迹起点纵向坐标，0 为上、1 为下 |
| `endX` | 否 | `0..1`，默认 `0.8` | 笔迹终点横向坐标 |
| `endY` | 否 | `0..1`，默认 `0.55` | 笔迹终点纵向坐标 |
| `curve` | 否 | `-1..1`，默认 `0` | 0 为直线，正负值向连线两侧弯曲 |

## 参数选择规则

1. 用户说“涂抹汽车”“涂抹汽车车牌”“标记人物眼睛”等可见语义目标时，必须查看上传图片，把对象名称翻译为简短英文 `target`。服务器以 SAM3.1 遮罩的包围区域生成覆盖笔迹，不再依赖固定的整图路径。
2. 坐标以完整图片左上角为 `(0,0)`、右下角为 `(1,1)`。若用户要求横向涂抹目标区域，起点放在目标左侧、终点放在目标右侧；竖向要求则相应使用上、下边界。
3. 用户直接说“图片左上角到中心”等几何位置时按语义换算坐标，并用该位置最主要的可见对象作为 `target`。无法可靠识别点名对象时使用 `main subject`，不得编造资源标识。
4. 先定 `width`，再用 `opacity` 控制覆盖感；不要靠极密间距代替高不透明度。
5. “重复涂过、接缝加深”提高 `overlap`；“纸张吸墨”提高 `bleed`。干净荧光笔降低 `bleed` 和 `edgeRoughness`。
6. 用户指定红、蓝、绿等颜色时转换为对应 `#RRGGBB`；未指定颜色保持默认值。

| 自然语言 | 参数对应 |
| --- | --- |
| 干净的半透明荧光笔 | `opacity=0.5, bleed=0.02, edgeRoughness=0.02` |
| 宽一点的普通马克笔 | `width=44, opacity=0.82` |
| 重复涂抹处明显加深 | `overlap=0.72, spacing=0.18` |
| 纸面有一点渗色 | `bleed=0.2, edgeRoughness=0.1` |
| 很毛糙的手绘边缘 | `bleed=0.32, edgeRoughness=0.24` |
| 窄而均匀的标签笔 | `width=12, spacing=0.22, bleed=0.03` |
| 用绿色马克笔涂抹图片中的车牌 | `target=car license plate`，视觉定位车牌左右边界写入起止坐标，`color=#22aa66` |
| 从人物左眼到右眼画一条略向上的弧线 | `target=person eyes`，视觉定位双眼中心写入起止坐标，设置非零 `curve` |

| 程度 | `width` | `bleed`/`edgeRoughness` |
| --- | ---: | --- |
| 轻微 | `12` | `0.03/0.02` |
| 中等 | `28` | `0.12/0.08` |
| 明显 | `52` | `0.25/0.16` |
| 强烈 | `90` | `0.4/0.28` |

默认值为示例中的完整 `data`。中性外观值是 `bleed=0`、`edgeRoughness=0`、`curve=0`，完全透明为 `opacity=0`。服务端绑定一张原始图片，并根据 `target` 派生一个 `subject_mask`；涂抹完成后仍保留原图作为背景。mask、SAM 响应、图片字节和资源身份都不进入模型 `data`。不适用于纹理笔刷、真实水彩扩散、图片显现或霓虹光效。模型不得输出图片、资源 ID、路径、URL、mask 或纹理字段。
