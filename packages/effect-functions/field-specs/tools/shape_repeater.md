# 图形重复器 `shape_repeater`

重复服务端绑定的矢量图形，并为重复单元应用二维偏移、逐级旋转和缩放。对应现有特效 `fx.vector.shapeRepeater`。

需要调用时只输出以下 JSON，不要附加解释或代码块：

```json
{
  "type": "shape_repeater",
  "data": {
    "count": 8,
    "offset": [0.08, 0.04],
    "rotation": 12,
    "scale": 0.92
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `count` | 是 | 整数 `1..128`，默认 `8` | 重复单元数量；数量越大性能开销越高 |
| `offset` | 是 | 两元素数组 `[x,y]`，每项 `-1..1`、步长 `0.01`，默认 `[0.08,0.04]` | 每级二维位移；正 x 向右，正 y 向下 |
| `rotation` | 是 | 数字 `-360..360` 度，步长 `1`，默认 `12` | 每级旋转量；负值反向旋转 |
| `scale` | 是 | 数字 `0.01..2`，步长 `0.01`，默认 `0.92` | 每级缩放；小于 `1` 逐级缩小，大于 `1` 逐级放大 |

## 参数选择优先级

先确定 `count`，再用 `offset` 建立阵列方向，最后用 `rotation` 和 `scale` 形成扇形或递进。普通平铺应保持 `rotation=0, scale=1`，不要用大旋转和大偏移同时制造难以控制的分散。

| 用户提示词 | 应输出的 `data` 参数 |
| --- | --- |
| 向右下重复八个并逐渐缩小 | `count=8, offset=[0.08,0.04], rotation=0, scale=0.92` |
| 水平排成五个同样大小 | `count=5, offset=[0.15,0], rotation=0, scale=1` |
| 形成旋转递进的十个图形 | `count=10, offset=[0.05,0.03], rotation=18, scale=0.9` |
| 向左上逐级放大 | `count=6, offset=[-0.1,-0.06], rotation=0, scale=1.08` |
| 密集强烈的螺旋阵列 | `count=24, offset=[0.04,0.02], rotation=30, scale=0.96` |

`count` 推荐值：轻微 `3`，中等 `8`，明显 `16`，强烈 `32`。`rotation` 推荐绝对值：轻微 `5°`，中等 `12°`，明显 `24°`，强烈 `45°`。默认重复八个并向右下偏移、略微缩小；`count=1, offset=[0,0], rotation=0, scale=1` 是中性设置。

矢量图形和路径由服务端绑定。本工具不生成图形、不处理粒子、真实三维复制、复杂网格排版或素材加载，也不要输出资源字段。

## 服务器输入槽（不进入模型 `data`）

- `vector_source`（必需，`data`，单个）：服务端解析的真实矢量图形及其栅格化结果。图片上传模式下，服务器从已授权图片提取轮廓代理以供单工具预览，图片身份不进入模型参数；缺失时必须停止执行。
