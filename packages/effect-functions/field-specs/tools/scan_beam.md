# 扫描光束 `scan_beam`

让一条柔和光带按指定角度和速度循环扫过画面。对应现有特效 `fx.light.scanBeam`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "scan_beam",
  "data": {
    "angle": 18,
    "width": 0.12,
    "softness": 0.4,
    "speed": 0.8
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `angle` | 是 | 数字 `-360..360` 度，步长 `1` | `0` 为水平坐标方向；正负值控制光带倾斜方向 |
| `width` | 是 | 数字 `0.005..1`，步长 `0.005`，相对画布 | 越大光带越宽 |
| `softness` | 是 | 数字 `0..1`，步长 `0.01` | 越大边缘越柔和 |
| `speed` | 是 | 数字 `-10..10` 周/秒，步长 `0.1` | 绝对值控制速度，正负号控制扫描方向，`0` 静止 |

## 参数选择规则

- 用户给出角度时直接使用合法整数度；“反向倾斜”优先改变 `angle` 符号。
- “细扫描线/宽光带”调整 `width`；“硬边/柔光”调整 `softness`，二者不可互相替代。
- “慢/快”映射到 `speed` 的绝对值；“反向扫”取负值；未说反向时保留正值。
- 用户只说“换方向”但未给角度时，优先保留角度并反转 `speed`，因为这是运动方向而非光带朝向。
- 未提及的参数保持默认值，避免同时把宽度和柔和度推到极端导致光带覆盖全画面。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 细硬的水平扫描线，慢慢扫 | `{"angle":0,"width":0.03,"softness":0.1,"speed":0.3}` |
| 默认倾角和柔和度，正常速度 | `{"angle":18,"width":0.12,"softness":0.4,"speed":0.8}` |
| 45 度宽光带，快速反向扫描 | `{"angle":45,"width":0.3,"softness":0.65,"speed":-2.5}` |
| 垂直方向的柔光扫描，速度很慢 | `{"angle":90,"width":0.18,"softness":0.85,"speed":0.2}` |
| 光束停在当前相位，不要移动 | `{"angle":18,"width":0.12,"softness":0.4,"speed":0}` |

## 推荐档位

| 表达 | `width` | `softness` | `speed` 绝对值 |
| --- | ---: | ---: | ---: |
| 细/硬/慢 | `0.03` | `0.1` | `0.3` |
| 中等 | `0.12` | `0.4` | `0.8` |
| 宽/柔/快 | `0.3` | `0.8` | `2.5` |

默认值为 `angle=18`、`width=0.12`、`softness=0.4`、`speed=0.8`。`speed=0` 是静止中性值，`softness=0` 是最硬边缘，`softness=1` 是最柔边缘；`speed=±10`、`width=1` 是极端边界，只在用户明确要求时使用。角度相差 `360` 度视觉方向等价，优先用接近 `-180..180` 的表达。

源画面由服务端绑定，不生成图片、视频、资源 ID、路径或 URL。本工具不用于霓虹轮廓、镜头光晕、能量环、真实激光物理模拟或改变素材本身。
