# 阻尼弹性 `elastic`

让服务端绑定的画面沿水平、垂直或缩放方向产生逐渐停止的弹性振荡。对应现有特效 `fx.motion.elastic`。

需要调用时只输出以下 JSON，不要附加解释或代码块：

```json
{
  "type": "elastic",
  "data": {
    "amplitude": 0.16,
    "period": 0.28,
    "decay": 5,
    "axis": "x"
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `amplitude` | 是 | 数字 `0..2` 画布比例，步长 `0.01`，默认 `0.16` | 初始振幅；越大位移或缩放越明显 |
| `period` | 是 | 数字 `0.02..4` 秒，步长 `0.01`，默认 `0.28` | 单次振荡周期；越小振荡越快 |
| `decay` | 是 | 数字 `0..20`，步长 `0.1`，默认 `5` | 阻尼衰减；越大停止越快，`0` 不衰减 |
| `axis` | 是 | `x` / `y` / `scale`，默认 `x` | 水平弹动选 `x`，垂直选 `y`，呼吸式缩放选 `scale` |

## 参数选择优先级

先选 `axis`，再用 `amplitude` 定幅度、`period` 定速度、`decay` 定持续感。用户说“快停下来”应增大 `decay`，不是把 `period` 降到极小。

| 用户提示词 | 应输出的 `data` 参数 |
| --- | --- |
| 水平轻微弹一下 | `amplitude=0.08, period=0.3, decay=8, axis=x` |
| 上下弹性摆动 | `amplitude=0.2, period=0.4, decay=5, axis=y` |
| 尺寸像果冻一样弹动 | `amplitude=0.12, period=0.25, decay=4, axis=scale` |
| 高频抖动后迅速停下 | `amplitude=0.15, period=0.1, decay=14, axis=x` |
| 大幅持续弹性振荡 | `amplitude=0.6, period=0.7, decay=1, axis=y` |

`amplitude` 推荐值：轻微 `0.06`，中等 `0.16`，明显 `0.35`，强烈 `0.7`。`decay` 推荐为持续 `1`、中等 `5`、快速停止 `10`、极快停止 `16`。默认是水平中等振幅、`0.28` 秒周期、衰减 `5`；`amplitude=0` 是中性设置。

素材由服务端绑定。本工具不处理随机冲击抖动、物理碰撞、连续漂浮、声音或三维软体模拟，也不要输出资源字段。

## 服务器输入槽（不进入模型 `data`）

- `source_layer`（必需，`data`，单个）：服务端解析并栅格化的真实主图层。模型不得输出该槽或任何资源身份；缺失时必须停止执行。
