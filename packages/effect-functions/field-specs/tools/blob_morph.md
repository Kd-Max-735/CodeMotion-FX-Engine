# 有机液态形状变形 `blob_morph`

对服务端绑定的闭合轮廓进行确定性谐波噪声变形和张力平滑，生成可动画的有机形状。只输出 JSON，不要附加解释、Markdown 或代码块：

```json
{"type":"blob_morph","data":{"vertexCount":24,"noiseAmount":0.18,"noiseScale":3,"tension":0.65,"speed":0.5,"rotation":0}}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `vertexCount` | 否 | 整数 `8..128`，默认 `24` | 轮廓细节数；近景可提高 |
| `noiseAmount` | 否 | `0..0.8`，默认 `0.18` | 控制轮廓不规则程度 |
| `noiseScale` | 否 | `1..12`，默认 `3` | 控制大小起伏的层数 |
| `tension` | 否 | `0..1`，默认 `0.65` | 越高越圆滑，越低越尖锐 |
| `speed` | 否 | `0..5`，默认 `0.5` | 噪声随时间变化速度 |
| `rotation` | 否 | `-360..360` 度，默认 `0` | 旋转采样方向，不是对象旋转 |

## 参数选择规则

1. “更液态”优先提高 `noiseAmount`，并保持中高 `tension`；“尖锐怪异”才降低张力。
2. `noiseScale` 决定起伏复杂度，不等同于强度。
3. 静态有机轮廓用 `speed=0`；精细近景提高 `vertexCount`，普通预览保持 24–40。

| 自然语言 | 参数对应 |
| --- | --- |
| 柔软地呼吸 | `noiseAmount=0.1, tension=0.85, speed=0.22` |
| 像液滴一样慢慢摆动 | `noiseAmount=0.2, tension=0.72, speed=0.45` |
| 边缘很多小起伏 | `noiseScale=7, vertexCount=48` |
| 做成尖锐不稳定的团块 | `noiseAmount=0.42, tension=0.25, speed=1.1` |
| 保持静态有机轮廓 | `speed=0, noiseAmount=0.16` |
| 把起伏方向转九十度 | `rotation=90` |

| 程度 | `noiseAmount` | `tension` |
| --- | ---: | ---: |
| 轻微 | `0.07` | `0.88` |
| 中等 | `0.18` | `0.65` |
| 明显 | `0.35` | `0.45` |
| 强烈 | `0.6` | `0.2` |

默认值为示例中的完整 `data`。中性变形值是 `noiseAmount=0`，中性动画值是 `speed=0`、`rotation=0`。不适用于两形状路径插值、流体物理、位图液化或开放路径波浪；源轮廓由服务端绑定，不放进 `data`。

## 服务器输入槽（不进入模型 `data`）

- `source_shape`（必需，`data`，单个）：提示词直接生成模式下由服务器创建确定性的闭合默认轮廓，不要求用户上传素材。模型不得输出轮廓点、资源身份、路径或 URL。
