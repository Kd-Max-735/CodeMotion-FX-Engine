# 波浪曲面 `wave_surface`

## 1. 工具作用

在有界二维网格上计算交叉波、径向波或斜向波的高度与坡度，形成可动画的参数化曲面。最大网格为 64 × 64。

## 2. 输出要求

模型只输出一个 `type/data` JSON 对象，`type` 必须为 `wave_surface`。不得输出资源、路径、URL、代码、材质文件、场景或其他工具。

## 3. 合法 JSON 示例

```json
{"type":"wave_surface","data":{"mode":"radial","gridSize":48,"amplitude":0.35,"frequencyX":5.5,"frequencyY":2,"damping":1.2,"speed":1.5,"crestColor":"#CAF0F8","troughColor":"#0077B6"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `mode` | 枚举 | `cross` / `radial` / `diagonal` | `cross` | 交叉起伏、中心涟漪或斜向行波 |
| `gridSize` | 整数 | 8–64 | 32 | 曲面采样密度 |
| `amplitude` | 数值 | 0.01–2 | 0.55 | 波峰与波谷高度 |
| `frequencyX` | 数值 | 0.25–12 | 3 | X 方向频率；径向模式使用它作主频率 |
| `frequencyY` | 数值 | 0.25–12 | 2 | Y 方向频率 |
| `damping` | 数值 | 0–3 | 0.35 | 从中心向外的衰减强度 |
| `speed` | 数值 | -4–4 | 1 | 相位速度和方向 |
| `crestColor` | `#RRGGBB` | 六位十六进制 | `#CAF0F8` | 波峰颜色 |
| `troughColor` | `#RRGGBB` | 六位十六进制 | `#0077B6` | 波谷颜色 |

## 5. 表达映射

“波更密”提高频率，“起伏更大”提高 `amplitude`，“远处更快消失”提高 `damping`，“更平滑精细”提高 `gridSize`，“更快/反向”调整 `speed`。“水滴涟漪”选择 `radial`，“交织水面”选择 `cross`。

## 6. 自然语言例子

- “做平缓的交叉海浪” → `cross`、低幅度、中低频率。
- “从中心扩散的密集涟漪” → `radial`、高 `frequencyX`。
- “斜向移动的织物波纹” → `diagonal`、不同的 X/Y 频率。
- “波峰更高但不要更密” → 只提高 `amplitude`。
- “边缘迅速平静” → 提高 `damping`。
- “涟漪向内收缩” → 使用负 `speed`。

## 7. 推荐档位

| 档位 | `gridSize` | `amplitude` | 频率 | `damping` |
| --- | ---: | ---: | ---: | ---: |
| 柔和 | 16–24 | 0.05–0.3 | 0.5–3 | 0.5–1.5 |
| 均衡 | 32–48 | 0.3–0.8 | 2–6 | 0.2–1 |
| 强烈 | 48–64 | 0.8–2 | 5–12 | 0–0.6 |

## 8. 默认值与中性行为

默认值生成中等网格、适中幅度和频率的交叉波面，有轻度边缘衰减并以正常速度前进。

## 9. 不能处理的内容

服务器可选绑定一张 `background_image` 图片并由波面位移、明暗和坡度高光处理。不能进行真实流体求解、碰撞或浮力；模型不能读取高度图、纹理、视频、文件、URL 或资源 ID，也不能组合其他效果。
