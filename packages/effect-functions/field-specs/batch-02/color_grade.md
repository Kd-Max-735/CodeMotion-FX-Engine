# 色彩分级（color_grade）

## 效果说明

对服务器绑定画面执行程序化颜色变换：曝光、对比度、饱和度、色温、色调偏移以及 lift/gamma/gain 会真实改变 RGB 数值，可用于电影感、暖调或褪色风格。

## 输出要求

只输出 JSON 对象，不要输出说明或其他工具。顶层必须且只能包含 `type` 和 `data`，`type` 必须为 `color_grade`。LUT、素材 ID、文件路径和 URL 由服务器管理，不能出现在 `data` 中。

```json
{"type":"color_grade","data":{"exposure":0.18,"contrast":1.08,"saturation":1.1,"temperature":0.3,"tint":0.04,"lift":0,"gamma":1,"gain":1.06,"mix":1}}
```

## 模型参数字段

| 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `exposure` | 是 | -3–3，步长 0.01 | 以档为单位整体提亮或压暗 |
| `contrast` | 否 | 0.5–2，步长 0.01 | 1 中性；电影感常用 1.05–1.25 |
| `saturation` | 否 | 0–2，步长 0.01 | 0 黑白，1 中性，大于 1 增艳 |
| `temperature` | 否 | -1–1，步长 0.01 | 负值偏冷，正值偏暖 |
| `tint` | 否 | -1–1，步长 0.01 | 负值偏绿，正值偏洋红 |
| `lift` | 否 | -0.25–0.25，步长 0.01 | 调整黑位；正值产生抬黑褪色感 |
| `gamma` | 否 | 0.2–3，步长 0.01 | 调整中间调曲线；1 中性 |
| `gain` | 否 | 0.5–2，步长 0.01 | 调整高光增益；1 中性 |
| `mix` | 否 | 0–1，步长 0.01 | 调色结果与原画混合比例 |

服务器输入：`source_frame` 为必需授权画面。本实现不要求 LUT；若未来使用 LUT，也只能由服务器授权绑定，不能写入模型 JSON。

## 参数选择规则

1. 先校正曝光，再决定对比度与饱和度，最后处理色温和色调。
2. “褪色”提高 `lift`、降低对比和饱和度；“通透”适度提高曝光、对比和 gain。
3. `gamma` 主要处理感知中间调，不应用极端值代替曝光。
4. 暖冷描述优先映射到 `temperature`；绿/洋红偏色映射到 `tint`。
5. 用户要求保留原色时降低 `mix`，不输出 LUT 引用。

## 自然语言示例

1. “整体暖一点，略微提亮”：曝光小幅为正，色温约 0.2–0.3。
2. “冷峻电影感”：对比提高、饱和略降、色温为负、黑位略压。
3. “做成低饱和褪色胶片”：饱和和对比降低，lift 提高，gain 略降。
4. “鲜艳通透的商业片”：曝光、对比、饱和和 gain 适度提高。
5. “只纠正偏绿，不改亮度”：保持中性曝光，tint 向正值微调。
6. “完全黑白”：`saturation=0`，其他字段按明暗需求选择。

## 推荐档位

| 档位 | contrast | saturation | temperature |
| --- | --- | --- | --- |
| 轻 | 1.05 | 1.03 | ±0.08 |
| 中 | 1.15 | 0.9–1.15 | ±0.2 |
| 强 | 1.35 | 0.6–1.4 | ±0.45 |

## 默认值和中性值

默认值也是完整中性值：`exposure=0`、`contrast=1`、`saturation=1`、`temperature=0`、`tint=0`、`lift=0`、`gamma=1`、`gain=1`、`mix=1`。此外 `mix=0` 会旁路全部调色。

## 不适用范围

不适合依赖特定外部 LUT、局部遮罩调色、肤色跟踪、HDR 色彩管理转换或显示器校准。资源与色彩管理配置不属于模型参数。
