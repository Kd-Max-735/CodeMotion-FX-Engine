# 景深（depth_of_field）

## 效果说明

根据服务器绑定的归一化深度场计算每个像素与焦平面的距离：焦内区域保持清晰，焦外区域随距离增加模糊半径，并对亮部产生可控散景权重。

## 输出要求

只输出合法 JSON，不输出解释、代码围栏之外的文本或其他工具。顶层只能包含 `type` 和 `data`，`type` 必须精确为 `depth_of_field`。深度信息、素材 ID、路径和 URL 由服务器绑定，绝不能写入 `data`。

```json
{"type":"depth_of_field","data":{"focusDepth":0.5,"focusRange":0.12,"blurRadius":8,"bokehBoost":0.25,"edgePreservation":0.6}}
```

## 模型参数字段

| 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `focusDepth` | 是 | 0–1，步长 0.01 | 选择清晰焦平面；0 近、1 远，具体含义服从服务器深度场 |
| `focusRange` | 否 | 0.01–1，步长 0.01 | 小值浅景深，大值让更多深度保持清晰 |
| `blurRadius` | 否 | 0–20，整数 | 焦外最大采样半径；高分辨率强景深取 10–18 |
| `bokehBoost` | 否 | 0–1，步长 0.01 | 提升焦外亮点权重，不改变焦点位置 |
| `edgePreservation` | 否 | 0–1，步长 0.01 | 高值减少跨深度边缘串色 |

当前 AE Agent 只需上传一张图片。服务器将该授权图片绑定为 `source_frame`，并在服务器内部派生同尺寸的锁定 `depth_field`；两者仍是分离的运行时输入，均不进入模型 JSON。

## 参数选择规则

1. 用户明确主体远近时优先确定 `focusDepth`，不要猜测深度资源标识。
2. “浅景深、微距”降低 `focusRange` 并提高 `blurRadius`。
3. “背景稍虚”使用中等焦域和 3–6 的半径。
4. 轮廓复杂或前后景交叠时提高 `edgePreservation`。
5. 只有出现“散景光斑、奶油化高光”时才明显提高 `bokehBoost`。

## 自然语言示例

1. “对焦近处人物，背景强烈虚化”：焦点偏近，焦域小，半径大。
2. “焦点在中景，前后都略微虚化”：`focusDepth` 约 0.5，焦域中等，半径中低。
3. “远山清晰，近处前景朦胧”：焦点偏远，半径中高。
4. “微距产品，只有窄窄一层清楚”：焦域 0.02–0.05，半径 14–20。
5. “保住人物发丝边缘”：提高边缘保持到 0.75 以上。
6. “背景灯变成明显散景”：提高 `bokehBoost`，同时保持较大模糊半径。

## 推荐档位

| 档位 | focusRange | blurRadius | bokehBoost |
| --- | --- | --- | --- |
| 轻 | 0.24 | 4 | 0.1 |
| 中 | 0.12 | 8 | 0.25 |
| 强 | 0.04 | 16 | 0.55 |

## 默认值和中性值

默认值：`focusDepth=0.5`、`focusRange=0.12`、`blurRadius=8`、`bokehBoost=0.25`、`edgePreservation=0.6`。中性值为 `blurRadius=0`；`focusRange=1` 通常接近全景清晰，但严格中性仍应使用半径 0。

## 不适用范围

没有有效深度场、深度场与画面尺寸不一致、需要真实光圈形状或物理镜头追焦时不适用。模型不能生成或引用深度图。
