# 流动渐变光（gradient_flow）

## 效果说明

在服务器绑定的源画面上叠加连续流动的多色渐变。方向、空间尺度、速度、相位和色板共同决定色带运动；它是连续色场，不是随机噪声。

## 输出要求

只输出一个 JSON 对象，不要输出 Markdown、解释、注释或第二个工具。顶层必须且只能包含 `type` 和 `data`，`type` 必须精确为 `gradient_flow`。不得在 `data` 中输出素材 ID、路径、URL 或其他资源信息。

```json
{"type":"gradient_flow","data":{"intensity":0.45,"scale":1.5,"speed":0.35,"angle":25,"phase":0,"palette":"aurora"}}
```

## 模型参数字段

| 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `intensity` | 是 | 0–1，步长 0.01 | 画面需保真取 0.15–0.35；视觉主导取 0.55–0.85 |
| `scale` | 否 | 0.25–6，步长 0.01 | 小值形成密集色带，大值形成宽阔渐变 |
| `speed` | 否 | -3–3，步长 0.01 | 绝对值控制速度，负值反向流动 |
| `angle` | 否 | -180–180，整数 | 0 为水平推进，90 为垂直推进 |
| `phase` | 否 | 0–1，步长 0.01 | 调整初始色带位置，不表示时间点 |
| `palette` | 否 | `aurora` / `sunset` / `ocean` / `prism` | 按极光、暖霞、海洋冷色或全彩语义选择 |

服务器输入：`source_frame` 是必需的授权 RGBA 帧，不属于模型 JSON。

## 参数选择规则

1. 先根据颜色语义选 `palette`，再决定强度和运动。
2. “缓慢、舒展”应提高 `scale` 并降低 `speed`；“快速、密集”反向处理。
3. 用户只要求静态渐变时将 `speed` 设为 0，并用 `phase` 调位置。
4. 未提方向时使用 25；未提颜色时使用 `aurora`。
5. 不要用 `phase` 模拟资源时间轴，不要输出任何资源字段。

## 自然语言示例

1. “加一层很轻的极光，慢慢横向流动”：`aurora`，强度低，尺度偏大，速度低，角度接近 0。
2. “暖色落日从右上往左下扫过”：`sunset`，角度约 -35，强度中高。
3. “海水一样的冷色宽渐变，几乎不动”：`ocean`，尺度大，速度接近 0。
4. “高能量彩虹快速穿过画面”：`prism`，尺度小，速度和强度高。
5. “保持构图，只换一个静态色带位置”：速度 0，仅调整相位。
6. “柔和的竖向品牌背景光”：角度 90，强度低到中，尺度中高。

## 推荐档位

| 档位 | intensity | scale | speed |
| --- | --- | --- | --- |
| 轻 | 0.2 | 2.5 | 0.15 |
| 中 | 0.45 | 1.5 | 0.35 |
| 强 | 0.8 | 0.7 | 1.2 |

## 默认值和中性值

默认值：`intensity=0.45`、`scale=1.5`、`speed=0.35`、`angle=25`、`phase=0`、`palette=aurora`。中性值为 `intensity=0`，此时不改变源画面；`speed=0` 仅表示静止，并非整体中性。

## 不适用范围

不适合需要精确局部遮罩、单一物体跟踪、真实灯光反射或颜色校正的请求。遮罩和素材绑定由服务器处理，不能放入模型参数。
