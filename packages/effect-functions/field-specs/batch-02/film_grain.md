# 胶片颗粒（film_grain）

## 效果说明

使用服务器种子和帧号生成确定性颗粒，可选择单色或彩色颗粒，并让颗粒偏向阴影、高光或均匀分布。相同上下文与参数始终得到相同结果。

## 输出要求

仅输出 JSON，不输出解释、注释或 Markdown。顶层只能包含 `type` 与 `data`，`type` 必须为 `film_grain`。不得在参数中包含素材、路径、URL、纹理或资源 ID。

```json
{"type":"film_grain","data":{"amount":0.32,"size":4,"monochrome":true,"response":"shadows","temporal":0.8}}
```

## 模型参数字段

| 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `amount` | 是 | 0–1，步长 0.01 | 颗粒振幅；自然质感一般 0.06–0.2 |
| `size` | 否 | 1–8，整数 | 1 细密，4 以上明显粗颗粒 |
| `monochrome` | 否 | 布尔值 | `true` 适合传统银盐感，`false` 产生彩色噪点 |
| `response` | 否 | `uniform` / `shadows` / `highlights` | 选择颗粒主要显现的明度区域 |
| `temporal` | 否 | 0–1，步长 0.01 | 0 固定颗粒；越高随帧更新越快 |

服务器输入：`source_frame` 为必需授权画面；随机种子和帧号来自服务器上下文，均不进入模型 JSON。

## 参数选择规则

1. “电影质感、细腻”用小尺寸和低强度。
2. “复古、16mm、粗粝”提高尺寸与强度，通常选择阴影响应。
3. 用户明确彩色胶片噪点时才设 `monochrome=false`。
4. 静帧海报或要求完全固定时将 `temporal` 设为 0。
5. 颗粒不负责划痕、漏光和色彩分级。

## 自然语言示例

1. “加一点几乎看不出的电影颗粒”：强度约 0.08，尺寸 1，单色。
2. “粗糙的 16mm 质感”：强度 0.3 左右，尺寸 4–5，阴影响应。
3. “彩色高感噪点”：单色关闭，强度中等，均匀或高光响应。
4. “颗粒只在暗部明显”：选择 `shadows`。
5. “做成固定不跳动的海报纹理”：`temporal=0`。
6. “每帧都有活跃颗粒”：提高 `temporal` 到 0.8–1。

## 推荐档位

| 档位 | amount | size | temporal |
| --- | --- | --- | --- |
| 轻 | 0.08 | 1 | 0.35 |
| 中 | 0.18 | 2 | 0.65 |
| 强 | 0.35 | 5 | 0.9 |

## 默认值和中性值

默认值：`amount=0.18`、`size=2`、`monochrome=true`、`response=uniform`、`temporal=0.65`。中性值为 `amount=0`。

## 不适用范围

不适合压缩块、数据错帧、像素排序、胶片划痕或外部颗粒纹理贴图。纹理资源不属于模型参数。
