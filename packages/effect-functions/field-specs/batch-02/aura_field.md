# 氛围光场（aura_field）

## 效果说明

围绕可控中心生成椭圆径向光场和柔和环带，可做人物背光、霓虹光环或环境辉光。它以中心、半径和软度形成空间衰减，与连续平面渐变不同。

## 输出要求

只输出 JSON，不要附加说明或 Markdown。顶层只能有 `type` 和 `data`，`type` 必须是 `aura_field`。资源 ID、路径、URL、图片或遮罩均不得进入 `data`。

```json
{"type":"aura_field","data":{"intensity":0.55,"centerX":0.5,"centerY":0.5,"radius":0.42,"softness":0.55,"ellipticity":1,"hue":285,"secondaryHue":190,"pulseRate":0.2}}
```

## 模型参数字段

| 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `intensity` | 是 | 0–1，步长 0.01 | 柔光 0.2–0.4，霓虹主视觉 0.65–0.9 |
| `centerX` | 否 | 0–1，步长 0.01 | 0 左侧，0.5 中心，1 右侧 |
| `centerY` | 否 | 0–1，步长 0.01 | 0 顶部，0.5 中心，1 底部 |
| `radius` | 否 | 0.05–1.5，步长 0.01 | 小半径聚焦，大半径覆盖环境 |
| `softness` | 否 | 0.05–1，步长 0.01 | 小值边界清楚，大值衰减柔和 |
| `ellipticity` | 否 | 0.25–4，步长 0.01 | 1 为近圆形；大于 1 压缩垂直范围，形成横向光场 |
| `hue` | 否 | 0–360，整数 | 主色相角 |
| `secondaryHue` | 否 | 0–360，整数 | 环带另一侧的过渡色相 |
| `pulseRate` | 否 | 0–4，步长 0.01 | 0 静止；大值加快呼吸频率 |

服务器输入：`source_frame` 为必需授权画面，不属于模型参数。

## 参数选择规则

1. 根据主体位置先定中心，再根据覆盖范围定半径。
2. 人像柔光使用较大软度和低强度；霓虹光环使用较小软度和高强度。
3. “宽幅背光”提高 `ellipticity`；“竖长光晕”降低到 1 以下。
4. 用户未要求动态时将 `pulseRate` 设为 0。
5. 色相使用 0/360 红、60 黄、120 绿、180 青、240 蓝、300 品红作为参照。

## 自然语言示例

1. “人物背后加一圈柔暖光”：中心靠主体，半径中等，软度高，主色相约 32。
2. “画面中央做紫青霓虹光环”：中心 0.5/0.5，紫色与青色，高强度、低软度。
3. “底部铺一层宽阔环境光”：中心下移，半径大，椭圆度高。
4. “左上角有一团很淡的蓝光”：中心左上，强度低，半径中小，蓝色相约 220。
5. “光环每秒呼吸一次”：`pulseRate` 约 1。
6. “不要动画，只保留静态光晕”：`pulseRate=0`。

## 推荐档位

| 档位 | intensity | radius | softness |
| --- | --- | --- | --- |
| 轻 | 0.25 | 0.55 | 0.8 |
| 中 | 0.55 | 0.42 | 0.55 |
| 强 | 0.82 | 0.3 | 0.25 |

## 默认值和中性值

默认值：`intensity=0.55`、中心 `0.5/0.5`、`radius=0.42`、`softness=0.55`、`ellipticity=1`、`hue=285`、`secondaryHue=190`、`pulseRate=0.2`。中性值为 `intensity=0`。

## 不适用范围

不适合物理正确的场景照明、阴影重建、镜头耀斑或需要跟踪遮罩的局部补光。位置是归一化画面坐标，不接受对象 ID。
