# RGB 分离（rgb_split）

## 效果说明

沿一个固定角度或从中心向外，分别移动红通道和蓝通道，绿色保持原位，形成清晰可控的通道错位。它强调完整通道分层，而非镜头边缘色散。

## 输出要求

只输出 JSON 对象，不添加解释、注释或其他工具。顶层必须且只能包含 `type` 和 `data`，`type` 必须为 `rgb_split`。素材与资源信息不得进入参数。

```json
{"type":"rgb_split","data":{"distance":6,"angle":0,"redScale":1,"blueScale":1,"mode":"symmetric","mix":0.9}}
```

## 模型参数字段

| 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `distance` | 是 | 0–64，步长 0.1 | 基础通道位移像素数 |
| `angle` | 否 | -180–180，整数 | `symmetric` 模式下的分离轴方向 |
| `redScale` | 否 | 0–2，步长 0.01 | 红通道相对位移倍率 |
| `blueScale` | 否 | 0–2，步长 0.01 | 蓝通道相对位移倍率 |
| `mode` | 否 | `symmetric` / `outward` | 固定轴双向分离，或从中心径向向外分离 |
| `mix` | 否 | 0–1，步长 0.01 | 通道分离结果混合比例 |

服务器输入：`source_frame` 是必需的授权 RGBA 帧，不属于模型 JSON。

## 参数选择规则

1. 明确方向词时选择 `symmetric` 并设置 `angle`。
2. “爆开、从中心扩散”选择 `outward`，此时 `angle` 不重要。
3. 红边更明显时提高 `redScale`；蓝边更明显时提高 `blueScale`。
4. 自然细边使用 1–4 像素，图形化错位可用 10–30 像素。
5. 只在镜头边缘逐渐增强的需求应使用 `chromatic_aberration`。

## 自然语言示例

1. “轻微水平红蓝分边”：距离小、角度 0、对称模式。
2. “沿 45 度方向明显错色”：距离中高、角度 45。
3. “红色拖得比蓝色远”：提高红倍率并降低蓝倍率。
4. “颜色从画面中心向外爆开”：选择 `outward` 并提高距离。
5. “保留一点错色但不要太抢眼”：降低距离与混合。
6. “只有蓝色边缘明显”：红倍率接近 0，蓝倍率提高。

## 推荐档位

| 档位 | distance | redScale / blueScale | mix |
| --- | --- | --- | --- |
| 轻 | 2.5 | 1 / 1 | 0.55 |
| 中 | 6 | 1 / 1 | 0.9 |
| 强 | 18 | 1.2 / 1.2 | 1 |

## 默认值和中性值

默认值：`distance=6`、`angle=0`、`redScale=1`、`blueScale=1`、`mode=symmetric`、`mix=0.9`。中性值为 `distance=0` 或 `mix=0`。

## 不适用范围

不适合色彩校正、镜头径向衰减模拟、压缩故障或跨帧残留。模型不负责选择源图层。
