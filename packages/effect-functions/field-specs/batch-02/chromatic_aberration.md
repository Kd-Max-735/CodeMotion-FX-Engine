# 色差（chromatic_aberration）

## 效果说明

模拟镜头色散：红、蓝通道沿相反方向采样，既可随画面半径增强形成镜头边缘色差，也可叠加固定方向偏移。绿色通道保持基准位置。

## 输出要求

只输出一个 JSON 对象，不添加解释。顶层必须且只能有 `type` 和 `data`，`type` 精确为 `chromatic_aberration`。不得输出图片、路径、URL 或资源 ID。

```json
{"type":"chromatic_aberration","data":{"amount":4,"radial":0.7,"angle":0,"falloff":1,"mix":0.8}}
```

## 模型参数字段

| 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `amount` | 是 | 0–24，步长 0.1 | 通道最大偏移像素；自然镜头感一般 1–4 |
| `radial` | 否 | 0–1，步长 0.01 | 1 为中心向边缘色散，0 为固定方向色散 |
| `angle` | 否 | -180–180，整数 | 控制固定方向分量；纯径向时影响很小 |
| `falloff` | 否 | 0–3，步长 0.01 | 大值把色差集中到边缘，小值让中心也明显 |
| `mix` | 否 | 0–1，步长 0.01 | 原画与色散结果混合比例 |

服务器输入：`source_frame` 为必需授权 RGBA 帧，不属于模型 JSON。

## 参数选择规则

1. “镜头边缘色差”使用高 `radial`、较高 `falloff` 和低到中等 `amount`。
2. “复古错位、方向性色边”降低 `radial`，再用 `angle` 定方向。
3. 自然效果优先降低 `amount`，不要仅靠降低 `mix` 掩盖过大偏移。
4. 用户未指定时采用偏径向配置。
5. 需要完整 RGB 图层错位时应使用 `rgb_split`，不是本工具。

## 自然语言示例

1. “只在镜头边缘有一点色边”：径向 1，衰减高，偏移 1–3。
2. “老镜头的红蓝色散”：偏移 4–7，径向中等，混合中高。
3. “水平方向强烈色差”：径向低，角度 0，偏移高。
4. “对角线轻微色边”：角度 45，径向约 0.3，偏移低。
5. “中心干净，四角明显”：径向高，衰减 2 左右。
6. “色差再淡一点”：保持方向，降低偏移和混合。

## 推荐档位

| 档位 | amount | radial | mix |
| --- | --- | --- | --- |
| 轻 | 1.5 | 1 | 0.45 |
| 中 | 4 | 0.7 | 0.8 |
| 强 | 15 | 0.8 | 1 |

## 默认值和中性值

默认值：`amount=4`、`radial=0.7`、`angle=0`、`falloff=1`、`mix=0.8`。中性值为 `amount=0` 或 `mix=0`。

## 不适用范围

不适合色彩校正、全通道图层分离、镜头耀斑或需要真实镜头标定数据的任务。源画面只能由服务器绑定。
