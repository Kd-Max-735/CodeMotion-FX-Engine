# 节拍脉冲

- toolName：`beat_pulse`
- effectId：`fx.audio.beatPulse`

## 工具作用

根据服务端预计算并锁定的真实音频节拍分析，让目标产生缩放、发光或两者兼有的脉冲。音频及分析结果由服务端绑定，不属于模型参数。

## 输出约束

只输出一个合法 JSON 对象，不要输出 Markdown、解释、注释或第二个工具调用。`type` 必须严格等于 `beat_pulse`，`data` 只能包含下列字段。

```json
{
  "type": "beat_pulse",
  "data": {
    "sensitivity": 0.62,
    "decay": 0.28,
    "amount": 0.35,
    "targetProperty": "both"
  }
}
```

## 参数字段

| 字段 | 必填 | 取值 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `sensitivity` | 是 | 0–1 | 0.62 | 越低越容易响应弱节拍 |
| `decay` | 否 | 0.05–2 秒 | 0.28 | 脉冲回落时间 |
| `amount` | 否 | 0–2 | 0.35 | 缩放或发光增量 |
| `targetProperty` | 是 | `scale` / `glow` / `both` | `both` | 固定的响应属性 |

## 服务器输入

| inputSlot | kind | 必需 | 说明 |
| --- | --- | --- | --- |
| `audio_analysis` | `audio` | 是 | 用户上传音频后，服务端解码并生成锁定的真实逐时间分析帧 |

## 选择策略

“更敏感”降低 `sensitivity`；“更平滑”或“拖尾更长”提高 `decay`；“更快、更利落”降低 `decay`；“更强”提高 `amount`；“更亮”选择 `glow` 或 `both` 并提高 `amount`。未说明属性时用 `both`。

## 参数优先级

先确定 `targetProperty`，再按节拍强弱确定 `sensitivity`，最后用 `decay` 和 `amount` 调整节奏与幅度。避免同时把灵敏度调得很低且幅度调到极高。

## 自然语言示例

1. 跟着鼓点轻轻放大，回落柔和一点。
2. 只让霓虹发光响应强拍，不要缩放。
3. 弱一点的节拍也要触发，脉冲短促。
4. 做明显的俱乐部重拍缩放和发光。
5. 节奏更平滑，幅度控制得克制些。
6. 只响应最强的鼓点，快速恢复。

## 推荐值、默认值和中性值

推荐从 `sensitivity=0.62`、`decay=0.28`、`amount=0.35`、`targetProperty=both` 开始；这组值同时是默认值和中性值。轻柔场景可把 `amount` 调到 0.15–0.25。

## 非适用范围

不生成或选择音频、音频地址、分析缓存、图层、字体或资源 ID；不做起音事件编排，不组合其他特效，也不决定渲染或导出设置。
