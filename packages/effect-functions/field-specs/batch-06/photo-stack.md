# 照片叠放（photo_stack）

## 工具作用

把服务端按顺序绑定的多张照片逐张揭示，并以可复现的二维偏移、旋转和深度间隔组成照片堆。照片数量与身份由服务端授权绑定，`data` 只控制最多显示数量和布局。

## JSON 示例

```json
{"type":"photo_stack","data":{"visibleCount":8,"revealInterval":0.25,"spreadX":0.22,"spreadY":0.14,"maxRotation":12,"depthGap":0.03,"startTime":0.5}}
```

## 参数字段

| 字段 | 类型与范围 | 默认值 | 推荐值 | 中性值 | 含义 |
| --- | --- | ---: | --- | ---: | --- |
| `visibleCount` | integer，2–32 | 6 | 4–12 | 2 | 最多显示的照片数 |
| `revealInterval` | number，0–10 秒 | 0.35 | 0.15–0.8 | 0 | 每张出现的间隔 |
| `spreadX` | number，0–1 | 0.16 | 0.05–0.35 | 0 | 横向散开距离 |
| `spreadY` | number，0–1 | 0.1 | 0.04–0.25 | 0 | 纵向散开距离 |
| `maxRotation` | number，0–45 度 | 8 | 3–20 | 0 | 单张最大随机旋转角 |
| `depthGap` | number，0–1 | 0.02 | 0.01–0.08 | 0 | 层间深度距离 |
| `startTime` | number，0–3600 秒 | 0 | 0–3 | 0 | 第一张出现时间 |

## 选择规则与优先级

用户明确“几张”时设置 `visibleCount`，但不得假设服务端一定绑定了足够照片。“整齐”降低散开与旋转，“散落”提高它们；“一起出现”令 `revealInterval=0`。优先级：明确数量/开始时间/间隔 > 布局方向与松散程度 > 风格词 > 默认值。

## 用户表达示例

- “八张照片依次叠到桌面上。”
- “做整齐的相册堆，旋转小一点。”
- “十张照片快速散落开。”
- “所有照片同时出现，不要错峰。”
- “半秒后开始，每张间隔 0.3 秒。”
- “横向铺开一些，纵向保持紧凑。”

## 不适合处理

不用于上传或选择照片、生成新照片、决定资源 ID、无限照片墙、视频剪辑或对单张图做深度视差。
