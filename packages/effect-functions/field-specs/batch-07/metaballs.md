# 融球场 `metaballs`

## 1. 工具作用

生成多个确定性运动中心，叠加反平方隐式场，形成会融合和分离的融球轮廓。点数和网格均有硬上限，避免无限采样。

## 2. 输出要求

只输出 `type/data` JSON，`type` 必须严格为 `metaballs`。不得输出音视频或图片路径、资源 ID、外部纹理、解释文字或额外字段。

## 3. 合法 JSON 示例

```json
{"type":"metaballs","data":{"seed":31,"ballCount":8,"gridSize":32,"radius":0.12,"threshold":1.1,"speed":0.6,"fillColor":"#FF006E","backgroundColor":"#03071E"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `seed` | 整数 | 0–2147483647 | 31 | 控制中心初始位置与运动相位 |
| `ballCount` | 整数 | 2–32 | 8 | 控制融球数量和画面复杂度 |
| `gridSize` | 整数 | 8–64 | 32 | 控制隐式场采样精度 |
| `radius` | 数值 | 0.02–0.35 | 0.12 | 单个球的影响半径 |
| `threshold` | 数值 | 0.25–4 | 1.1 | 高值使轮廓收紧，低值更易融合 |
| `speed` | 数值 | 0–4 | 0.6 | 中心运动速度；0 为静止 |
| `fillColor` | `#RRGGBB` | 六位十六进制 | `#FF006E` | 融球颜色 |
| `backgroundColor` | `#RRGGBB` | 六位十六进制 | `#03071E` | 背景颜色 |

## 5. 表达映射

“更多、更复杂”提高 `ballCount`；“更大、更容易粘连”提高 `radius` 或降低 `threshold`；“分离、更紧致”提高 `threshold`；“更流畅精细”提高 `gridSize`；“更快/静止”调整 `speed`。颜色直接设置，不引用调色板文件。

## 6. 自然语言例子

- “粉色熔岩在深色背景缓慢流动” → 默认附近参数和低速。
- “很多小水银球快速融合” → 高 `ballCount`、小 `radius`、中低阈值、高速。
- “只有几个大而柔软的变形体” → 低球数、大半径、低速。
- “让形状彼此更分离” → 提高 `threshold`。
- “保持当前形状不动” → `speed` 0 并保持 seed。
- “换一种随机布局” → 更换 `seed`。

## 7. 推荐档位

| 档位 | `ballCount` | `gridSize` | `radius` | `threshold` |
| --- | ---: | ---: | ---: | ---: |
| 简洁 | 2–5 | 16–32 | 0.15–0.28 | 0.7–1.2 |
| 均衡 | 6–12 | 32–48 | 0.08–0.18 | 0.9–1.5 |
| 密集 | 13–32 | 48–64 | 0.03–0.1 | 1.1–2.5 |

## 8. 默认值与中性行为

默认值提供八个中等大小的球、均衡阈值、标准采样和温和速度，既能看见融合又不会充满全场。

## 9. 不能处理的内容

不能使用图片或三维模型作为球体，不能读取外部力场、纹理、遮罩、文件、URL 或资源 ID；不能模拟真实流体碰撞，也不组合其他工具。
