# 神圣几何 `sacred_geometry`

## 1. 工具作用

使用极坐标和有限构造规则生成生命之花、梅塔特隆式连线或室利延陀罗式交叠三角形，输出圆与线的确定性几何描述。

## 2. 输出要求

只输出 `{"type":"sacred_geometry","data":{...}}` JSON。不要输出符号解释、宗教断言、SVG 文件、外部图案、资源标识、路径或额外工具调用。

## 3. 合法 JSON 示例

```json
{"type":"sacred_geometry","data":{"pattern":"flower_of_life","rings":5,"symmetry":6,"scale":0.8,"rotation":0,"speed":0.12,"strokeColor":"#FFD166","backgroundColor":"#073B4C"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `pattern` | 枚举 | `flower_of_life` / `metatron` / `sri_yantra` | `flower_of_life` | 圆阵、中心放射连线或交叠三角形 |
| `rings` | 整数 | 1–12 | 5 | 径向层数和复杂度 |
| `symmetry` | 整数 | 3–24 | 6 | 圆阵/连线的旋转对称数 |
| `scale` | 数值 | 0.1–2 | 0.8 | 整体尺寸 |
| `rotation` | 数值 | -180–180 度 | 0 | 初始角度 |
| `speed` | 数值 | -2–2 | 0.12 | 整体旋转速度，负值反向 |
| `strokeColor` | `#RRGGBB` | 六位十六进制 | `#FFD166` | 几何线条颜色 |
| `backgroundColor` | `#RRGGBB` | 六位十六进制 | `#073B4C` | 背景颜色 |

圆和线的总图元预算最多为 601；构造只使用有限循环，不接受递归规则或任意脚本。

## 5. 表达映射

“更密/更复杂”提高 `rings`，圆阵或梅塔特隆需要更多辐射方向时提高 `symmetry`；“更大/缩小”调整 `scale`；“倾斜”调 `rotation`；“旋转快/反向”调 `speed`；色彩只用直接色值。

## 6. 自然语言例子

- “金色生命之花，缓慢旋转” → `flower_of_life`、金色线条、小幅正 `speed`。
- “更复杂的圆阵” → 增加 `rings` 和 `symmetry`。
- “黑白梅塔特隆结构” → `metatron`、白线深背景。
- “九层交叠三角形” → `sri_yantra`、`rings` 9。
- “图案缩小到画面中心” → 降低 `scale`。
- “静止并顺时针倾斜 30 度” → `rotation` 30、`speed` 0。

## 7. 推荐档位

| 档位 | `rings` | `symmetry` | `scale` |
| --- | ---: | ---: | ---: |
| 简洁 | 1–3 | 3–6 | 0.4–0.8 |
| 均衡 | 4–7 | 6–12 | 0.7–1.1 |
| 复杂 | 8–12 | 12–24 | 0.8–1.5 |

`sri_yantra` 的主要密度由 `rings` 决定，`symmetry` 不改变其固定三角构造。

## 8. 默认值与中性行为

默认值生成五层、六重对称、标准大小的金色生命之花，并以很低速度旋转，构图清晰且不过密。

## 9. 不能处理的内容

不能加载 SVG、字体、纹理、图片或调色板资源；不能输出资源 ID、路径、URL 或宗教文本；不能生成任意用户脚本几何、三维挤出或多效果组合。
