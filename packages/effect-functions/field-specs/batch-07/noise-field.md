# 噪声场 `noise_field`

## 1. 工具作用

生成可平滑动画的二维确定性分形值噪声场，适合云雾、地形高度、流体扰动和抽象纹理。相同的服务端上下文 seed、参数 seed 和时间会得到相同结果。

## 2. 输出要求

模型只能输出一个 JSON 对象，且只能包含 `type` 和 `data`。`type` 必须严格等于 `noise_field`，`data` 只能包含下表字段。不要输出解释、Markdown、资源标识或第二个工具调用。

## 3. 合法 JSON 示例

```json
{"type":"noise_field","data":{"seed":42,"gridSize":32,"scale":3.5,"octaves":5,"persistence":0.55,"speed":0.4,"lowColor":"#102A43","highColor":"#F0F4F8"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `seed` | 整数 | 0–2147483647 | 17 | 用户要求换一种随机纹理时更换；复现时保持不变 |
| `gridSize` | 整数 | 8–64 | 24 | 越大采样越细，计算和输出也越大 |
| `scale` | 数值 | 0.25–12 | 2.5 | 小值形成大块缓变，大值形成细碎纹理 |
| `octaves` | 整数 | 1–6 | 4 | 越高细节层级越多 |
| `persistence` | 数值 | 0.1–0.85 | 0.5 | 控制高频层的保留量 |
| `speed` | 数值 | -4–4 | 0.25 | 0 为静止，负值反向移动 |
| `lowColor` | `#RRGGBB` | 六位十六进制 | `#102A43` | 噪声低值颜色 |
| `highColor` | `#RRGGBB` | 六位十六进制 | `#F0F4F8` | 噪声高值颜色 |

复杂度预算为 `gridSize² × octaves ≤ 24576`，最大字段输出为 4096 个有限数值；超出预算必须拒绝，不能降级为无界采样。

## 5. 表达映射

“更密/更碎”优先提高 `scale`，需要更多层次时再提高 `octaves` 和 `persistence`；“更柔和”降低这三项。“更快/反向”调整 `speed`。“放大纹理”降低 `scale`。“冷色/暖色/高反差”用两个直接颜色值表达，不输出调色板资源。

## 6. 自然语言例子

- “做一层缓慢漂移的蓝灰云雾” → `scale` 1–2、`octaves` 3、低 `speed`。
- “细碎而强烈的湍流” → `scale` 7–10、`octaves` 6、`persistence` 约 0.7。
- “静态地形高度图” → `speed` 0、`scale` 3–5、`octaves` 5。
- “让纹理反向快速流动” → 使用负的高绝对值 `speed`。
- “换一种构图但以后要能复现” → 更换 `seed`，其余参数保持不变。
- “黑白柔和噪点” → 两个颜色设为深灰和浅灰，并降低 `scale`。

## 7. 推荐档位

| 档位 | `gridSize` | `scale` | `octaves` | `persistence` |
| --- | ---: | ---: | ---: | ---: |
| 柔和 | 16–24 | 0.8–2 | 2–3 | 0.3–0.45 |
| 均衡 | 24–40 | 2–5 | 4 | 0.45–0.6 |
| 密集 | 40–64 | 5–10 | 5–6 | 0.6–0.8 |

## 8. 默认值与中性行为

默认值生成中等采样、适度层次、低速漂移的蓝灰噪声，是不偏激的通用背景；未指定字段时使用默认值。

## 9. 不能处理的内容

不能读取图片、视频、音频、纹理文件或调色板资源；不能输出资源 ID、路径、URL、遮罩或导出设置；不能组合其他效果，也不生成可编辑项目结构。
