# L 系统 `l_system`

## 1. 工具作用

用受限的递归重写规则和海龟绘图生成植物、科赫折线或龙形曲线。实现限制展开字符数为 16384、线段数为 8192，避免递归爆炸。

## 2. 输出要求

只输出 `type/data` JSON，`type` 必须是 `l_system`。模型不能自定义规则字符串、输出代码、添加资源字段或调用其他工具。

## 3. 合法 JSON 示例

```json
{"type":"l_system","data":{"pattern":"plant","iterations":4,"angle":25,"step":6,"scale":1,"speed":0.2,"strokeColor":"#2D6A4F"}}
```

## 4. 参数表

| 参数 | 类型 | 范围/选项 | 默认值 | 选择策略 |
| --- | --- | --- | --- | --- |
| `pattern` | 枚举 | `plant` / `koch` / `dragon` | `plant` | 植物分枝、直角雪花折线或龙形曲线 |
| `iterations` | 整数 | 1–6；`plant`/`koch` 最多 5 | 4 | 递归深度和复杂度 |
| `angle` | 数值 | 5–120 度 | 25 | 控制每次转向角度 |
| `step` | 数值 | 0.5–30 | 6 | 单线段基础长度 |
| `scale` | 数值 | 0.1–5 | 1 | 整体几何缩放 |
| `speed` | 数值 | -3–3 | 0.2 | 整体缓慢转动速度 |
| `strokeColor` | `#RRGGBB` | 六位十六进制 | `#2D6A4F` | 线条颜色 |

## 5. 表达映射

“更密/更复杂”提高 `iterations`，不要用 `step` 冒充复杂度；“枝杈张开”提高 `angle`；“更大/更小”调 `scale`，局部线段粗疏感用 `step`；“旋转更快”调 `speed`；颜色用直接十六进制色值。

## 6. 自然语言例子

- “生成四层绿色蕨类分枝” → `plant`、`iterations` 4、绿色线条。
- “更繁密的植物，但保持安全上限” → `plant`、`iterations` 5。
- “直角科赫折线” → `koch`、`angle` 90。
- “红色龙形曲线” → `dragon`、高迭代、红色线条。
- “整体放大两倍但不要增加细节” → `scale` 2，迭代不变。
- “让图案慢慢反向旋转” → 小幅负 `speed`。

## 7. 推荐档位

| 档位 | `iterations` | `step` | `scale` |
| --- | ---: | ---: | ---: |
| 简洁 | 1–2 | 8–16 | 0.6–1.2 |
| 均衡 | 3–4 | 4–8 | 0.8–1.5 |
| 复杂 | 5–6 | 1–5 | 0.5–1.2 |

`plant` 和 `koch` 的复杂档位最多使用 5；只有 `dragon` 可以使用 6。

## 8. 默认值与中性行为

默认值给出四次迭代、自然分枝角度、正常比例和轻微转动的绿色植物，是稳定且不过密的中性行为。

## 9. 不能处理的内容

不能接受任意公理、重写规则、脚本或字体；不能读取外部 SVG、纹理、文件或 URL；不能突破展开/线段上限，也不负责三维挤出或多特效组合。
