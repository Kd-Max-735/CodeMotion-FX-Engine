# 弹性缩放出现 `scale_pop`

让服务端绑定的画面从起始比例弹性缩放到结束比例，形成弹出或收缩落定的动效。对应现有特效 `fx.motion.scalePop`。

需要调用时只输出以下 JSON，不要附加解释或代码块：

```json
{
  "type": "scale_pop",
  "data": {
    "startScale": 0.2,
    "endScale": 1,
    "spring": 0.65,
    "pivot": [0.5, 0.5],
    "duration": 1.2
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `startScale` | 是 | 数字 `0..4`，步长 `0.01`，默认 `0.2` | 小于结束比例为放大出现，大于结束比例为缩小落定 |
| `endScale` | 是 | 数字 `0..4`，步长 `0.01`，默认 `1` | 通常保持 `1` 表示回到原始尺寸 |
| `spring` | 是 | 数字 `0..2`，步长 `0.01`，默认 `0.65` | 控制过渡中的弹性摆动；克制或稳重时降低 |
| `pivot` | 是 | 两元素数组 `[x,y]`，每项 `0..1`、步长 `0.01`，默认 `[0.5,0.5]` | 缩放中心；左上 `[0,0]`，中心 `[0.5,0.5]`，右下 `[1,1]` |
| `duration` | 是 | 数字 `0.05..60` 秒，步长 `0.05`，默认 `1.2` | 弹性缩放完成时间；只控制快慢，不改变缩放幅度 |

## 参数选择优先级

先用 `startScale` 与 `endScale` 定义缩放方向和幅度，再用 `spring` 增加弹性，使用 `duration` 控制完成时间，最后按用户指定位置设置 `pivot`。不要把 `spring` 当成最终缩放比例，也不要用效果明显/轻微替代持续时间。

| 用户提示词 | 应输出的 `data` 参数 |
| --- | --- |
| 从很小弹到正常大小 | `startScale=0.1, endScale=1, spring=0.65, pivot=[0.5,0.5]` |
| 轻微放大出现，稳一点 | `startScale=0.8, endScale=1, spring=0.2, pivot=[0.5,0.5]` |
| 从放大状态缩回正常 | `startScale=1.5, endScale=1, spring=0.35, pivot=[0.5,0.5]` |
| 从左上角弹出 | `startScale=0.2, endScale=1, spring=0.7, pivot=[0,0]` |
| 强烈卡通弹出 | `startScale=0, endScale=1.2, spring=1.4, pivot=[0.5,0.5]` |
| 很快弹入，0.4 秒完成 | `startScale=0.2, endScale=1, spring=0.65, duration=0.4, pivot=[0.5,0.5]` |
| 轻微且缓慢，4 秒完成 | `startScale=0.8, endScale=1, spring=0.2, duration=4, pivot=[0.5,0.5]` |

缩放幅度推荐：轻微 `0.8→1`，中等 `0.5→1`，明显 `0.2→1`，强烈 `0→1.2`。`spring` 推荐为轻微 `0.2`、中等 `0.65`、明显 `1.1`、强烈 `1.6`。`duration` 推荐快速 `0.2..0.8` 秒、标准 `1..2` 秒、缓慢 `3..6` 秒。默认从 `0.2` 弹到 `1`；`startScale=endScale` 且 `spring=0` 是中性设置。

素材由服务端绑定。本工具不处理透明度、位移、三维挤出、镜头推拉或改变素材实际尺寸，也不要生成文件、字体或 URL。

## 服务器输入槽（不进入模型 `data`）

- `source_layer`（必需，`data`，单个）：服务端解析并栅格化的真实主图层。模型不得输出该槽或任何资源身份；缺失时必须停止执行。
