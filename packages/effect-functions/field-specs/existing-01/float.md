# 循环漂浮 `float`

让服务端绑定的画面沿一个或两个轴做连续正弦漂浮，适合悬浮物或轻微呼吸式位移。对应现有特效 `fx.motion.float`。

需要调用时只输出以下 JSON，不要附加解释或代码块：

```json
{
  "type": "float",
  "data": {
    "axis": "y",
    "range": 0.04,
    "frequency": 1,
    "phase": 0
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `axis` | 是 | `x` / `y` / `both`，默认 `y` | 水平、垂直或对角同步漂浮 |
| `range` | 是 | 数字 `0..1` 画布比例，步长 `0.005`，默认 `0.04` | 从中心到峰值的位移幅度 |
| `frequency` | 是 | 数字 `0..20` Hz，步长 `0.1`，默认 `1` | 每秒循环次数；`0` 固定在由相位决定的位置 |
| `phase` | 是 | 数字 `-6.283..6.283` 弧度，步长 `0.01`，默认 `0` | 调整循环起点；约 `1.571` 为四分之一周期 |

## 参数选择优先级

`axis` 决定方向，`range` 决定幅度，`frequency` 决定速度。只有用户要求错开起始节奏或指定初始位置时才调整 `phase`；不要用相位表示速度。

| 用户提示词 | 应输出的 `data` 参数 |
| --- | --- |
| 轻轻上下漂浮 | `axis=y, range=0.025, frequency=0.7, phase=0` |
| 左右缓慢悬浮 | `axis=x, range=0.04, frequency=0.4, phase=0` |
| 斜向循环浮动 | `axis=both, range=0.06, frequency=1, phase=0` |
| 快速小幅浮动 | `axis=y, range=0.02, frequency=3, phase=0` |
| 从最高点开始下落 | `axis=y, range=0.08, frequency=1, phase=1.57` |

`range` 推荐值：轻微 `0.02`，中等 `0.04`，明显 `0.08`，强烈 `0.15`。`frequency` 推荐为舒缓 `0.3`、中等 `1`、明显 `2`、快速 `4`。默认是垂直 `0.04` 幅度、每秒一次；`range=0` 是中性设置。

素材由服务端绑定。本工具不处理一次性划入、随机震动、轨迹跟随、三维悬浮或物理浮力，也不要生成路径或资源字段。
