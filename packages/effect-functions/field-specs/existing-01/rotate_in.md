# 旋转进入 `rotate_in`

让服务端绑定的画面围绕指定支点旋转进入，并可附带运动模糊与额外整圈旋转。对应现有特效 `fx.motion.rotateIn`。

需要调用时只输出以下 JSON，不要附加解释或代码块：

```json
{
  "type": "rotate_in",
  "data": {
    "angle": -90,
    "pivot": [0.5, 0.5],
    "blur": 0.08,
    "turns": 0
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `angle` | 是 | 数字 `-720..720` 度，步长 `1`，默认 `-90` | 起始角度；负值与正值产生相反旋向 |
| `pivot` | 是 | 两元素数组 `[x,y]`，每项 `0..1`、步长 `0.01`，默认 `[0.5,0.5]` | 旋转支点；用户提到角落或边缘时调整 |
| `blur` | 是 | 数字 `0..1`，步长 `0.01`，默认 `0.08` | 旋转初期的附加模糊感；清晰利落时设 `0` |
| `turns` | 是 | 数字 `-4..4` 圈，步长 `0.25`，默认 `0` | 增加完整圈数；符号也影响旋向 |

## 参数选择优先级

实际起始旋转量为 `angle + turns×360`。精确角度优先写入 `angle`；只有用户明确说“多转几圈”才使用 `turns`，避免两者重复累计出过大角度。

当前函数在约一秒的进入窗口内完成旋转，因此旋转速度由这段时间内的总旋转量控制：慢速使用较小的 `angle`，快速使用较大的 `angle`，一圈及以上的高速旋转使用 `turns`。不要用 `blur` 表达速度；它只改变拖影感。若用户同时给出方向和速度，先确定正负方向，再按慢速约 `30°`、中速约 `90°`、快速约 `360°`、很快约 `720°` 选择总旋转量。

| 用户提示词 | 应输出的 `data` 参数 |
| --- | --- |
| 逆时针转 90 度进入 | `angle=-90, pivot=[0.5,0.5], blur=0.08, turns=0` |
| 顺时针半圈进入 | `angle=180, pivot=[0.5,0.5], blur=0.08, turns=0` |
| 从左下角旋入 | `angle=-90, pivot=[0,1], blur=0.06, turns=0` |
| 清晰地转两圈进入 | `angle=0, pivot=[0.5,0.5], blur=0, turns=2` |
| 强烈旋转并带明显拖影感 | `angle=-180, pivot=[0.5,0.5], blur=0.35, turns=-1` |
| 慢速逆时针旋转进入 | `angle=-30, pivot=[0.5,0.5], blur=0.04, turns=0` |
| 快速顺时针旋转进入 | `angle=0, pivot=[0.5,0.5], blur=0.12, turns=1` |
| 很快地逆时针转两圈进入 | `angle=0, pivot=[0.5,0.5], blur=0.18, turns=-2` |

总旋转及对应平均速度推荐：慢速 `30°`，中速 `90°`，较快 `180°`，快速到很快 `360°..720°`。`blur` 推荐为清晰 `0`、轻微 `0.05`、中等 `0.12`、明显 `0.3`。默认从 `-90°` 围绕中心以中速进入；`angle=0, turns=0, blur=0` 是中性设置。

素材由服务端绑定。本工具不处理三维旋转、持续自转、方向模糊滤镜、镜头旋转或路径运动，也不要输出资源参数。

## 服务器输入槽（不进入模型 `data`）

- `source_layer`（必需，`data`，单个）：服务端解析并栅格化的真实主图层。模型不得输出该槽或任何资源身份；缺失时必须停止执行。
