# 能量脉冲 `energy_pulse`

以指定中心生成随进度扩张的多层径向能量环，控制半径、衰减宽度和环数。对应现有特效 `fx.light.energyPulse`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "energy_pulse",
  "data": {
    "center": [0.5, 0.5],
    "radius": 0.34,
    "falloff": 0.2,
    "rings": 4
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `center` | 是 | 两元素数字数组 `[x,y]`；各 `0..1`，步长 `0.01` | 左上 `[0,0]`，中心 `[0.5,0.5]`，右下 `[1,1]` |
| `radius` | 是 | 数字 `0..2`，步长 `0.01`，相对画布 | 越大脉冲环扩张范围越大 |
| `falloff` | 是 | 数字 `0.001..1`，步长 `0.005` | 越大环带越宽、衰减越柔和 |
| `rings` | 是 | 数字 `1..32`，步长 `1` | 控制环层数量，按次数词选择整数 |

## 参数选择规则

- 位置词先映射 `center`；未指定时使用画面中心。
- “小范围/冲出画面”优先调 `radius`；`radius>1` 可让范围超出归一化画布。
- “锐利冲击波”降低 `falloff`；“宽厚、柔和能量带”提高它。
- “单环/多层密集”直接映射 `rings`；不要用高 `rings` 代替更宽的衰减。
- 当前动画阶段由服务端时间驱动；本工具 Schema 没有速度或 `progress` 字段，不要生成它们。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 从中心发出一个锐利小脉冲 | `{"center":[0.5,0.5],"radius":0.18,"falloff":0.04,"rings":1}` |
| 默认的四层能量环 | `{"center":[0.5,0.5],"radius":0.34,"falloff":0.2,"rings":4}` |
| 从左下角发出六层柔和脉冲 | `{"center":[0.2,0.8],"radius":0.6,"falloff":0.4,"rings":6}` |
| 右上角密集的十二层冲击波 | `{"center":[0.8,0.2],"radius":0.8,"falloff":0.12,"rings":12}` |
| 超出画面的宽厚双环 | `{"center":[0.5,0.5],"radius":1.4,"falloff":0.55,"rings":2}` |

## 推荐档位

| 程度 | `radius` | `falloff` | `rings` |
| --- | ---: | ---: | ---: |
| 小而锐利 | `0.18` | `0.04` | `1..2` |
| 标准 | `0.34` | `0.2` | `4` |
| 大而密集 | `0.8` | `0.4` | `8..12` |

默认值为 `center=[0.5,0.5]`、`radius=0.34`、`falloff=0.2`、`rings=4`。中心坐标是位置中性值；`radius=0` 是零基础半径，`falloff=0.001` 是最锐边界，`rings=1` 是单环。最大 `radius=2`、`falloff=1`、`rings=32` 仅用于极端范围、极宽或极密效果。

源画面和动画时间由服务端绑定，不生成图片、视频、纹理、资源 ID、路径或 URL。本工具不控制播放速度，不用于镜头鬼影、扫描光束、霓虹轮廓或物理冲击波模拟。
