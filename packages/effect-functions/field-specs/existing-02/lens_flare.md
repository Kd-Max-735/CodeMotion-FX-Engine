# 镜头光晕 `lens_flare`

围绕指定归一化光源位置生成柔和主光源、少量离散镜片鬼影、克制水平散射和色散。对应现有特效 `fx.light.lensFlare`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "lens_flare",
  "data": {
    "source": [0.72, 0.28],
    "ghosts": 2,
    "streak": 0.18,
    "chromatic": 0.03
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `source` | 是 | 两元素数字数组 `[x,y]`；各 `0..1`，步长 `0.01` | 左上 `[0,0]`，中心 `[0.5,0.5]`，右下 `[1,1]` |
| `ghosts` | 是 | 整数 `0..8` | 控制离散镜片鬼影数量；`0` 可完全关闭 |
| `streak` | 是 | 数字 `0..1`，步长 `0.01` | 越大水平散射越明显 |
| `chromatic` | 是 | 数字 `0..0.5`，步长 `0.01` | 越大综合色散越明显 |

## 参数选择规则

- 位置词先映射 `source`：左/中/右约为 `0.2/0.5/0.8`，上/中/下约为 `0.2/0.5/0.8`。
- 用户给出鬼影数量时直接使用整数；“少量/丰富”可用 `2..3` / `7..10`。`0` 仅表示最低鬼影设置，不承诺完全移除运行时的一层光学变化。
- “横向拉丝、电影镜头条纹”优先提高 `streak`；“彩边、棱镜色散”优先提高 `chromatic`。
- 鬼影复杂度由 `ghosts` 决定，条纹长度由 `streak` 决定，两者不要重复加码。
- 位置优先级最高；未提及光学细节时保持默认鬼影、条纹和色散。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 左上角放一个克制光晕，两个鬼影 | `{"source":[0.2,0.2],"ghosts":2,"streak":0.2,"chromatic":0.03}` |
| 使用默认镜头光晕 | `{"source":[0.72,0.28],"ghosts":5,"streak":0.45,"chromatic":0.08}` |
| 右下角，八个鬼影，电影感横向光条 | `{"source":[0.82,0.78],"ghosts":8,"streak":1.1,"chromatic":0.12}` |
| 光源居中，把鬼影降到最低，只保留轻微条纹 | `{"source":[0.5,0.5],"ghosts":0,"streak":0.25,"chromatic":0}` |
| 右上角强烈综合色散 | `{"source":[0.8,0.2],"ghosts":6,"streak":0.6,"chromatic":0.65}` |

## 推荐档位

| 程度 | `ghosts` | `streak` | `chromatic` |
| --- | ---: | ---: | ---: |
| 克制 | `0` | `0.08` | `0.01` |
| 标准 | `2` | `0.18` | `0.03` |
| 强烈 | `6` | `0.65` | `0.3` |

默认值为 `source=[0.72,0.28]`、`ghosts=2`、`streak=0.18`、`chromatic=0.03`。`ghosts=0` 完全关闭鬼影，`streak=0`、`chromatic=0` 分别关闭条纹强度和色散；`source=[0.5,0.5]` 是位置中性值。

源画面由服务端绑定，不生成图片、镜头贴图、纹理、资源 ID、路径或 URL。本工具不是物理镜头模拟，不用于霓虹描边、扫描光带、能量脉冲或全局曝光调整。
