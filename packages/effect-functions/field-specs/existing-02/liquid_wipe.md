# 液态擦除 `liquid_wipe`

使用确定性噪声边界在服务端绑定的 A、B 两路画面之间完成液态擦除，并可添加边缘光。对应现有特效 `fx.transition.liquidWipe`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "liquid_wipe",
  "data": {
    "noise": 0.16,
    "viscosity": 0.6,
    "edgeGlow": 0.25,
    "progress": 1
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `noise` | 是 | 数字 `0..1`，步长 `0.01` | 越大液态边界位移越不规则 |
| `viscosity` | 是 | 数字 `0..1`，步长 `0.01` | 越大边界变化越缓、形态越黏稠；越小细碎变化越多 |
| `edgeGlow` | 是 | 数字 `0..2`，步长 `0.01` | 控制转场边缘附加光强度 |
| `progress` | 是 | 数字 `0..1`，步长 `0.01` | 控制末态擦除范围；正常完整转场必须使用 `1` |

## 参数选择规则

- “边界起伏大、随机破边”提高 `noise`；“轮廓克制”降低它。
- “黏稠、缓慢流体形态”提高 `viscosity`；“水花、细碎活跃”降低它。
- “发光边缘”提高 `edgeGlow`；“不发光”使用 `0`。
- 不规则幅度由 `noise` 优先决定，细碎频率和软化感再由 `viscosity` 决定；不要用二者重复表达强度。
- “只转到几成”才降低 `progress`；普通擦除、完整擦除和未提末态范围时必须使用 `1`。速度由外部时间轴控制，本 Schema 没有速度字段。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 克制黏稠的液态边缘，不发光，转到三成 | `{"noise":0.08,"viscosity":0.85,"edgeGlow":0,"progress":0.3}` |
| 默认液态擦除并完整显示目标图 | `{"noise":0.16,"viscosity":0.6,"edgeGlow":0.25,"progress":1}` |
| 像水花一样细碎，蓝白边缘光明显，完整转场 | `{"noise":0.55,"viscosity":0.2,"edgeGlow":0.8,"progress":1}` |
| 黏稠而起伏强烈，快转完了 | `{"noise":0.65,"viscosity":0.9,"edgeGlow":0.35,"progress":0.9}` |
| 保持默认质感并完成转场 | `{"noise":0.16,"viscosity":0.6,"edgeGlow":0.25,"progress":1}` |

## 推荐档位

| 表达 | `noise` | `viscosity` | `edgeGlow` |
| --- | ---: | ---: | ---: |
| 克制黏稠 | `0.08` | `0.85` | `0..0.15` |
| 自然液态 | `0.16` | `0.6` | `0.25` |
| 活跃水花 | `0.5` | `0.2` | `0.5..0.8` |

默认值为 `noise=0.16`、`viscosity=0.6`、`edgeGlow=0.25`、`progress=1`。`noise=0` 是平直边界，`edgeGlow=0` 关闭边缘光，`progress=0/1` 是 A/B 两端；`viscosity=0/1` 是最活跃与最黏稠边界。渲染到 `progress=1` 后必须保持 B，不得回跳到 A。`noise=1`、`edgeGlow=2` 仅用于明确的极端风格。

A、B 两路素材由服务端绑定，不生成第二路视频、流体贴图、纹理、资源 ID、路径或 URL。本工具是视觉近似，不做物理流体模拟，也不用于线性擦除、径向扇形或像素块溶解。
