# 遮罩显现 `mask_reveal`

使用服务端绑定的真实遮罩控制源画面的显现阶段、羽化和反相。对应现有特效 `fx.composite.maskReveal`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "mask_reveal",
  "data": {
    "progress": 0.5,
    "feather": 0.04,
    "invert": false
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `progress` | 是 | 数字 `0..1`，步长 `0.01` | 控制遮罩阈值阶段；越大显现推进越后 |
| `feather` | 是 | 数字 `0..0.5`，步长 `0.005` | `0` 为硬边，越大遮罩边缘越柔和 |
| `invert` | 是 | 布尔值 | 正常遮罩 `false`；反相、显示相反区域用 `true` |

## 参数选择规则

- “显现到几成”直接映射 `progress`；一半使用 `0.5`，完成使用 `1`。
- “硬边、清晰轮廓”降低 `feather`；“柔和、羽化、渐隐边缘”提高它。
- “反相遮罩、显示外部、黑白区域对调”使用 `invert=true`。
- 范围取反优先由 `invert` 决定，边缘软硬由 `feather` 决定，不要用高羽化模拟反相。
- 用户未提到反相时必须保持 `false`；未描述边缘时使用默认 `0.04`。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 硬边遮罩显现到三成 | `{"progress":0.3,"feather":0,"invert":false}` |
| 默认遮罩显现到一半 | `{"progress":0.5,"feather":0.04,"invert":false}` |
| 柔和羽化地显现到八成 | `{"progress":0.8,"feather":0.15,"invert":false}` |
| 反相遮罩，显示到六成 | `{"progress":0.6,"feather":0.04,"invert":true}` |
| 反相并使用宽羽化，全部显现 | `{"progress":1,"feather":0.3,"invert":true}` |

## 推荐档位

| 边缘 | `feather` | 阶段 | `progress` |
| --- | ---: | --- | ---: |
| 硬边 | `0` | 初段 | `0.1..0.25` |
| 轻微羽化 | `0.04` | 一半 | `0.5` |
| 柔和 | `0.12..0.18` | 近完成 | `0.8..0.9` |
| 极柔 | `0.3..0.5` | 完成 | `1` |

默认值为 `progress=0.5`、`feather=0.04`、`invert=false`。`feather=0` 是硬边中性值，`invert=false` 是正常遮罩；`progress=0/1` 是阶段边界，`feather=0.5` 是最大羽化边界。

遮罩与源画面由服务端绑定，不生成 `mask`、遮罩 ID、图片、视频、路径或 URL。本工具不创建或编辑遮罩几何，不用于轨道遮罩模式选择、图层混合、置换扭曲或多遮罩布尔组合。
