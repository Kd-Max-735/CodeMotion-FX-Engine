# 霓虹发光 `neon_glow`

沿源画面的 Alpha 或亮度边缘添加线性色彩空间霓虹光晕，控制颜色、扩散范围、亮度与闪烁。对应现有特效 `fx.light.neonGlow`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "neon_glow",
  "data": {
    "color": "#42C8FF",
    "radius": 0.08,
    "intensity": 1.8,
    "flicker": 0.12
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `color` | 是 | 最长 16 字符的字符串；优先使用 `#RRGGBB` | 按用户指定色选择；未指定用默认青蓝色 |
| `radius` | 是 | 数字 `0..0.5`，步长 `0.005`，相对画布 | 越大光晕扩散越宽 |
| `intensity` | 是 | 数字 `0..8`，步长 `0.05` | 越大霓虹越亮 |
| `flicker` | 是 | 数字 `0..1`，步长 `0.01` | 越大随机闪烁越明显 |

## 参数选择规则

- “贴边、细光”降低 `radius`；“柔散、外扩”提高它。
- “微亮/强烈刺眼”主要映射到 `intensity`，不要用半径代替亮度。
- “稳定常亮”使用 `flicker=0`；“轻微电流感”约 `0.1..0.25`；“故障闪烁”可提高到 `0.5..0.8`。
- 用户指定颜色时输出标准六位十六进制；颜色名称应转换为对应 `#RRGGBB`。
- 优先级为颜色语义、亮度、范围、闪烁；未提及的字段保持默认值。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 稳定的细蓝色霓虹，亮度克制 | `{"color":"#3388FF","radius":0.03,"intensity":1,"flicker":0}` |
| 默认青蓝光，稍微闪一下 | `{"color":"#42C8FF","radius":0.08,"intensity":1.8,"flicker":0.2}` |
| 宽而明亮的粉色霓虹 | `{"color":"#FF4FB8","radius":0.18,"intensity":3.5,"flicker":0.08}` |
| 强烈绿色故障霓虹，闪烁明显 | `{"color":"#39FF88","radius":0.12,"intensity":5,"flicker":0.65}` |
| 关闭光效但保留合法参数 | `{"color":"#42C8FF","radius":0.08,"intensity":0,"flicker":0}` |

## 推荐档位

| 程度 | `radius` | `intensity` | `flicker` |
| --- | ---: | ---: | ---: |
| 轻微稳定 | `0.03` | `0.8` | `0` |
| 标准霓虹 | `0.08` | `1.8` | `0.12` |
| 强烈闪烁 | `0.18` | `4` | `0.6` |

默认值为 `color=#42C8FF`、`radius=0.08`、`intensity=1.8`、`flicker=0.12`。`intensity=0` 是关闭发光的中性边界，`flicker=0` 为稳定常亮，`radius=0` 为无扩散范围；最大值 `0.5/8/1` 仅用于明确的极端宽光、超亮或强闪烁。

源图片、文字或图形由服务端绑定，不生成图片、字体、纹理、资源 ID、路径或 URL。本工具不改变源几何，不生成扫描光束、镜头鬼影、能量环或通用调色。
