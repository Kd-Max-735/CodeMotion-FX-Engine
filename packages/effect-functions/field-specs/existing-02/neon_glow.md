# 霓虹发光 `neon_glow`

对上传图片中用户指定的可见目标添加霓虹轮廓和柔和外扩光晕。Ark 必须检查随本工具附带的图片，把中文目标描述翻译成简短、具体的英文 SAM3.1 目标短语；服务端再从 `source_image` 派生锁定的 `subject_mask`，并在保留原图的前提下只对该对象渲染。对应现有特效 `fx.light.neonGlow`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "neon_glow",
  "data": {
    "color": "#42C8FF",
    "radius": 0.08,
    "intensity": 1.8,
    "flicker": 0.12,
    "target": "main subject"
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `color` | 是 | 最长 16 字符的字符串；优先使用 `#RRGGBB` | 按用户指定色选择；未指定用默认青蓝色 |
| `radius` | 是 | 数字 `0..0.5`，步长 `0.005`，相对画布 | 越大光晕扩散越宽 |
| `intensity` | 是 | 数字 `0..8`，步长 `0.05` | 越大霓虹越亮 |
| `flicker` | 是 | 数字 `0..1`，步长 `0.01` | 越大随机闪烁越明显 |
| `target` | 是 | 1..80 个字符的英文短语 | 根据图片和用户描述输出可被 SAM3.1 分割的具体可见对象，例如 `car`、`car headlights`；不得输出中文、坐标或资源信息 |

## 参数选择规则

- “贴边、细光”降低 `radius`；“柔散、外扩”提高它。
- “微亮/强烈刺眼”主要映射到 `intensity`，不要用半径代替亮度。
- “稳定常亮”使用 `flicker=0`；“轻微电流感”约 `0.1..0.25`；“故障闪烁”可提高到 `0.5..0.8`。
- 用户指定颜色时输出标准六位十六进制；颜色名称应转换为对应 `#RRGGBB`。
- 必须同时理解图片和自然语言。“照片中的汽车发光”使用 `target="car"`，不能选择整幅图片。
- `target` 只描述一个可见对象或部件；将中文目标翻译成简短英文，不臆造图片中不存在的目标。
- 优先级为颜色语义、亮度、范围、闪烁；未提及的字段保持默认值。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 让照片里的汽车稳定地发出蓝色霓虹 | `{"color":"#3388FF","radius":0.03,"intensity":1,"flicker":0,"target":"car"}` |
| 让汽车前灯发出较强粉色霓虹并轻微闪烁 | `{"color":"#FF4FB8","radius":0.18,"intensity":3.5,"flicker":0.18,"target":"car headlights"}` |
| 强烈绿色故障霓虹，作用于人物外套 | `{"color":"#39FF88","radius":0.12,"intensity":5,"flicker":0.65,"target":"person's jacket"}` |
| 关闭汽车光效但保留合法参数 | `{"color":"#42C8FF","radius":0.08,"intensity":0,"flicker":0,"target":"car"}` |

## 推荐档位

| 程度 | `radius` | `intensity` | `flicker` |
| --- | ---: | ---: | ---: |
| 轻微稳定 | `0.03` | `0.8` | `0` |
| 标准霓虹 | `0.08` | `1.8` | `0.12` |
| 强烈闪烁 | `0.18` | `4` | `0.6` |

默认值为 `color=#42C8FF`、`radius=0.08`、`intensity=1.8`、`flicker=0.12`、`target=main subject`。`intensity=0` 是关闭发光的中性边界，`flicker=0` 为稳定常亮，`radius=0` 为无扩散范围；最大值 `0.5/8/1` 仅用于明确的极端宽光、超亮或强闪烁。

前端要求用户上传一张图片到 `source_image`。前端不要求第二次上传：`subject_mask` 由服务端用同一张授权图片和 `target` 调用 SAM3.1 派生并锁定。模型不生成 mask、图片、资源 ID、路径或 URL，Tool Call JSON 中也不得出现这些内容。本工具不改变源几何，不生成扫描光束、镜头鬼影、能量环或通用调色。
