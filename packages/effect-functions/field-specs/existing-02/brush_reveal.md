# 笔刷显现 `brush_reveal`

使用服务端绑定的真实笔刷覆盖逐步显现画面，控制笔刷尺寸、边缘粗糙度和显现进度。对应现有特效 `fx.draw.brushReveal`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "brush_reveal",
  "data": {
    "size": 0.12,
    "roughness": 0.35,
    "progress": 0.5
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `size` | 是 | 数字 `0.005..1`，步长 `0.005`，相对画布 | 越大笔刷覆盖越宽 |
| `roughness` | 是 | 数字 `0..1`，步长 `0.01` | 越大边缘越破碎、手工感越强 |
| `progress` | 是 | 数字 `0..1`，步长 `0.01` | `0` 未显现，`1` 完全显现 |

## 参数选择规则

- “细笔刷、窄刷痕”降低 `size`；“大刷子、宽幅涂抹”提高 `size`。
- “干净、平滑边缘”降低 `roughness`；“干刷、毛糙、破边”提高它。
- 用户给出百分比时，将百分比除以 `100` 映射到 `progress`。
- 宽度由 `size` 优先控制，边缘质感由 `roughness` 控制；不要用高粗糙度代替大尺寸。
- 未明确强度时采用默认笔刷尺寸和粗糙度，只按描述调整 `progress`。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 用细而干净的笔刷显现三成 | `{"size":0.04,"roughness":0.1,"progress":0.3}` |
| 大刷子粗糙地刷到一半 | `{"size":0.3,"roughness":0.7,"progress":0.5}` |
| 宽幅平滑刷过，完成八成 | `{"size":0.45,"roughness":0.08,"progress":0.8}` |
| 很细的干刷，只露出开头 | `{"size":0.02,"roughness":0.85,"progress":0.1}` |
| 默认笔触，全部显现 | `{"size":0.12,"roughness":0.35,"progress":1}` |

## 推荐档位

| 表达 | `size` | `roughness` | `progress` |
| --- | ---: | ---: | ---: |
| 细/平滑/初段 | `0.04` | `0.1` | `0.2` |
| 中等/自然/半程 | `0.12` | `0.35` | `0.5` |
| 宽/粗糙/近完成 | `0.35` | `0.75` | `0.9` |

默认值为 `size=0.12`、`roughness=0.35`、`progress=0.5`。`roughness=0` 是最平滑边缘，`progress=0` 与 `1` 是未显现和完全显现；`size=1`、`roughness=1` 是最大支持边界，通常只用于明确的超宽或极粗糙效果。

笔刷纹理与覆盖数据由服务端绑定，不生成 `brushTexture`、纹理、资源 ID、路径或 URL。本工具不创建新笔刷素材，不改变源画面内容，也不用于手写笔压、墨水扩散或粉笔颗粒。

## 服务器输入槽（不进入模型 `data`）

- `vector_source`（必需，`data`，单个）：提示词直接生成模式下由服务器创建并栅格化确定性的默认矢量图形，不要求用户上传素材。图形身份不进入模型参数。
- `brush_texture`（必需，`texture`，单个）：服务器为本次请求创建确定性的默认笔刷覆盖，不要求用户上传笔刷素材。纹理身份只在服务器内部绑定。
