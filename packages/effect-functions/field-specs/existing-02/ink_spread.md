# 墨水扩散 `ink_spread`

模拟墨水从中心扩散、渗入介质并形成不规则边缘的过程。对应现有特效 `fx.draw.inkSpread`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "ink_spread",
  "data": {
    "diffusion": 0.55,
    "edgeNoise": 0.2,
    "absorption": 0.65,
    "progress": 0.5
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `diffusion` | 是 | 数字 `0..1`，步长 `0.01` | 越大扩散范围和扩散感越强 |
| `edgeNoise` | 是 | 数字 `0..1`，步长 `0.01` | 越大扩散边缘越不规则 |
| `absorption` | 是 | 数字 `0..1`，步长 `0.01` | 越大渗透感、覆盖浓度和软边范围越强 |
| `progress` | 是 | 数字 `0..1`，步长 `0.01` | 控制扩散阶段，`0` 起始，`1` 完成 |

## 参数选择规则

- “扩得快/范围大”提高 `diffusion`；“收敛、小范围”降低它。
- “边缘平整”降低 `edgeNoise`；“有机、毛边、随机”提高它。
- “纸张吸墨、渗透明显、墨色更厚”提高 `absorption`；“浮在表面、干脆”降低它。
- 范围优先由 `diffusion` 选择，轮廓随机度再由 `edgeNoise` 修饰，渗化厚重感最后由 `absorption` 调节。
- 完成多少只使用 `progress`，不要通过同时提高扩散和吸收来代替进度。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 小范围平滑扩散到三成 | `{"diffusion":0.25,"edgeNoise":0.05,"absorption":0.4,"progress":0.3}` |
| 自然墨迹扩散到一半 | `{"diffusion":0.55,"edgeNoise":0.2,"absorption":0.65,"progress":0.5}` |
| 湿纸上强烈渗开，边缘很乱 | `{"diffusion":0.85,"edgeNoise":0.75,"absorption":0.9,"progress":0.8}` |
| 墨水几乎不渗，只扩散一点 | `{"diffusion":0.2,"edgeNoise":0.1,"absorption":0.1,"progress":0.4}` |
| 保持默认质感并完全扩散 | `{"diffusion":0.55,"edgeNoise":0.2,"absorption":0.65,"progress":1}` |

## 推荐档位

| 程度 | `diffusion` | `edgeNoise` | `absorption` |
| --- | ---: | ---: | ---: |
| 克制 | `0.25` | `0.08` | `0.3` |
| 自然 | `0.55` | `0.2` | `0.65` |
| 强烈 | `0.85` | `0.7` | `0.9` |

默认值为 `diffusion=0.55`、`edgeNoise=0.2`、`absorption=0.65`、`progress=0.5`，也是中等自然档。每个字段的 `0` 是最小边界，`1` 是最大边界；除明确要求完全平整、完全无吸收或极端扩散外，避免同时使用多个极端值。

源图形由服务端绑定。本工具不生成纸张纹理、遮罩、图片或资源标识，不接受路径或 URL。它不用于沿路径手写、笔刷遮罩显现、粉笔描边、液态转场或物理精度的流体模拟。

## 服务器输入槽（不进入模型 `data`）

- `vector_source`（必需，`data`，单个）：服务端解析的真实图形或矢量路径及其栅格化结果。图片上传模式下，服务器从已授权图片提取画布内轮廓代理，使墨水从图形范围内扩散；图片身份不进入模型参数。缺失时必须停止执行。
