# 运动模糊 `motion_blur`

按照二维速度向量和快门角进行时间方向采样，模拟运动物体的拖影。对应现有特效 `fx.post.motionBlur`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "motion_blur",
  "data": {
    "shutterAngle": 180,
    "samples": 8,
    "velocity": [0.08, 0],
    "centered": true
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `shutterAngle` | 是 | 数字 `0..720` 度，步长 `1` | 越大曝光时间范围和拖影长度越强 |
| `samples` | 是 | 数字 `1..32`，步长 `1` | 请求的采样上限；越多拖影越平滑、开销越高，实际值受服务端质量档限制 |
| `velocity` | 是 | 两元素数字数组 `[x,y]`；各 `-2..2`，步长 `0.01`，相对画布 | `x` 正向向右，`y` 正向向下；绝对值决定速度 |
| `centered` | 是 | 布尔值 | `true` 在当前帧前后对称采样；`false` 为单向拖尾 |

## 参数选择规则

- 先把方向和速度映射到 `velocity`：右 `[+,0]`、左 `[-,0]`、下 `[0,+]`、上 `[0,-]`，斜向同时设置两轴。
- 拖影强弱由速度绝对值与 `shutterAngle` 共同决定；用户只说“加强拖影”时优先提高快门角，保留已知速度方向。
- “居中、前后均匀”选 `centered=true`；“尾巴拖在身后、单向残影”选 `false`。
- “更平滑”提高 `samples`，不改变速度或快门角；实际采样仍由服务端质量档封顶。
- 没有方向信息时使用默认 `[0.08,0]`，不要根据画面内容自行分析运动。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 向右轻微运动模糊，前后均匀 | `{"shutterAngle":90,"samples":6,"velocity":[0.04,0],"centered":true}` |
| 默认快门运动模糊 | `{"shutterAngle":180,"samples":8,"velocity":[0.08,0],"centered":true}` |
| 快速向左移动，拖尾留在身后 | `{"shutterAngle":240,"samples":12,"velocity":[-0.18,0],"centered":false}` |
| 向右上高速运动，拖影要平滑 | `{"shutterAngle":360,"samples":18,"velocity":[0.22,-0.16],"centered":true}` |
| 关闭运动模糊 | `{"shutterAngle":0,"samples":1,"velocity":[0,0],"centered":true}` |

## 推荐档位

| 程度 | `shutterAngle` | `velocity` 单轴绝对值 | `samples` |
| --- | ---: | ---: | ---: |
| 轻微 | `60..90` | `0.02..0.05` | `4..6` |
| 中等 | `180` | `0.08` | `8` |
| 明显 | `240..360` | `0.15..0.3` | `12..18` |
| 极强 | `540..720` | `0.5..1` | `20..32` |

默认值为 `shutterAngle=180`、`samples=8`、`velocity=[0.08,0]`、`centered=true`。`shutterAngle=0` 或 `velocity=[0,0]` 可形成无拖影的中性边界；`samples=1` 是最低采样。最大快门角、速度和采样属于极端设置，不要同时使用，除非用户明确要求夸张效果。

源画面和实际素材由服务端绑定，不生成视频、运动向量资源、资源 ID、路径或 URL。本工具不分析光流，不用于高斯柔化、固定角度方向模糊、径向模糊或物理相机仿真。
