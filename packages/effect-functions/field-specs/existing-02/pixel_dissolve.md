# 像素溶解 `pixel_dissolve`

把服务端绑定的 A、B 两路画面划分为像素块，并按随机、线性或径向顺序确定性溶解。对应现有特效 `fx.transition.pixelDissolve`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "pixel_dissolve",
  "data": {
    "grid": 20,
    "order": "random",
    "seed": 1,
    "progress": 0.5
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `grid` | 是 | 数字 `2..128`，步长 `1`，网格单元数 | 越大块越细密，越小块越粗大 |
| `order` | 是 | `random` / `linear` / `radial` | 随机散开、横向顺序或从中心径向推进 |
| `seed` | 是 | 数字 `0..100000`，步长 `1` | 只改变 `random` 排列；相同种子可复现 |
| `progress` | 是 | 数字 `0..1`，步长 `0.01` | `0` 完全为 A，`1` 完全为 B |

## 参数选择规则

- “大像素块”降低 `grid`；“细碎像素”提高 `grid`。`grid` 是每轴网格密度，不是像素尺寸。
- “随机溶解”选 `random`；“从一侧依次”选 `linear`；“从中心向外”选 `radial`。
- 只有用户要求更换随机图案或给出种子时才修改 `seed`；`linear` 和 `radial` 下保留默认种子即可。
- 块大小由 `grid` 决定，空间顺序由 `order` 决定，随机变体由 `seed` 决定。
- “完成多少”只映射 `progress`，不通过提高网格密度模拟进度。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 大块随机溶解到三成，种子 42 | `{"grid":8,"order":"random","seed":42,"progress":0.3}` |
| 默认像素溶解到一半 | `{"grid":20,"order":"random","seed":1,"progress":0.5}` |
| 细碎像素从一侧依次切换 | `{"grid":64,"order":"linear","seed":1,"progress":0.6}` |
| 从中心径向溶解，块稍大 | `{"grid":12,"order":"radial","seed":1,"progress":0.75}` |
| 使用种子 9001 的随机图案并完成 | `{"grid":20,"order":"random","seed":9001,"progress":1}` |

## 推荐档位

| 块大小 | `grid` | 阶段 | `progress` |
| --- | ---: | --- | ---: |
| 粗大 | `6..10` | 开始 | `0.1..0.25` |
| 中等 | `20` | 一半 | `0.5` |
| 细密 | `48..64` | 快结束 | `0.75..0.9` |
| 极细 | `96..128` | 完成 | `1` |

默认值为 `grid=20`、`order=random`、`seed=1`、`progress=0.5`。`progress=0/1` 是 A/B 两端，`grid=2` 是最粗网格，`grid=128` 是最细网格；种子没有视觉强弱意义，`0` 和 `100000` 只是合法边界。

A、B 两路素材由服务端绑定，不生成第二路视频、纹理、资源 ID、路径或 URL。本工具不创建素材，不用于液态边缘、柔和线性擦除、径向扇形擦除或粒子物理消散。
