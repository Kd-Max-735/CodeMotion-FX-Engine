# 径向模糊 `radial_blur`

围绕指定中心生成向外缩放或绕中心旋转的径向模糊。对应现有特效 `fx.post.radialBlur`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "radial_blur",
  "data": {
    "center": [0.5, 0.5],
    "strength": 0.16,
    "mode": "zoom",
    "samples": 8
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `center` | 是 | 两元素数字数组 `[x,y]`；各 `0..1`，步长 `0.01` | 左上 `[0,0]`，中心 `[0.5,0.5]`，右下 `[1,1]` |
| `strength` | 是 | 数字 `0..2`，步长 `0.01` | 模糊强弱的首选参数 |
| `mode` | 是 | `zoom` / `spin` | 向中心缩放拖影选 `zoom`，绕中心旋转拖影选 `spin` |
| `samples` | 是 | 数字 `1..32`，步长 `1` | 请求的采样上限；越多越平滑、开销越高，实际值受服务端质量档限制 |

## 参数选择规则

- 先判断模式：“冲向中心、速度隧道、缩放”选 `zoom`；“旋转、漩涡式拖影”选 `spin`。
- 位置词映射到 `center`；未指定时使用 `[0.5,0.5]`。
- 强弱由 `strength` 决定；质量和平滑度由 `samples` 决定，不用高采样代替强度。实际采样仍由服务端质量档封顶。
- 轻微效果优先 `strength=0.05..0.1`；明显效果 `0.2..0.4`；超过 `0.6` 应有明确的强烈要求。
- 用户只要求“径向模糊”而未说旋转时使用默认 `zoom`。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 从画面中心轻微向外缩放模糊 | `{"center":[0.5,0.5],"strength":0.08,"mode":"zoom","samples":6}` |
| 默认径向缩放模糊 | `{"center":[0.5,0.5],"strength":0.16,"mode":"zoom","samples":8}` |
| 围绕左上方旋转模糊 | `{"center":[0.2,0.2],"strength":0.22,"mode":"spin","samples":10}` |
| 右侧中心的强烈速度隧道效果 | `{"center":[0.8,0.5],"strength":0.5,"mode":"zoom","samples":16}` |
| 关闭径向模糊 | `{"center":[0.5,0.5],"strength":0,"mode":"zoom","samples":1}` |

## 推荐档位

| 程度 | `strength` | `samples` |
| --- | ---: | ---: |
| 轻微 | `0.05..0.1` | `4..6` |
| 中等 | `0.16` | `8` |
| 明显 | `0.25..0.4` | `10..16` |
| 极强 | `0.6..1` | `16..24` |

默认值为 `center=[0.5,0.5]`、`strength=0.16`、`mode=zoom`、`samples=8`。`strength=0` 是关闭模糊的中性值，中心坐标是位置中性值，`samples=1` 是最低采样。`strength=2`、`samples=32` 是极端边界，通常不要同时取最大值。

源画面由服务端绑定，不生成图片、视频、资源 ID、路径或 URL。本工具不用于普通高斯柔化、单一方向模糊、真实速度矢量快门模糊、镜头畸变或景深。
