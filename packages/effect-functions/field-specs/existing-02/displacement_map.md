# 置换贴图 `displacement_map`

使用服务端绑定的置换图通道扭曲源画面的采样坐标，分别控制水平和垂直位移。对应现有特效 `fx.composite.displacementMap`。

只输出 JSON，不附加解释或代码块：

```json
{
  "type": "displacement_map",
  "data": {
    "xAmount": 0.05,
    "yAmount": 0.05,
    "channel": "luma"
  }
}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `xAmount` | 是 | 数字 `-1..1`，步长 `0.005`，相对画布 | 绝对值控制水平位移强度，正负号反转通道映射极性 |
| `yAmount` | 是 | 数字 `-1..1`，步长 `0.005`，相对画布 | 绝对值控制垂直位移强度，正负号反转通道映射极性 |
| `channel` | 是 | `red` / `green` / `blue` / `alpha` / `luma` | 按用户指定的置换信息通道选择；未指定用亮度 |

## 参数选择规则

- “水平扭曲”主要调整 `xAmount` 并将 `yAmount` 设为 `0`；“垂直扭曲”反之；“二维扭曲”同时设置。
- “反向”只翻转对应轴的通道映射极性，不改变绝对强度；置换图低于和高于中点的区域仍会向相反方向采样。
- “轻微/明显/强烈”映射到各轴绝对值；常用范围 `0.02..0.2`，超过 `0.3` 应有明确强烈要求。
- 用户明确红、绿、蓝、Alpha 或亮度通道时直接选择对应枚举；一般灰度置换图使用 `luma`。
- 先确定轴向，再确定强度和符号，最后选择通道；不要通过换通道表达方向。

## 自然语言示例

| 用户表达 | `data` 参数结果 |
| --- | --- |
| 用亮度做轻微二维置换 | `{"xAmount":0.03,"yAmount":0.03,"channel":"luma"}` |
| 只向水平方向明显扭曲 | `{"xAmount":0.12,"yAmount":0,"channel":"luma"}` |
| 垂直反向置换，使用红通道 | `{"xAmount":0,"yAmount":-0.15,"channel":"red"}` |
| 用 Alpha 通道做强烈的正向二维置换 | `{"xAmount":0.3,"yAmount":0.3,"channel":"alpha"}` |
| 关闭置换但保留默认通道 | `{"xAmount":0,"yAmount":0,"channel":"luma"}` |

## 推荐档位

| 程度 | 单轴 `Amount` 绝对值 |
| --- | ---: |
| 关闭 | `0` |
| 轻微 | `0.02..0.05` |
| 中等 | `0.08..0.15` |
| 强烈 | `0.2..0.35` |
| 极端 | `0.5..1` |

默认值为 `xAmount=0.05`、`yAmount=0.05`、`channel=luma`。`xAmount=0`、`yAmount=0` 分别是对应轴无位移的中性值，两者均为 `0` 时关闭置换；`±1` 是最大方向边界。通道枚举没有强弱顺序。

置换图和源画面由服务端绑定，不生成 `map`、纹理、图片、资源 ID、路径或 URL。本工具不选择或创建置换图，不用于普通图层混合、遮罩显现、轨道 matte、液态物理模拟或几何网格编辑。
