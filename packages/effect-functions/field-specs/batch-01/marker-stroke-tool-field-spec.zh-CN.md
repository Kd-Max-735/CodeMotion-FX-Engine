# 马克笔涂抹 `marker_stroke`

沿服务端绑定笔迹生成重叠的确定性马克笔笔头印迹，模拟透明叠色、渗色和纸面边缘。只输出 JSON，不要附加解释、Markdown 或代码块：

```json
{"type":"marker_stroke","data":{"width":28,"opacity":0.82,"overlap":0.35,"bleed":0.12,"edgeRoughness":0.08,"spacing":0.3}}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `width` | 否 | `1..400` px，默认 `28` | 笔触宽度 |
| `opacity` | 否 | `0..1`，默认 `0.82` | 单次笔头透明度 |
| `overlap` | 否 | `0..1`，默认 `0.35` | 笔头覆盖密度和叠色程度 |
| `bleed` | 否 | `0..1`，默认 `0.12` | 边缘随机外扩程度 |
| `edgeRoughness` | 否 | `0..0.5`，默认 `0.08` | 中心线横向细小扰动 |
| `spacing` | 否 | `0.05..1`，默认 `0.3` | 相对笔宽的印迹间距 |

## 参数选择规则

1. 先定 `width`，再用 `opacity` 控制覆盖感；不要靠极密间距代替高不透明度。
2. “重复涂过、接缝加深”提高 `overlap`；“纸张吸墨”提高 `bleed`。
3. 干净荧光笔降低 `bleed` 和 `edgeRoughness`；真实手绘才同时提高两者。

| 自然语言 | 参数对应 |
| --- | --- |
| 干净的半透明荧光笔 | `opacity=0.5, bleed=0.02, edgeRoughness=0.02` |
| 宽一点的普通马克笔 | `width=44, opacity=0.82` |
| 重复涂抹处明显加深 | `overlap=0.72, spacing=0.18` |
| 纸面有一点渗色 | `bleed=0.2, edgeRoughness=0.1` |
| 很毛糙的手绘边缘 | `bleed=0.32, edgeRoughness=0.24` |
| 窄而均匀的标签笔 | `width=12, spacing=0.22, bleed=0.03` |

| 程度 | `width` | `bleed`/`edgeRoughness` |
| --- | ---: | --- |
| 轻微 | `12` | `0.03/0.02` |
| 中等 | `28` | `0.12/0.08` |
| 明显 | `52` | `0.25/0.16` |
| 强烈 | `90` | `0.4/0.28` |

默认值为示例中的完整 `data`。中性外观值是 `bleed=0`、`edgeRoughness=0`，完全透明为 `opacity=0`。不适用于纹理笔刷、真实水彩扩散、图片显现或霓虹光效。笔迹与任何纸张纹理由服务端绑定，模型不得生成路径或纹理字段。
