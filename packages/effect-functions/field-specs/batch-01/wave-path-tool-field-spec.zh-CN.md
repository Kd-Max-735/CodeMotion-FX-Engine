# 路径波浪形变 `wave_path`

在用户上传图片上，根据自然语言指定的可见起点和终点生成路径，并沿路径法线产生连续波浪。唯一 Ark 模型根据随请求提供的授权图片把语义位置转换为归一化坐标。需要调用时只输出 JSON，不要附加解释、Markdown 或代码块：

```json
{"type":"wave_path","data":{"amplitude":24,"wavelength":160,"phase":0,"speed":0.25,"taper":0,"sampleSpacing":8,"startX":0.15,"startY":0.5,"endX":0.85,"endY":0.5}}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `amplitude` | 否 | `0..500` px，默认 `24` | 控制横向偏移；`0` 为不形变 |
| `wavelength` | 否 | `4..2000` px，默认 `160` | 越小波纹越密，越大越舒展 |
| `phase` | 否 | `-360..360` 度，默认 `0` | 只在用户要求起始相位时调整 |
| `speed` | 否 | `-10..10` 周/秒，默认 `0.25` | 正负决定传播方向；`0` 为静止 |
| `taper` | 否 | `0..1`，默认 `0` | 增大后路径两端波幅减弱 |
| `sampleSpacing` | 否 | `1..64` px，默认 `8` | 小值更平滑但计算量更高 |
| `startX` | 否 | `0..1`，默认 `0.15` | 视觉理解所得起点中心横坐标 |
| `startY` | 否 | `0..1`，默认 `0.5` | 视觉理解所得起点中心纵坐标 |
| `endX` | 否 | `0..1`，默认 `0.85` | 视觉理解所得终点中心横坐标 |
| `endY` | 否 | `0..1`，默认 `0.5` | 视觉理解所得终点中心纵坐标 |

## 参数选择规则

1. 先用 `amplitude` 判断形变强度，再用 `wavelength` 判断疏密，不要用两者重复表达强度。
2. “固定波浪”设 `speed=0`；“反向流动”使用负速度。
3. 用户强调端点稳定时提高 `taper`；精度未明确时保持 `sampleSpacing=8`。

| 自然语言 | 参数对应 |
| --- | --- |
| 轻轻起伏、波浪拉长 | `amplitude=10, wavelength=260` |
| 做成飘带一样缓慢流动 | `amplitude=34, wavelength=190, speed=0.4` |
| 密集的小波纹向反方向跑 | `amplitude=14, wavelength=60, speed=-1.2` |
| 两端固定，中间明显摆动 | `amplitude=42, taper=0.9` |
| 保持当前形状但从半周期开始 | `amplitude=24, phase=180` |
| 要很平滑的近景曲线 | `sampleSpacing=3` |

| 程度 | `amplitude` | `wavelength` |
| --- | ---: | ---: |
| 轻微 | `8` | `260` |
| 中等 | `24` | `160` |
| 明显 | `48` | `110` |
| 强烈 | `90` | `70` |

定位优先级：用户明确的起点/终点对象或部位 > 图片视觉证据 > 默认横向路径。必须分别输出起点和终点，不能交换方向，也不能输出对象名称代替坐标。

默认值为示例中的完整 `data`。中性形变值是 `amplitude=0`；中性动画值是 `speed=0`、`phase=0`、`taper=0`。不适用于整张位图液化、真实布料模拟、路径布尔运算或多条路径自动编排。

## 服务器输入槽

- `source_image`：必需的授权背景图片，同时仅在当前允许的视觉定位请求中提供给唯一 Ark 模型。图片身份、字节、路径或 URL 绝不进入 Tool Call JSON。
