# 路径波浪形变 `wave_path`

将服务端已绑定的矢量路径按弧长重采样，并沿路径法线生成连续波浪。路径本身不属于模型参数。需要调用时只输出 JSON，不要附加解释、Markdown 或代码块：

```json
{"type":"wave_path","data":{"amplitude":24,"wavelength":160,"phase":0,"speed":0.25,"taper":0,"sampleSpacing":8}}
```

| `data` 字段 | 必填 | 取值 | 选择策略 |
| --- | --- | --- | --- |
| `amplitude` | 否 | `0..500` px，默认 `24` | 控制横向偏移；`0` 为不形变 |
| `wavelength` | 否 | `4..2000` px，默认 `160` | 越小波纹越密，越大越舒展 |
| `phase` | 否 | `-360..360` 度，默认 `0` | 只在用户要求起始相位时调整 |
| `speed` | 否 | `-10..10` 周/秒，默认 `0.25` | 正负决定传播方向；`0` 为静止 |
| `taper` | 否 | `0..1`，默认 `0` | 增大后路径两端波幅减弱 |
| `sampleSpacing` | 否 | `1..64` px，默认 `8` | 小值更平滑但计算量更高 |

## 参数选择规则

1. 先用 `amplitude` 判断形变强度，再用 `wavelength` 判断疏密，不要用两者重复表达强度。
2. “固定波浪”设 `speed=0`；“反向流动”使用负速度。
3. 用户强调端点稳定时提高 `taper`；精度未明确时保持 `sampleSpacing=8`。

| 自然语言 | 参数对应 |
| --- | --- |
| 轻轻起伏、波浪拉长 | `amplitude=10, wavelength=260` |
| 做成飘带一样缓慢流动 | `amplitude=34, wavelength=190, speed=0.4` |
| 密集的小波纹向反方向跑 | `amplitude=14, wavelength=60, speed=-1.2` |
| 两端固定，中间明显摆动 | `amplitude=42, taper=0.9` |
| 保持当前形状但从半周期开始 | `amplitude=24, phase=180` |
| 要很平滑的近景曲线 | `sampleSpacing=3` |

| 程度 | `amplitude` | `wavelength` |
| --- | ---: | ---: |
| 轻微 | `8` | `260` |
| 中等 | `24` | `160` |
| 明显 | `48` | `110` |
| 强烈 | `90` | `70` |

默认值为示例中的完整 `data`。中性形变值是 `amplitude=0`；中性动画值是 `speed=0`、`phase=0`、`taper=0`。不适用于位图液化、真实布料模拟、路径布尔运算或多条路径自动编排；路径由服务端单独绑定，绝不能生成路径、URL 或资源 ID。
