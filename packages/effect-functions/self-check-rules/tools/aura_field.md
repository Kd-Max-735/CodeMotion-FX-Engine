# aura_field 自检规则

<!-- self-check-parameter-contract:start -->
## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `intensity` | 光场强度 |
| `centerX` | 中心横坐标 |
| `centerY` | 中心纵坐标 |
| `radius` | 光场半径 |
| `hue` | 主色相 |
| `pulseRate` | 呼吸频率 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

同时接收一份自检 JSON 和一张 `keyframe_contact_sheet`。JSON 顶层只有 `file_name`、`original_request`、`summary`、`metadata`；合成图只由最终 MP4 的关键帧组成。不得假设还存在调用参数、源素材、渲染中间结果或其他上下文。

## 核心原则

1. 先从用户原始要求提取颜色、中心位置、覆盖范围、柔和程度、亮度和是否需要呼吸。
2. 最终成片事实优先，执行完成不等于视觉要求已经满足。
3. 氛围光应形成连续光场，不应退化成零散亮斑或完全遮盖底图。
4. 连续的呼吸起伏和轻微中心漂移是正常表现，不得机械判为闪烁故障。
5. 用户没有指定的审美偏好不得升级为失败条件。

## 自检视图字段

- `file_name`：仅用于识别最终视频文件，不得解释为服务器位置。
- `original_request`：用户未经改写的原始要求，是确定验收维度的唯一来源。
- `summary.description`：实际光场位置、亮度、颜色、覆盖和时间表现的简述。
- `metadata.media`：编码格式、尺寸、帧率、时长、帧数和可解码状态。
- `metadata.quality`：黑帧、连续性、非预期闪变和证据覆盖情况。
- `metadata.keyframe_evidence`：关键帧数量、时间、角色和合成图名称，不含本地地址。

## 关键帧规则

- 静态光场选前、中、后三个稳定阶段，证明位置和亮度没有意外漂移。
- 呼吸光场覆盖呼吸开始、较暗阶段、峰值、中心漂移最明显阶段和循环后段；没有证明作用的重复帧可以省略。
- 帧数不固定，只保留能证明光效出现、峰值、循环与稳定性的时刻。
- 合成图按时间从左到右排列，不把参数、指标或用户文字写入画面。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 暖色、紫青或指定色调 | “主要颜色”和峰值关键帧 |
| 光在左上、人物背后或画面中央 | “光场位置”和全部关键帧 |
| 局部光环或宽幅环境光 | “覆盖范围”和峰值关键帧 |
| 柔和、清晰、明亮或强烈 | “实际亮度”、光场边缘和底图可读性 |
| 静止或呼吸 | “呼吸表现”及跨时刻关键帧 |
| 无闪烁、无黑帧、无碎裂 | `metadata.quality` 和合成图 |

## 判定流程

1. 列出用户明确提出且适用于氛围光场的要求。
2. 对每项要求查找 JSON 事实和对应关键帧，不从事实反推用户要求。
3. 检查实际光场中心、颜色、覆盖和亮度是否与原始要求一致，底图是否仍可辨认；位置不一致时必须返修，不能因光场本身可见而通过。
4. 检查静态稳定性或呼吸循环；平滑呼吸不能作为故障证据。
5. 仅在证据明确冲突或存在影响交付的质量缺陷时判定返修。

## 通过与返修

通过时给出简洁交付结论。用户明确要求“右上角”等位置时，只有最终成片检测到的实际位置一致才可通过。返修时使用“将光场移回人物背后”“将光场移到右上角”“扩大柔光覆盖”“减弱过强泛白”“让呼吸更平滑”等用户可理解的效果语言。

## 禁止事项

- 不把算法、公式、后端、资源身份、路径或中间数据混入参数摘要。
- 不输出服务器路径、资源标识、网址、租户或鉴权信息。
- 不把正常呼吸和轻微漂移误判为故障闪烁。
- 不用用户要求覆盖实际检测位置，也不因关键帧中存在光场就忽略位置冲突。
- 不把编码完成、证据充分或主观偏好直接当作通过结论。
