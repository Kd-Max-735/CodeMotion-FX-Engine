# wave_warp 自检规则

## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `amplitude` | 扭曲幅度 |
| `frequency` | 波纹频率 |
| `axis` | 扭曲方向 |
| `phase` | 起始相位 |
| `speed` | 波动速度 |
| `edgeMode` | 边缘模式 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

- 不把算法、公式、后端、资源身份、路径或中间数据混入参数摘要。

## 核心原则

波浪扭曲必须从成片证明规则、连续的单轴波形及其时间传播。随机弯曲不是规则波浪；主体自然摆动也不能单独证明坐标扭曲。

## 自检视图字段

- `metadata.observed_effect`：记录扭曲方向、波纹疏密、波形连续性和边缘稳定性。

## 关键帧规则

运动波形覆盖起始、波峰变化、代表波形、波谷变化和结束中的实际可辨时刻；静止波形用早中晚证明稳定。数量由变化决定，按时间合并为 `keyframe_contact_sheet`，只标注帧序、角色和时间。

## 用户要求到证据的映射

| 要求 | 证据 |
| --- | --- |
| 横向摆动或纵向起伏 | “扭曲方向”与轮廓位移 |
| 波纹更密或舒展 | “波纹疏密”与代表帧 |
| 快慢、正向或反向 | 按时间排列的波峰/波谷状态 |
| 边缘固定或无破边 | “边缘稳定性”与画面四周 |

## 判定流程

先确认波形规则且主要沿一轴；核对疏密、强弱和跨帧传播；再检查连续性、暗边、撕裂和异常跳变。

## 通过与返修

规则波形与用户方向、疏密和节奏一致且边缘可交付时通过。返修使用“改成纵向起伏”“让波纹更舒展”“减慢传播”。

## 禁止事项

- 不把算法、公式、后端、资源身份、路径或中间数据混入参数摘要。
- 不把周期回到相似波形误判为重复帧。
- 不凭单帧判断传播方向。
- 不把源素材自身曲线当成波浪扭曲。
