## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `text` | 书写文字 |
| `fontSize` | 字号 |
| `positionX` | 横向位置 |
| `positionY` | 纵向位置 |
| `color` | 笔迹颜色 |
| `pressure` | 笔压 |
| `speedVariation` | 速度变化 |
| `progress` | 书写进度 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

检查四字段自检 JSON 与最终视频 `keyframe_contact_sheet`。用户指定的文字、笔迹进度、书写方向、可读性和质感决定验收维度。

## 核心原则

笔迹应沿时间形成可理解的书写过程，最终可见内容与用户要求一致。自然粗细变化、短暂停顿和轻微抖动可以是手写质感，不应机械判为不连续。

## 自检视图字段及含义

- `summary.description`：实际书写过程、连贯性与结束状态。
- `summary.missing_information`：无法可靠确认的笔迹事实。
- `metadata.media`：最终视频规格。
- `metadata.quality`：基础质量与时间状态。
- `metadata.keyframe_evidence`：起始、推进、中段、细节、结束和保持帧。

## 关键帧合成图的检查方法

追踪笔迹端点与已写区域的增长，检查是否按合理顺序形成文字或图形。结束帧用于核对缺笔、断笔和可读性；保持帧用于确认笔迹没有意外消失。

## 用户要求到证据的映射

| 用户要求 | 主要证据 |
| --- | --- |
| 指定文字或图形写出 | “文字完成状态”和结束帧 |
| 逐笔书写 | “笔迹进度”和推进帧 |
| 连贯、自然、有手写感 | “笔迹连续性”和细节帧 |
| 只写到部分进度 | “笔迹进度”和结束帧 |
| 完成后保留 | “结束保持”和保持帧 |

## 判定流程

提取内容、进度和质感要求；确认笔迹可见；追踪书写推进；检查结束内容与连贯性；最后检查保持和视频质量。

## 通过与返修原则

笔迹推进清楚、连贯性和完成程度符合用户要求时通过。返修描述“第二个字少一横”“笔迹中段断开”“只完成约一半但用户要求写完”等现象。

## 禁止事项

- 不输出文字轮廓、书写路径、内部计算、采样安排或字体资源信息。
- 不把自然压感变化误判为闪烁。
- 不要求用户未指定的书法风格。
