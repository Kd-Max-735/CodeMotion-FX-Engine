# wave_surface 自检规则

## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `mode` | 波面模式 |
| `gridSize` | 网格尺寸 |
| `amplitude` | 波面幅度 |
| `frequencyX` | 横向频率 |
| `frequencyY` | 纵向频率 |
| `damping` | 波动阻尼 |
| `speed` | 波动速度 |
| `crestColor` | 波峰颜色 |
| `troughColor` | 波谷颜色 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

仅接收四字段自检 JSON 和最终 MP4 的 `keyframe_contact_sheet`。不得读取高度数据、坡度数据、计算网格、函数参数、路径或资源身份。

## 核心原则

波浪曲面的证据是连续峰谷、可辨波面形态、随峰谷变化的明暗和跨时刻波面推进。二维规则扭曲或纯颜色渐变不能冒充曲面起伏。

## 自检视图字段

`summary` 应说明波面形态、峰谷层次、波面变化、高光与阴影、曲面完整性；`metadata` 记录最终媒体、技术质量和证据覆盖。

## 关键帧规则

覆盖波面起始、峰谷推进、代表波面、后段变化和结束中的实际可辨状态；静止曲面用早中晚确认稳定。合成图只标注帧序、角色和时间。

## 用户要求到证据的映射

| 要求 | 证据 |
| --- | --- |
| 中心涟漪、交叉或斜向波 | “波面形态”与空间分布 |
| 起伏强弱、峰谷明显 | “峰谷层次”与明暗变化 |
| 向外、向内或斜向推进 | 多时刻峰谷位置 |
| 边缘衰减、曲面完整 | “曲面完整性”与外围区域 |

## 判定流程

确认画面具有曲面峰谷而非平面条纹；核对波面形态和层次；用时间序列判断推进与连续性；最后检查断面、过暗、闪烁和边缘污染。

## 通过与返修

波面形态、峰谷和运动符合用户要求且曲面完整时通过。返修使用“增强峰谷层次”“改成中心向外涟漪”“让外围更平静”。

## 禁止事项

- 不把算法、公式、后端、资源身份、路径或中间数据混入参数摘要。
- 不把固定明暗渐变误判为波峰波谷。
- 不凭单帧判断波面推进方向。
- 不把正常阴影区域机械判为黑帧。
