# shake 自检规则

## 输入契约

验收输入为一份顶层仅含 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及最终 MP4 的 `keyframe_contact_sheet`。

## 核心原则

- 冲击震动应表现为多数画面区域同步发生的快速二维位移，而不是局部主体运动。
- 强度、节奏、反向回摆和衰减必须从成片跨帧位移确认。
- 用户要求持续晃动时不强制衰减；用户要求“震一下后停止”时必须看到峰值后趋稳。
- 剪辑跳切、镜头推拉、滚动字幕或运动物体不能冒充冲击震动。

## 自检视图字段及含义

- `summary.description`：最终画面的震动强度、节奏和衰减概述。
- `summary.key_information`：包括“特效类型”“可见程度”“震动强度”“震动节奏”“衰减表现”“整画面一致性”。
- `metadata.effect.震动强度`：轻微、中等或明显。
- `metadata.effect.震动节奏`：顿挫、自然或密集。
- `metadata.effect.衰减表现`：未见明显冲击、明显衰减并趋稳或持续到后段。
- `metadata.effect.误判保护`：是否确认整画面同步位移。
- `metadata.quality` 与 `metadata.keyframe_evidence`：画质和峰值、回摆、后段状态证据。

## 关键帧检查规则

- 抽帧数量按震动事件决定，覆盖冲击前基准、最大偏移、一次或多次反向回摆、衰减阶段和结束状态。
- 强震或高频震动增加峰值/回摆帧；轻微短震只保留能证明位移与恢复的帧。
- 检查画面多个区域是否同向同步位移，边缘是否因位移出现不可接受的黑边、撕裂或重复。
- 关键帧相同不代表无震动；需结合峰值附近时刻。仅有局部物体位置变化则震动证据无效。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 轻微、中等、猛烈 | “震动强度”和最大偏移帧 |
| 顿挫、自然、高频密集 | “震动节奏”和相邻回摆帧 |
| 快速停止或逐渐衰减 | “衰减表现”、峰值与结束帧 |
| 持续晃动 | 后段关键帧仍存在同步位移 |
| 震一下后回正 | 冲击前、峰值、回摆、结束关系 |
| 无黑边、撕裂或跳切 | `metadata.quality` 与偏移峰值帧 |

## 判定流程

1. 提取强度、节奏、持续或衰减要求。
2. 确认整画面同步位移证据，而非局部运动。
3. 对照峰值、回摆和后段关键帧判断强弱与衰减。
4. 检查边缘安全与突发画面损坏。
5. 只有运动类型和用户需求均匹配时通过。

## 通过与返修原则

画面同步震动清楚、强度节奏符合要求、衰减关系正确且无明显黑边或撕裂时通过。返修使用“减弱震动”“增加回摆密度”“让冲击后更快稳定”等语言。

## 误判保护

- 主体自身运动、字幕滚动和局部特效不算整画面震动。
- 镜头推拉或旋转不等于二维冲击位移。
- 正常回摆不算随机跳帧。
- 用户明确要求持续震动时，后段未衰减不是缺陷。

## 禁止事项

- 不输出内部强度值、频率、随机信息、位移数组或实现细节。
- 不以输入设置证明震动存在或衰减正确。
- 不用单帧判断节奏。
- 不把所有画面运动统一称为震动。
