# sacred_geometry 自检规则

## 输入契约

输入是一份顶层严格为 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及最终 MP4 的 `keyframe_contact_sheet`。不得读取几何图元、构造声明、函数入参或中间矢量数据。

## 核心原则

1. 验收图案类型的视觉特征、中心位置、对称性、层次密度、线条颜色、背景关系、尺寸和旋转。
2. 圆与线的交叉是正常几何结构，不能把交点误判为断裂或杂点。
3. 整体旋转时，结构关系应保持稳定；角度变化本身不是闪烁或变形故障。
4. 复杂图案允许密集交叠，但仍需保持中心、层次和线条可读性。
5. 不对图案附加宗教含义或用户未要求的象征解释。

## 自检视图字段

- `file_name`：最终视频名称。
- `original_request`：图案、密度、颜色、尺寸和运动要求的来源。
- `summary.description`：实际几何位置、颜色、覆盖、亮度和旋转概况。
- `summary.key_information`：几何位置、线条颜色、图案覆盖、层次与密度、对称表现和旋转表现。
- `metadata.media`：最终视频规格与可解码状态。
- `metadata.quality`：线条连续性、中心平衡、异常黑帧和旋转误判保护。
- `metadata.keyframe_evidence`：几何起始、多个旋转结构和后段证据。

## 关键帧规则

- 静止图案选前、中、后帧，证明中心、颜色和结构稳定。
- 旋转图案覆盖起始角度、多个有区分度的旋转位置和后段。
- 关键帧应展示完整图案，不能只裁切局部交点。
- 帧数不固定，证据按时间合成一张图。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 生命之花式圆阵 | 完整关键帧中的重复圆与中心层次 |
| 中心放射连线 | 完整关键帧中的中心和放射结构 |
| 交叠三角层次 | 完整关键帧中的上下交叠与层数感 |
| 更密、更复杂或更简洁 | “层次与密度”和完整图案 |
| 金色、白色或指定背景关系 | “线条颜色”和代表帧 |
| 居中、放大或缩小 | “几何位置”“图案覆盖”和画面边缘 |
| 静止、顺向或反向旋转 | “旋转表现”和跨时刻帧 |

## 判定流程

1. 从原始要求提取图案视觉特征、密度、颜色、尺寸、位置和旋转。
2. 检查图案是否围绕中心均衡展开，结构是否完整可读。
3. 对旋转帧核对整体结构关系是否保持，不把合法交点当作断裂。
4. 检查线条与背景是否有足够辨识度，边缘是否被无意裁切。
5. 证据明确违背要求时才返修。

## 通过与返修

返修建议使用“把图案移回画面中心”“增加几何层次但保留可读性”“减小图案避免裁边”“让整体旋转保持结构稳定”等效果语言。

## 禁止事项

- 不输出图元数量、参数、构造规则、公式、算法、后端或中间矢量。
- 不输出路径、资源标识、网址或身份信息。
- 不把线条交叉误判为断裂，不把整体旋转误判为闪烁。
- 不附加宗教断言、象征意义或用户未要求的解释。
