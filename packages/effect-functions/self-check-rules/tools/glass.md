# glass 自检规则

## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `blur` | 玻璃模糊 |
| `refraction` | 折射强度 |
| `tintColor` | 玻璃色调 |
| `tintStrength` | 色调强度 |
| `border` | 边缘宽度 |
| `opacity` | 玻璃不透明度 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

仅接收四字段自检 JSON 和最终 MP4 的 `keyframe_contact_sheet`。不得读取玻璃表面数据、背景绑定、函数参数、路径或资源标识。

## 核心原则

以实际通透/磨砂观感、折射、色调、边缘高光和原素材运动保留为证据。模糊不能单独证明玻璃材质，偏色也不能单独证明折射。

## 自检视图字段

- `metadata.observed_effect`：记录通透与磨砂、折射表现、玻璃色调、边缘高光及原有运动保留情况。

## 关键帧规则

静态素材取能证明材质稳定的早中晚时刻；动态素材增加能证明原有运动仍连续的时刻。只从最终 MP4 抽帧，合成图只标注帧序、角色和时间。

## 用户要求到证据的映射

| 要求 | 证据 |
| --- | --- |
| 清透或磨砂 | “通透与磨砂”及细节保留程度 |
| 折射明显或克制 | “折射表现”与轮廓偏移 |
| 冷色、暖色或指定颜色 | “玻璃色调”与中性区域 |
| 边框高光 | “边缘高光”与画面周边 |
| 保留视频运动 | “原有运动保留”与跨时刻关键帧 |

## 判定流程

先核对玻璃类型，再区分模糊、折射、色调和高光各自证据；动态素材额外核对运动连续性；最后检查过曝边框、过度糊化和整帧色偏。

## 通过与返修

材质观感与用户要求一致且内容仍可用时通过。返修使用“提高通透度”“增强磨砂感”“减弱边缘高光”“保留原视频运动”。

## 禁止事项

- 不输出模糊、折射、透明度数值或材质模型。
- 不把源素材自身虚焦误判为磨砂玻璃。
- 不把视频原有运动误判为玻璃动画。
- 不要求清透玻璃必须出现强彩边。
