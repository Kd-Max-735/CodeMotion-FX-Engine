# RGB 分离自检规则

## 输入契约

输入包括用户原始要求、自检 JSON 和最终成片关键帧合成图。JSON 顶层仅接受 `file_name`、`original_request`、`summary`、`metadata`。

## 核心原则

必须从最终轮廓确认红、绿、蓝通道发生结构性错位。整幅偏色或素材原有彩色边缘不等于 RGB 分离。

## 自检视图字段及含义

- `rgb_separation`：分离可见度、方向和观察跨度。
- `separation_shape`：中心向外或统一轴向的分离形态。
- `affected_picture_ratio`：实际受通道分离影响的画面占比。
- `green_subject_reference`：绿色主体轮廓的参照状态。
- `keyframe_contact_sheet`：来自最终成片、按时间合并的关键帧视觉证据。

## 关键帧检查规则

检查高反差轮廓上三通道相对位置、分离形态和绿色参照轮廓，并比较不同时间是否稳定。按分离强弱和形态变化动态选帧。

## 用户要求到证据的映射

分离方向映射红蓝错位方向；强弱映射可见度与跨度；中心外扩或对称要求映射分离形态；范围要求映射受影响占比。

## 判定流程

先确认结构性通道错位，再核对方向、形态和覆盖范围，随后排除整体染色、压缩彩边与随机色噪，最后比对用户要求。

## 通过与返修原则

三通道错位清楚、形态符合要求且主体结构仍可辨时通过。仅有偏色、无结构错位、方向或形态错误、严重彩边污染时返修。

## 禁止事项

不得用设置值证明分离，不得把色差或素材自带彩边直接当作 RGB 分离，不得披露内部计算、路径、资源或抽帧安排。
