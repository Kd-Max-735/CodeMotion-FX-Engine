# elastic 自检规则

## 输入契约和核心原则

验收输入只有顶层为 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及从最终 MP4 合成的 `keyframe_contact_sheet`。

验收实际画面是否沿用户需要的方向发生交替超调与回弹，并按需要逐步衰减或持续。不得把声明的方向、周期或阻尼当成事实；必须从成片中的极值、反向和稳定阶段确认。

## 自检视图字段

- `file_name`：最终视频文件名。
- `original_request`：用户原始需求。
- `summary.description`：用水平、垂直或缩放方向，以及超调、反向回弹和趋稳描述结果。
- `summary.key_information`：实际弹性方向、方向反转、阻尼趋势和节奏。
- `summary.missing_information`：无法由现有画面可靠确认的事项。
- `metadata.media`：最终视频媒体事实。
- `metadata.quality`：黑帧、冻结、闪变、突切和尺寸一致性。
- `metadata.keyframe_evidence`：关键帧时间、角色和合成图信息。

## 关键帧合成图

检查开始状态、第一侧超调、反向回弹、后续较小超调、阻尼稳定段和结束。关键帧数量随实际振荡阶段变化；振荡较多时可包含更多有证明力的极值，振荡很少时不得机械凑帧。

水平弹性应主要表现为左右往返，垂直弹性应主要表现为上下往返，缩放弹性应主要表现为大小交替。衰减型结果的后续极值应逐渐靠近最终状态；持续型需求则允许末段仍有规律振荡。

## 用户要求与证据

| 用户要求 | 首选证据 |
| --- | --- |
| 水平、垂直、缩放 | “弹性方向”和各极值帧 |
| 幅度轻微或强烈 | 第一组相反极值的实际差异 |
| 高频、缓慢 | 关键变化在时间上的密度与“阻尼节奏” |
| 快速停止 | 后段极值明显收小并接近结束状态 |
| 持续振荡 | 末段仍有规律、可见的相反极值 |
| 果冻或弹簧感 | 超调、反向回弹与尺寸或位置变化的连贯组合 |
| 最终稳定 | 阻尼稳定段和结束帧 |

## 判定流程

1. 提取方向、幅度、快慢、衰减和持续性要求。
2. 确认最终视频可用且关键极值覆盖充分。
3. 判定主运动方向，检查是否存在交替超调和回弹。
4. 比较早期与后期极值，判断实际阻尼趋势。
5. 检查结束状态、裁切、突跳、闪变和冻结。
6. 仅在事实证据明确不符时返修。

## 通过与返修原则

返修使用“改为水平回弹”“增强首次超调”“减慢往返节奏”“让振幅更快衰减”“保留更持久的弹性”“让末段稳定”等用户可理解语言。

## 禁止事项

- 不写出或比较函数参数、振荡公式、采样安排、算法、后端或资源信息。
- 不以预期周期和衰减曲线证明成片正确。
- 不把单向位移、随机震动或循环漂浮当成阻尼弹性。
- 不强制末段稳定，除非用户要求或效果本身明确应收束。
- 不输出路径、URL 或身份信息。
