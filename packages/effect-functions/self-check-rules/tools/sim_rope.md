# sim_rope 自检规则

## 输入契约

输入是一份顶层仅含 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及全部取自最终 MP4 的 `keyframe_contact_sheet`。

## 核心原则

- 绳索必须是细长、连续且有端点关系的可见结构，并呈现整体相连的摆动或下垂。
- 一般物体平移、随机曲线、粒子轨迹或画面裂缝不能冒充绳索模拟。
- 检查绳索位置、摆幅、方向、端点稳定和绳体连续性。
- 单端和双端固定的预期不同，只按用户明确要求验收。

## 自检视图字段及含义

- `summary.description`：绳体形态、摆动和连续性的成片描述。
- `summary.key_information`：包括“特效类型”“可见程度”“绳索位置”“摆动幅度”“摆动方向”“连续性”“端点稳定”。
- `metadata.effect.绳索形态`：细长连续或无法可靠确认。
- `metadata.effect.摆动幅度`：轻微、自然或大幅摆动。
- `metadata.effect.摆动方向`：跨时刻观察到的主要方向。
- `metadata.effect.连续性`：绳体是否保持可辨识。
- `metadata.effect.误判保护`：一般物体移动未作为绳索证据。

## 关键帧检查规则

- 抽帧数量随摆动状态变化，覆盖初始绳形、最大摆幅、反向摆动、端点状态和结束绳形；无明显运动时用前中后稳定帧。
- 跨帧确认绳体各部分相连运动，曲线不能突然断裂、换位、缩成一点或伸长到不可解释程度。
- 单端固定时检查锚端相对稳定、自由端摆动；双端固定时检查两端稳定且中段下垂/振动。
- 最大摆幅帧检查边缘裁切、绳体交叉、断裂和突然穿越背景主体。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 起点位于指定对象或部位 | “绳索位置”与初始关键帧 |
| 单端摆绳或双端悬挂 | “端点稳定”和跨时刻端点关系 |
| 长、短、绷紧或松软 | 初始/峰值绳形与下垂弧度 |
| 轻微、自然或猛烈摆动 | “摆动幅度”和峰值/反向帧 |
| 快速停下或持续摆动 | 峰值后的后段关键帧 |
| 无断裂、异常伸长或裁切 | “连续性”、`metadata.quality` 和最大摆幅帧 |

## 判定流程

1. 提取锚点位置、固定方式、长度感、松紧、摆幅和停止要求。
2. 确认细长连续绳体确实存在。
3. 检查端点与中段的跨帧关系。
4. 检查摆动峰值、反向和结束状态。
5. 排除普通物体移动及画面裂缝后作出结论。

## 通过与返修原则

绳体连续、端点关系正确、摆动和下垂符合用户要求且无明显断裂或裁切时通过。返修使用“固定绳索起点”“减小摆幅”“保持绳体连续”“让双端都稳定”等语言。

## 误判保护

- 一条静态画面边缘或裂缝不等于绳索。
- 背景物体移动不等于绳体摆动。
- 单端自由摆动时，自由端移动不是端点故障。
- 轻微编码锯齿不等于绳体断裂。

## 禁止事项

- 不输出节点、分段、约束、模拟步长、内部设置、锚点数据或资源信息。
- 不以输入固定方式证明端点正确。
- 不用单帧证明摆动方向或衰减。
- 不要求绳索具备断裂、缠绕或三维碰撞能力。
