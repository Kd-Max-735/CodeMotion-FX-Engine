# 人声响应文字自检规则

## 输入契约

审查只接收四字段自检 JSON 和最终 MP4 的 `keyframe_contact_sheet`。可见文字内容属于交付事实，内部文字结构不属于审查输入。

## 核心原则

必须描述成片里实际可见的文字内容，以及低响应和高响应时文字的尺寸、位置或明暗变化。人声能量输入存在不能证明文字已经响应。

## 自检视图字段

- `visible_content`：最终画面中实际可见的文字内容。
- `response_dimension`：实际发生变化的可见维度。
- `response_range`：响应幅度等级。
- `quiet_state`、`active_state`：低响应与高响应状态是否可辨。
- 媒体、质量与关键帧证据位于 `metadata` 对应视图。

## 关键帧规则

按实际观察选择低响应文字态、高响应文字态和必要的过渡态。若人声段落有多个明显峰值，可增加帧；合成图按时间排序。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 指定文字内容 | `visible_content` 与清晰文字关键帧 |
| 随人声放大、移动或变亮 | `response_dimension` 与低、高响应态 |
| 轻柔或明显 | `response_range` 与状态差异 |
| 停顿时回归 | `quiet_state` 与峰后关键帧 |

## 判定流程

先核对文字实际内容和可读性，再比较低、高响应状态，最后判断幅度、回归和用户意图。只有音频证据、没有文字视觉变化时必须失败。

## 通过与返修

通过要求文字内容可辨、响应维度正确、低高状态可区分。返修应指出内容错误、文字不可读、响应维度不符或停顿时未回归。

## 禁止事项

- 不输出音频特征、字形数组、属性路径或内部数值。
- 不用人声分析结果代替文字成片表现。
- 不暴露字体资源、图层信息、路径或后端。
