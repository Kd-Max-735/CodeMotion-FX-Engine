# character_cascade 自检规则

## 输入契约

检查四字段自检 JSON 和最终视频 `keyframe_contact_sheet`。`original_request` 中的文字内容、级联方向、节奏和完整性要求是验收目标。

## 核心原则

文字必须可读且最终完整，级联应表现为文字单元错时进入并汇合。运动中的暂时重叠、偏移或模糊可能是正常过渡，只有完成帧仍缺字、错位或不可读才构成明确问题。

## 自检视图字段及含义

- `summary.description`：级联过程和最终文字状态。
- `summary.key_information`：文字显现范围、级联过程、文字完整性、文字边界和完成保持。
- `summary.missing_information`：无法确认的文字覆盖事实。
- `metadata.media`：最终视频规格。
- `metadata.quality`：基础质量与异常静止。
- `metadata.keyframe_evidence`：开始、字符到达、中段、完成和保持帧。

## 关键帧合成图的检查方法

按时间观察文字单元是否分批进入、是否沿一致方向收敛，以及完成帧是否形成完整可读文字。不要在过渡帧要求所有字符已经对齐；重点检查结束与保持证据。

## 用户要求到证据的映射

| 用户要求 | 主要证据 |
| --- | --- |
| 指定文字完整出现 | “文字完整性”、完成帧和保持帧 |
| 逐字符、逐词或逐行级联 | “级联过程”和字符到达帧 |
| 从指定方向进入 | 连续关键帧中的位移方向 |
| 快慢、错时感 | 关键帧时间和显现节奏 |
| 位置与可读性 | “文字显现范围”“文字边界”和完成帧 |

## 判定流程

先核对用户文字与级联要求；观察开始到完成的时序；重点检查最终文字完整性和保持；再检查位置、裁切与基础质量。

## 通过与返修原则

级联过程明确、最终文字完整可读且位置符合要求时通过。返修描述“最后一个字未出现”“完成后仍有字符偏离”“文字右侧被裁切”等实际差异。

## 禁止事项

- 不输出文字栅格、内部选择方式、计算或采样安排。
- 不把过渡帧的错位当成最终缺陷。
- 不因字体风格不合个人喜好而失败，除非用户明确指定。
