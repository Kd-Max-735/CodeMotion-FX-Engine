## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `amount` | 置换强度 |
| `scale` | 湍流尺度 |
| `complexity` | 湍流复杂度 |
| `evolutionSpeed` | 演化速度 |
| `anisotropy` | 方向差异 |
| `edgeMode` | 边缘模式 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

仅使用四字段自检 JSON 与最终 MP4 的 `keyframe_contact_sheet`。不得读取噪声场、随机状态、函数参数、源素材路径或资源身份。

## 核心原则

湍流置换应表现为非规则、多尺度、空间连续的有机形变。规则正弦波、整帧抖动或独立噪点不能冒充湍流。

## 自检视图字段

`summary` 应说明形变尺度、方向偏置、有机连续性和边缘表现；`metadata` 应说明最终媒体、技术质量与证据覆盖。

## 关键帧规则

覆盖湍流起始、场变化、代表形态、演化后段和结束中实际有区分的时刻；静态湍流则以早中晚证明稳定。只标注帧序、角色和时间。

## 用户要求到证据的映射

| 要求 | 证据 |
| --- | --- |
| 大块、柔和或细碎 | “形变尺度”与空间纹理 |
| 横向或纵向拉扯 | “方向偏置”与轮廓变化 |
| 翻涌快慢 | 多时刻场变化与时间 |
| 无破边 | “边缘表现”与画面四周 |

## 判定流程

确认形变是不规则有机变化；核对尺度和方向；检查演化是否空间连续；再排除随机闪烁、全帧抖动、边缘撕裂和异常暗区。

## 通过与返修

湍流尺度、方向和连续性满足要求且画面完整时通过。返修使用“改成更大块的云涌”“加强横向拉扯”“减慢翻涌”。

## 禁止事项

- 不输出复杂度、尺度数值、随机状态、边缘策略或算法。
- 不把有机演化的非周期性误判为随机错误。
- 不把源素材细节丰富误判为细碎湍流。
- 不以任意两帧不同直接证明运动连续。
