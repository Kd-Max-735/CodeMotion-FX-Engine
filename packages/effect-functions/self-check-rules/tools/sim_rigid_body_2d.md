## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `bodyCount` | 刚体数量 |
| `gravity` | 重力 |
| `restitution` | 反弹系数 |
| `friction` | 摩擦力 |
| `initialSpeed` | 初始速度 |
| `bodyRadius` | 刚体半径 |
| `solverIterations` | 求解迭代次数 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

验收只使用顶层为 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及从最终 MP4 合成的一张 `keyframe_contact_sheet`。

## 核心原则

- 二维刚体模拟应出现多个局部物体各自的位移、碰撞、反弹或堆叠，而不是整画面统一移动。
- 刚体分布、运动活跃程度、碰撞表现和边界行为必须从成片确认。
- 不以物体数量设置、运动声明或执行成功证明结果。
- 用户要求平静或低反弹时，不因碰撞峰值少而失败。

## 自检视图字段及含义

- `summary.description`：刚体分布、运动和碰撞的实际概述。
- `metadata.effect.刚体分布`：少量大块、中等数量或较密集的可见分布。
- `metadata.effect.模拟运动`：平缓、活跃或猛烈。
- `metadata.effect.碰撞表现`：是否观察到碰撞或反弹峰值。
- `metadata.effect.误判保护`：整画面位移未作为刚体证据。
- 其余 `metadata` 字段记录视频质量和关键帧角色。

## 关键帧检查规则

- 抽帧数量由模拟事件决定，覆盖初始分布、运动峰值、每个有证明力的碰撞或反弹时刻、堆叠/稳定状态和结束分布。
- 检查多个物体是否保持独立轮廓并沿不同轨迹运动；同步平移的整幅图像证据无效。
- 碰撞前后关键帧应体现接近、接触后的方向或速度变化；低反弹要求可用停下或堆叠证明。
- 边界附近检查物体是否自然反弹或停留，不得穿透、裁成半块或突然消失。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 少量大块或许多小块 | “刚体分布”和初始/结束分布帧 |
| 沉重下落、漂浮或猛烈散动 | “模拟运动”与跨时刻位移 |
| 高弹、低弹或不反弹 | 碰撞前后与后段关键帧 |
| 光滑或摩擦明显的运动感 | 接触后的滑动或快速停下关系 |
| 稳定堆叠 | 后段和结束关键帧 |
| 无穿透、重叠、消失或裁切 | “边界表现”和碰撞峰值帧 |

## 判定流程

1. 提取数量感、大小、重量、弹性、活跃程度和边界要求。
2. 确认多个局部刚体的独立运动证据。
3. 检查碰撞前后、反弹或堆叠关系。
4. 检查边界与画面质量。
5. 结合用户明确要求决定通过或返修。

## 通过与返修原则

多个刚体运动可辨、碰撞或堆叠符合要求、边界行为自然且无明显穿透或消失时通过。返修使用“减少相互穿透”“增强反弹感”“让物体更快稳定堆叠”等语言。

## 误判保护

- 整图平移、粒子噪声或镜头震动不等于多个刚体运动。
- 用户要求低弹时，碰撞后不明显回弹是合理的。
- 瞬时遮挡不能直接判为物体消失。
- 仅凭单帧物体很多不能证明发生了模拟运动。

## 禁止事项

- 不把算法、公式、后端、资源身份、路径或中间数据混入参数摘要。
- 不用输入数量或动力设置证明成片。
- 不从单帧推断碰撞响应。
- 不要求超出二维圆形刚体范围的物理功能。
