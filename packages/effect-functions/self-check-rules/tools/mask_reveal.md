# mask_reveal 自检规则

## 输入契约

检查四字段自检 JSON 和最终视频 `keyframe_contact_sheet`。用户对遮罩形状、覆盖方向、目标显现范围、未覆盖区域和边缘质感的要求是验收目标。

## 核心原则

遮罩覆盖应与目标画面显现一致，未覆盖区域保留源画面，边界按用户要求清晰或柔和。反向遮罩会交换覆盖与未覆盖含义，不能仅凭中央区域未显现就判失败。

## 自检视图字段及含义

- `summary.description`：遮罩覆盖、目标画面、源画面保留和边缘结果。
- `summary.key_information`：遮罩覆盖、目标画面、未覆盖区域、遮罩边缘和显现过程。
- `summary.missing_information`：缺少源或目标对照时的缺项。
- `metadata.media`：最终视频规格。
- `metadata.quality`：基础质量和异常静止。
- `metadata.keyframe_evidence`：起始、覆盖增长、中段、边界、完成和保持帧。

## 关键帧合成图的检查方法

沿时间观察遮罩边界移动或扩展，确认边界一侧逐步显示目标画面，另一侧保持源画面。检查边界有无跳变、泄漏、孤立孔洞和明显色边；自定义遮罩允许不规则覆盖。

## 用户要求到证据的映射

| 用户要求 | 主要证据 |
| --- | --- |
| 指定区域显现目标 | “遮罩覆盖”“目标画面”和完成帧 |
| 未覆盖区域保留原画 | “未覆盖区域”和中段帧 |
| 扩展、移动或反向显现 | “显现过程”和连续关键帧 |
| 柔边或硬边 | “遮罩边缘”和边界检查帧 |
| 完整或局部覆盖 | “遮罩覆盖”和结束帧 |

## 判定流程

提取覆盖、方向、边缘和完成要求；识别遮罩两侧的源目标关系；追踪覆盖过程；检查完成帧；最后核对视频质量。

## 通过与返修原则

覆盖关系、方向、边缘和完成程度符合要求时通过。返修描述“遮罩外区域也变成目标画面”“边界中途跳到另一侧”“要求柔边但出现明显锯齿”等差异。

## 禁止事项

- 不输出遮罩资源、内部覆盖值、计算、采样安排或实现信息。
- 不把反向遮罩的合法结果误判为源目标颠倒。
- 不要求自定义遮罩形成规则几何形状。
