# particle_emitter 自检规则

## 输入契约

输入为程序生成的自检 JSON 和最终视频的 `keyframe_contact_sheet`。JSON 必须包含 `file_name`、`original_request`、`summary`、`metadata`，合成图必须呈现实际生成、增长、峰值和退场过程。

## 核心原则

- 验收可见的发射源、生成连续性、数量峰值、主方向和生命周期。
- 发射可以稀疏、间歇或持续，不要求逐粒子一致。
- 重力弯曲、扩散、边缘离场和合理运动模糊都是正常现象。
- 不从内部生成数据推导通过，必须与最终画面互证。

## 自检视图字段

- `file_name`：最终视频文件名。
- `original_request`：用户未经改写的需求。
- `summary.description`：实际发射过程描述。
- `summary.key_information`：粒子数量感、发射位置感、发射方向、发射力度和生命周期。
- `summary.missing_information`：无法可靠取得的信息。
- `metadata.media`：最终视频规格和可用状态。
- `metadata.quality`：黑帧、跨帧变化和亮度跳变。
- `metadata.keyframe_evidence`：发射前、开始、增长、峰值、尾段及最终状态。

## 关键帧规则

根据实际粒子活动选择发射前、首次出现、增长阶段、数量峰值、峰值后的明显下降、最后活动和最终状态。若发射持续至结束，保留持续尾段而不虚构退场。重合阶段合并，数量不固定。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 发射位置 | “发射位置感”和首次出现帧 |
| 方向、扇形或集中喷射 | “发射方向”及开始到峰值帧 |
| 稀疏或密集 | “粒子数量感”和峰值帧 |
| 柔和或强劲 | “发射力度”及扩散距离变化 |
| 持续发射或停止退场 | “生命周期”及峰值后、最终帧 |
| 卡死、断流、闪烁或破图 | `metadata.quality` 与全组关键帧 |

## 判定流程

1. 提取位置、方向、数量感、力度和持续性的明确要求。
2. 确认从首次粒子到峰值的增长连续可见。
3. 检查发射源是否稳定，粒子是否沿可理解方向离开。
4. 允许随机分布；只有发射源错位、方向相反、过程断层或画面损坏才返修。

## 通过与返修

通过要求发射源可辨、生成连续、数量与方向符合需求、生命周期自然。返修用“集中发射区域”“扩大喷射范围”“降低数量感”“延长退场”等效果语言。

## 禁止事项

- 不输出粒子数组、随机来源、生成速率数据、运动计算或运行实现。
- 不把正常稀疏、重力弯曲、粒子离场和运动模糊误判为失败。
- 不要求发射量逐帧线性增长，不以单帧证明持续过程。
- 不输出服务器路径、资源或授权信息。
