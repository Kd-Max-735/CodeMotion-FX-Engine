# dash_flow 自检规则

## 输入契约

输入是一份仅含 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及一张由最终 MP4 关键帧按时间合成的 `keyframe_contact_sheet`。

## 核心原则

- 核对真实可见的虚线路径、虚实节奏、流动方向、速度感和路径稳定性。
- 方向必须由跨时刻的虚线位置变化证明，不能由文字声明或路径起终定义证明。
- 静止虚线是合法结果，但只有用户要求静止时才能据此通过运动要求。
- 整幅画面平移、普通实线闪烁或粒子移动不能冒充虚线沿路径流动。

## 自检视图字段及含义

- `summary.description`：成片虚线的路径、方向、速度和节奏概述。
- `summary.key_information`：包括“特效类型”“可见程度”“虚线流向”“流动速度”“虚线节奏”“路径覆盖”。
- `metadata.effect.虚线流向`：从成片变化观察到的方向。
- `metadata.effect.流动速度`：静止、缓慢、中速或快速的可理解描述。
- `metadata.effect.虚线节奏`：短段细密、虚实清楚或长段舒展。
- `metadata.effect.路径稳定性`：变化是否集中在局部路径。
- 其余 `metadata` 字段记录视频质量与关键帧时间角色。

## 关键帧检查规则

- 抽帧数量不固定。静止虚线覆盖前中后；流动虚线覆盖起始、至少两个不同位置、运动变化峰值和结束。
- 必须能沿同一条可辨路径追踪虚线段位置变化；关键帧差异只有整图背景变化时，方向证据无效。
- 对快速流动增加位置变化帧，避免首尾恰好同相而误判静止。
- 检查虚线是否保持段与空隙，不得在运动中粘成实线、断成无路径碎点或反向跳动。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 从一处流向另一处 | “虚线流向”与至少两个位置变化关键帧 |
| 正向、反向或静止 | 跨时刻虚线段位移；静止时用前中后稳定帧 |
| 快、慢 | “流动速度”和关键帧时间间隔内的位移 |
| 细密、稀疏、长段或短段 | “虚线节奏”和路径最清晰帧 |
| 指定路径位置、颜色或粗细 | “路径覆盖”和成片关键帧 |
| 无闪烁、跳线或背景污染 | `metadata.quality` 与运动变化帧 |

## 判定流程

1. 提取用户指定的路径位置、流向、速度和虚线节奏。
2. 确认媒体和关键帧证据来自最终 MP4。
3. 先确认虚线和路径存在，再判断跨帧方向与速度。
4. 检查段空节奏与路径稳定性。
5. 证据不足时不猜方向，明确返修或补证据。

## 通过与返修原则

虚线沿同一路径以用户要求的方向和速度移动、节奏清楚且无明显跳线时通过。返修使用“让虚线向相反方向流动”“减慢流速”“恢复清楚的段间空隙”等表达。

## 误判保护

- 首尾同相不能证明静止，需检查中间位置。
- 背景主体运动不能作为虚线流向。
- 正常周期循环不能判为重复故障。
- 高速虚线的轻微编码模糊不能直接判为实线。

## 禁止事项

- 不输出路径点、内部设置、速度数值、资源信息或实现细节。
- 不用输入方向证明成片方向。
- 不用单帧推断运动方向。
- 不因用户未指定端帽等审美细节而判失败。
