# blend 自检规则

## 输入契约

同时检查四字段自检 JSON 与最终视频的单张 `keyframe_contact_sheet`。不得假设还能读取原始素材、调用设置或中间图层。

## 核心原则

验收图层是否形成用户要求的可见混合结果，关注两层贡献、明暗、色彩和稳定性。静态混合本来就可全片不变，不得把稳定结果判为卡死。

## 自检视图字段及含义

- `summary.description`：最终混合画面的整体观感。
- `summary.key_information`：图层贡献、明暗结果、色彩结果、混合覆盖和时间表现。
- `summary.missing_information`：无法可靠比较底层或叠加层时的缺项。
- `metadata.media`：最终视频规格和可用性。
- `metadata.quality`：黑帧、尺寸一致性、时间状态和异常静止。
- `metadata.keyframe_evidence`：成片关键帧的角色和时间。

## 关键帧合成图的检查方法

比较前段、中段和后段画面，确认混合没有意外切回单层、透明断层、色块或帧间跳变。若素材本身运动，应观察混合关系是否连续；若两层静止，稳定相同的多帧是正面证据。

## 用户要求到证据的映射

| 用户要求 | 主要证据 |
| --- | --- |
| 底层或叠加层更突出 | “图层贡献”和最终混合帧 |
| 变亮、压暗、增强对比或改变色彩 | “明暗结果”“色彩结果”和关键帧 |
| 全画面统一混合 | “混合覆盖”和前中后帧 |
| 混合稳定无闪烁 | “时间表现”、`metadata.quality` |
| 输出规格 | `metadata.media` |

## 判定流程

先提取用户指定的混合观感，再确认两层贡献与画面结果，随后检查时间一致性和基础质量。用户未指定某层强弱时，不以个人偏好决定失败。

## 通过与返修原则

混合结果符合用户要求且没有明显断层或异常跳变时通过。返修只描述“叠加层几乎不可见”“画面比要求更暗”“中途突然恢复为底层”等可观察差异。

## 禁止事项

- 不猜测或输出内部混合设置、计算方式或图层标识。
- 不把合法的深色、浅色或静态结果机械判为失败。
- 不要求用户未提出的特定审美风格。
