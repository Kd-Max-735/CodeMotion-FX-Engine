# particle_orbit_field 自检规则

## 输入契约

使用程序生成的自检 JSON 和最终 MP4 的单张 `keyframe_contact_sheet`。JSON 顶层必须包含 `file_name`、`original_request`、`summary`、`metadata`，合成图必须按时间展示实际环绕过程。

## 核心原则

- 验收群体是否形成可辨认的轨道与环绕方向，不追踪单个粒子。
- 允许轨道宽窄变化、局部离散和轻微径向摆动。
- 顺逆时针必须用多时刻证据判断，不能靠一张静帧猜测。
- 正常轨道稀疏、交叠和运动模糊不应误判。

## 自检视图字段

- `file_name`：成片名称。
- `original_request`：用户原始要求。
- `summary.description`：实际轨道形态与环绕表现。
- `summary.key_information`：粒子数量感、轨道范围、环绕方向、环绕速度和轨道稳定性。
- `summary.missing_information`：不可可靠判断项。
- `metadata.media`：成片规格和可解码事实。
- `metadata.quality`：黑帧、时间变化和亮度跳变。
- `metadata.keyframe_evidence`：轨道形成、分段环绕、最明显环绕及后段证据。

## 关键帧规则

关键帧数量不固定。从实际累计环绕变化中选择轨道形成、可达到的分段环绕时刻、环绕最明显和后段状态。环绕不足时不虚构完整一周，也不复制帧凑数量。所有证据合并为一张时间有序图片。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 顺时针或逆时针 | “环绕方向”及至少两个分段环绕帧 |
| 紧凑或宽轨 | “轨道范围”及轨道形成、后段帧 |
| 快慢 | “环绕速度”和跨时刻角位置变化 |
| 稳定圆环或涡旋收拢 | “轨道稳定性”及全组关键帧 |
| 粒子多寡 | “粒子数量感”和环绕最明显帧 |
| 断裂、瞬移、全帧异常 | `metadata.quality` 与合成图 |

## 判定流程

1. 提取用户对方向、半径、速度和稳定性的明确要求。
2. 确认多时刻证据足以辨别环绕，不用单帧作方向结论。
3. 检查轨道是否连续形成，群体是否围绕共同区域运动。
4. 允许随机扰动；仅在主环绕方向相反、轨道完全不成形或画面损坏时返修。

## 通过与返修

通过要求轨道可辨、方向正确、范围和速度符合需求且运动连续。返修建议使用“改为逆时针”“收紧轨道”“减慢环绕”“增强成环感”等语言。

## 禁止事项

- 不展示或核对粒子坐标、随机来源、力场关系、计算步进或运行实现。
- 不把少量偏离轨道的粒子、正常交叠或模糊判为失败。
- 不要求每个粒子保持相同半径，不臆造用户未要求的完美圆环。
- 不输出服务器路径和资源标识。
