# 径向模糊自检规则

## 输入契约

输入包括用户原始要求、自检 JSON 和最终成片关键帧合成图。JSON 顶层仅接受 `file_name`、`original_request`、`summary`、`metadata`。

## 核心原则

径向模糊必须围绕可辨认的视觉中心形成向外缩放或环绕旋转的连续拖影；普通均匀柔化不能作为证据。

## 自检视图字段及含义

- `visual_center`：变化相对稳定的视觉中心位置。
- `radial_appearance`：向中心缩放拖开或围绕中心旋转拖开。
- `blur_visibility`：实际可见程度。
- `center_change`、`edge_change`、`center_to_edge_separation`：中心与外围的变化关系。
- `keyframe_contact_sheet`：来自最终成片、按时间合并的关键帧视觉证据。

## 关键帧检查规则

检查中心位置是否稳定、外围拖影是否连续、各象限是否同属一个径向结构，并观察主体可辨性与画面边缘。按径向形态变化动态选帧。

## 用户要求到证据的映射

中心方位映射 `visual_center`；缩放或旋转映射实际形态；强弱映射可见度；“中心清楚、边缘更强”映射中心—外围差异。

## 判定流程

先定位视觉中心，再识别缩放或旋转形态，随后核对中心与外围层次和跨帧稳定性，最后排除均匀模糊或多中心破碎拖影。

## 通过与返修原则

中心、形态和强弱符合用户要求且径向结构连续时通过。中心明显错位、形态错误、仅均匀变糊、象限断裂或主体不可辨时返修。

## 禁止事项

不得由设置值推定中心或形态，不得把普通失焦视为径向模糊，不得输出内部计算、路径、资源或抽帧安排。
