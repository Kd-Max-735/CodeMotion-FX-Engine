# fractal 自检规则

## 输入契约

只审查四字段自检 JSON 和最终 MP4 的 `keyframe_contact_sheet`。不得访问递归配置、计算网格、迭代过程、素材路径或资源身份。

## 核心原则

关注成片是否形成可辨的重复递归层、中心深入感、层间区分和连续动画。复杂纹理不等于分形递归；单纯缩放也不能证明层层嵌套。

## 自检视图字段

`summary` 应描述递归层次、层间区分、中心深入感和动画连续性；`metadata` 提供最终媒体、技术质量和证据覆盖事实。

## 关键帧规则

静止分形覆盖早中晚；动画分形覆盖起始、递归结构变化、最具层次的代表时刻和结束。按实际变化决定数量，只标注帧序、角色和时间。

## 用户要求到证据的映射

| 要求 | 证据 |
| --- | --- |
| 更多层、深入、隧道感 | “递归层次”“中心深入感”与中心区域 |
| 层层旋转 | 多时刻嵌套结构的角度变化 |
| 反差或柔和 | “层间区分”与关键帧 |
| 静止或持续运动 | “动画连续性”及时间序列 |

## 判定流程

确认用户要求的是递归画面而非普通纹理；核对层级、中心和层间可辨度；再检查运动方向、连续性、闪烁和细节崩解。

## 通过与返修

递归层清楚且满足深度与运动要求时通过。返修可说“增加可辨递归层”“减弱层间反差”“让层级旋转更连续”。

## 禁止事项

- 不输出计算次数、网格、层数数值、缩放比例或内部公式。
- 不把高频纹理噪点当成丰富递归层次。
- 不把周期旋转返回相似画面判为重复帧。
- 不因中心区域较暗而自动判黑帧。
