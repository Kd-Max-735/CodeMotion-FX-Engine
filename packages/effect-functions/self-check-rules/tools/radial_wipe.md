# radial_wipe 自检规则

## 输入契约

只使用自检 JSON 与一张 `keyframe_contact_sheet`。JSON 顶层仅有 `file_name`、`original_request`、`summary`、`metadata`；关键帧全部从最终 MP4 抽取并按时间排序。

## 核心原则

- 径向擦除必须表现为围绕同一中心连续扩展的扇形边界。
- 擦除中心、起始区域、旋转方向和最终进度都要由成片阶段证据确认。
- 普通淡入淡出、整帧切换、圆形扩张或镜头旋转不能冒充径向擦除。
- 两路画面内容差异很小时，应承认证据受限，不能凭设置推断方向。

## 自检视图字段及含义

- `summary.description`：成片扇形擦除的中心、推进形态与完成状态。
- `summary.key_information`：包括“特效类型”“可见程度”“擦除中心”“擦除进度”“擦除方向”“阶段连续性”。
- `metadata.effect.擦除中心`：从成片变化估计的可理解画面区域。
- `metadata.effect.擦除进度`：变化范围较小、部分完成或接近完整。
- `metadata.effect.扇形推进`：是否存在可见扇形证据。
- `metadata.effect.阶段连续性`：覆盖是否总体连续增加。
- `metadata.keyframe_evidence`：擦除各阶段的时间和角色。

## 关键帧检查规则

- 抽帧数量随可见擦除阶段而变。优先选择起始、早期扇形、四分之一附近、中段、后段和完成帧；阶段不可辨时只保留有证明力的帧。
- 在连续帧中追踪同一扇形边界，确认中心不漂移、边界不跳切、覆盖总体增加。
- 顺逆时针必须由新显现区域沿圆周的先后顺序判断；仅有开始和结束两帧不能可靠判断方向。
- 结束帧检查是否达到用户要求的完成状态并保持目标画面。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 指定擦除中心 | “擦除中心”和多个扇形阶段帧 |
| 从顶部、右侧、底部或左侧开始 | 最早可见扇形边界关键帧 |
| 顺时针或逆时针 | 至少三个连续阶段中新增区域的圆周顺序 |
| 完整或部分擦除 | “擦除进度”、后段和结束关键帧 |
| 快慢和时长感 | 阶段帧时间间隔及覆盖增长 |
| 无跳切、黑帧或边缘破损 | “阶段连续性”、`metadata.quality` 和关键帧 |

## 判定流程

1. 提取中心、起始区域、方向、完成程度和节奏要求。
2. 确认最终 MP4 可用且阶段关键帧充分。
3. 先确认扇形形态，再判断中心和方向。
4. 检查覆盖增长、结束状态和画面质量。
5. 当两路画面过于相似导致方向不可见时，不得猜测。

## 通过与返修原则

扇形边界围绕正确中心连续推进、方向和完成程度符合需求且无明显跳切时通过。返修使用“把擦除中心移到画面中央”“改为逆时针推进”“让转场完整结束”等可见效果语言。

## 误判保护

- 全局淡变不等于扇形擦除。
- 圆形由内向外扩张不等于沿圆周推进。
- 镜头旋转不等于擦除方向。
- 两路画面相似导致的低变化不能直接判定方向错误。

## 禁止事项

- 不输出中心坐标、角度、内部进度值、资源身份或实现信息。
- 不以输入设置证明擦除中心或方向。
- 不从单帧推断旋转方向。
- 不要求关键帧展示源素材或中间遮罩。
