# energy_pulse 自检规则

## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `center` | 脉冲中心 |
| `radius` | 脉冲半径 |
| `falloff` | 边缘衰减 |
| `rings` | 脉冲环数 |
| `duration` | 脉冲时长 |
| `centerMode` | 中心定位模式 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

输入是一份顶层仅有 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及最终 MP4 的 `keyframe_contact_sheet`。不得访问中心坐标声明、发射次数声明、源图或渲染中间结果。

## 核心原则

1. 验收脉冲中心、环带亮度、颜色、外扩范围、传播方向、发射节奏和消退。
2. 脉冲应表现为从中心向外推进的环带，而不是仅在中心随机闪亮。
3. 发射峰值、脉冲间暗段和最终消退属于正常节奏，不得误判为闪烁、黑帧或卡死。
4. 多次脉冲需要能够区分发射阶段，但不强求每一圈在单帧中同时可见。
5. 用户没有要求循环时，完成后回到底图是正常结果。

## 自检视图字段

- `file_name`：最终视频名称。
- `original_request`：中心、范围、次数、速度和强弱要求的唯一来源。
- `summary.description`：实际中心、颜色、峰值亮度和最大覆盖概况。
- `metadata.media`：最终视频规格与可解码状态。
- `metadata.quality`：环带连续性、异常黑帧和脉冲误判保护。
- `metadata.keyframe_evidence`：出现、峰值、传播、间隔和消退阶段。

## 关键帧规则

- 从最终成片中选择脉冲出现、一个或多个实际峰值、最远传播阶段、脉冲间暗段和最终消退。
- 发射次数较多时可增加峰值帧，但只保留彼此有区分度的阶段。
- 单次脉冲也至少覆盖出现、传播峰值和消退。
- 帧数不固定，按时间合成为一张图。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 从人物手掌、太阳或画面角落发出 | “脉冲中心”和出现帧 |
| 向外扩散 | “传播方向”和不同半径阶段 |
| 小范围或冲出画面 | “覆盖范围”和最远传播帧 |
| 锐利或宽厚环带 | 峰值帧中的环带边缘与厚度 |
| 发射一次或多次 | “脉冲阶段”和分离峰值帧 |
| 指定持续时间 | `metadata.media` 与完整消退阶段 |
| 不闪烁 | `metadata.quality`；正常峰值和暗段除外 |

## 判定流程

1. 提取用户对中心、传播、范围、次数、强弱和持续时间的明确要求。
2. 检查出现帧是否从正确区域开始，后续环带是否向外推进。
3. 检查峰值与暗段是否构成合理脉冲节奏，多次发射是否可区分。
4. 检查最终消退是否自然，底图是否恢复且没有异常黑帧。
5. 不把正常脉冲明暗变化作为故障证据。

## 通过与返修

返修时使用“把脉冲中心移到手掌”“扩大传播范围”“让环带更宽厚”“分开发射峰值”“让最后一圈自然消退”等语言。

## 禁止事项

- 不把算法、公式、后端、资源身份、路径或中间数据混入参数摘要。
- 不输出路径、资源标识、网址或身份信息。
- 不把脉冲暗段判为黑帧，不把峰值与消退判为闪烁。
- 不要求所有脉冲圈在同一帧同时出现。
