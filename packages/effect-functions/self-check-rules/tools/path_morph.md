# path_morph 自检规则

## 输入契约

只接收四字段自检 JSON 和从最终 MP4 生成的单张 `keyframe_contact_sheet`。不得读取两张素材的路径、身份、函数入参、变形轨迹或中间点。

## 核心原则

验收源画面、最大变形、目标显现和结束稳定四类可见阶段。输入声明不能证明 A 已转到 B；短暂模糊也不能代替方向明确的变形过渡。

## 自检视图字段

`summary.key_information` 应包含起止关系、变形峰值、推进方向、过渡连续性和结束稳定性；`metadata` 记录媒体、质量和关键帧证据。

## 关键帧规则

动态选择源画面、变形进入、最大变形、目标显现、目标稳定等实际存在的阶段；未出现的阶段不得用重复帧补齐。只标注帧序、角色和时间。

## 用户要求到证据的映射

| 要求 | 证据 |
| --- | --- |
| 从 A 转到 B | “起止关系”与首末关键帧 |
| 左右、上下、中心向外 | “推进方向”与中间阶段空间变化 |
| 拉伸、液态、轻微或强烈 | “变形峰值”与代表帧 |
| 完整结束并清晰 | “结束稳定性”与末段关键帧 |

## 判定流程

确认首末是否实际不同；定位最大变化阶段；核对推进方向和形变观感；检查目标是否显现并稳定；最后排除跳切、长时间卡住和末帧残影。

## 通过与返修

起止明确、中间变形符合要求且目标稳定时通过。返修使用“让目标更早显现”“改为从右向左推进”“清除结束残影”。

## 禁止事项

- 不输出素材身份、方向枚举、时长数值、轨迹或内部点数组。
- 不把源图与目标图内容相似直接判转场失败。
- 不把最大变形阶段的合理模糊判为失焦缺陷。
- 不用首末两帧跳变冒充连续路径变形。
