# marker_stroke 自检规则

## 输入契约

验收只接收一份自检 JSON 和一张 `keyframe_contact_sheet`。JSON 顶层仅有 `file_name`、`original_request`、`summary`、`metadata`。合成图中的所有画面必须来自最终 MP4，并按时间从左到右排列。

## 核心原则

- 先从 `original_request` 提取用户明确要求的涂抹对象、范围、颜色、覆盖感和笔触风格。
- 只使用成片事实判断，不以执行成功或任何输入设置证明视觉正确。
- 马克笔应表现为有宽度、可叠色的连续笔触；普通细线、整图染色或主体自身运动不能替代马克笔证据。
- 用户未指定的审美偏好不构成失败理由。

## 自检视图字段及含义

- `summary.description`：最终画面中实际可见的马克笔表现。
- `summary.key_information`：包括“特效类型”“可见程度”“描边覆盖”“笔触质感”“落笔过程”。
- `metadata.effect.描边覆盖`：笔迹在成片中的局部、适中或大范围覆盖事实。
- `metadata.effect.笔触质感`：平整、自然手绘起伏或粗粝等可见质感。
- `metadata.effect.落笔状态`：逐步展开或保持稳定。
- `metadata.effect.边缘完整性`：主笔迹是否连贯、是否存在离散碎点。
- `metadata.media`、`metadata.quality`：最终视频可用性与基础画质。
- `metadata.keyframe_evidence`：关键帧数量、时间、角色和合成图标识。

## 关键帧检查规则

- 抽帧数量不固定。渐进落笔至少覆盖效果起始、一次或多次覆盖增长、最大覆盖和结束保持；静态结果覆盖前中后稳定性。
- 检查笔迹是否在目标可见区域内逐步出现，是否有不合理回退、突然整片闪现或越过目标的大面积污染。
- 最大覆盖帧用于检查宽度感、透明叠色、边缘起伏和碎点；结束帧检查成品是否保持。
- 不能用源图、遮罩或中间渲染图替代最终 MP4 关键帧。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 涂抹指定对象或部位 | “描边覆盖”与最大覆盖关键帧 |
| 宽、窄、覆盖明显或轻淡 | “可见程度”“描边覆盖”与关键帧 |
| 平整、手绘、粗糙或渗色感 | “笔触质感”“边缘完整性”与近看可辨的关键帧 |
| 从一处涂到另一处 | “落笔过程”与按时间排列的增长帧 |
| 指定颜色 | 最大覆盖帧中的实际笔迹颜色 |
| 无黑帧、闪帧、污染 | `metadata.quality` 与异常时刻关键帧 |

## 判定流程

1. 列出用户明确要求，不自行添加风格标准。
2. 确认视频可解码且关键帧均来自最终 MP4。
3. 用自检事实确认覆盖、质感和落笔状态。
4. 用合成图核对目标位置、推进顺序和可见笔触。
5. 只有事实与画面共同支持时通过；冲突时以最终画面为准。

## 通过与返修原则

通过要求马克笔笔迹可辨认、覆盖用户目标、落笔过程合理且无影响交付的画面损坏。返修意见使用“扩大目标覆盖”“让笔触更连贯”“减少目标外涂抹”等用户语言，并指出对应关键帧。

## 误判保护

- 局部主体运动不等于落笔推进。
- 压缩噪点不等于纸面颗粒或渗色。
- 用户要求轻淡时，不因笔迹不浓重而失败。
- 整幅画面同步变色不能证明马克笔覆盖正确。

## 禁止事项

- 不输出或核对函数入参、几何数组、遮罩、内部指标、资源信息或实现细节。
- 不使用输入设置循环证明输出正确。
- 不把编码完成当成视觉验收通过。
- 不向用户展示内部规则编号或审查过程。
