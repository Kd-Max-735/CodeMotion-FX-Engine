# liquid_displace 自检规则

## 输入契约

输入仅为四字段自检 JSON 和最终 MP4 的单张 `keyframe_contact_sheet`，不读取流场、素材身份、函数参数或中间纹理。

## 核心原则

液态置换应以成片中的有机流动、折射变形、圆润连续性和彩色边缘为证据。规则波浪、随机抖动或纯模糊不能冒充液态流动。

## 自检视图字段

`summary.key_information` 应包含液态流动、折射表现、彩色边缘和流动连续性；媒体、基础质量和关键帧证据分别位于 `metadata.media`、`metadata.quality`、`metadata.keyframe_evidence`。

## 关键帧规则

覆盖流动起始、折射代表状态、主要形变变化和结束；缓慢凝胶可少取，活跃液面应增加不同流态。所有帧必须来自最终 MP4，只标注帧序、角色和时间。

## 用户要求到证据的映射

| 要求 | 证据 |
| --- | --- |
| 黏稠、缓慢、活跃 | “液态流动”与跨时刻形变速度 |
| 折射强弱 | “折射表现”与主体轮廓弯曲 |
| 棱彩或无彩边 | “彩色边缘”与高反差轮廓 |
| 圆润连续 | “流动连续性”与关键帧过渡 |

## 判定流程

从原始要求提取流态、折射和彩边目标；核对多时刻实际变化；排除随机闪烁、整帧平移和纯模糊；最后检查边缘污染和画面完整性。

## 通过与返修

流态符合要求、折射可辨且运动连续时通过。返修使用“让流动更黏稠”“增强折射”“减弱彩色边缘”等效果语言。

## 禁止事项

- 不输出黏度、速度、折射数值、流场或内部算法。
- 不把正常焦散亮度变化判为闪白。
- 不把棱彩边缘误判为编码色散。
- 不因缓慢液体帧差较小而直接判冻结。
