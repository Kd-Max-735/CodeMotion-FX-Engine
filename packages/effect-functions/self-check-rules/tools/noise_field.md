# noise_field 自检规则

## 输入契约

输入为程序生成的 `file_name`、`original_request`、`summary`、`metadata` 自检 JSON，以及从最终编码视频抽取的一张 `keyframe_contact_sheet`。JSON 描述最终纹理的可观察尺度、层次和时间变化。

## 核心原则

- 验收噪声纹理的连续性、空间尺度、明暗层次和时间演变。
- 随机纹理无需逐像素一致，也不应出现明显规则重复块。
- 静止噪声可以没有运动；动态噪声应连续演变而非整帧跳换。
- 自然细密纹理和编码颗粒不能机械判为破图。

## 自检视图字段

- `file_name`：最终视频文件名。
- `original_request`：用户原始需求。
- `summary.description`：实际噪声场描述。
- `summary.key_information`：纹理尺度、明暗层次、空间分布、时间变化和稳定性。
- `summary.missing_information`：不可可靠判断项。
- `metadata.media`：格式、尺寸、帧率、时长、帧数和可解码状态。
- `metadata.quality`：黑帧、跨帧变化与亮度跳变。
- `metadata.keyframe_evidence`：起始纹理、明显演变、层次最分明、细节代表和后段纹理。

## 关键帧规则

先比较完整过程中的纹理变化，再选择起始、实际变化最明显的若干时刻、层次最分明、细节代表和后段。静止纹理只保留稳定性所需帧，不虚构运动峰值。全部帧合为一张时间有序图片。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 柔雾、大块或细密纹理 | “纹理尺度”及细节代表帧 |
| 低对比或强烈层次 | “明暗层次”及层次最分明帧 |
| 静止或流动变化 | “时间变化”、起始、演变和后段帧 |
| 平铺连续、不重复 | “空间分布”与全组合成图 |
| 稳定、无跳帧 | “稳定性”、`metadata.quality` 与相邻关键帧 |
| 黑帧、闪白、色块破损 | 质量字段和合成图 |

## 判定流程

1. 提取用户对纹理尺度、对比、动静和颜色气质的要求。
2. 确认画面形成连续噪声层次，不出现明显规则棋盘或重复接缝。
3. 动态效果检查连续演变，静态效果检查跨时刻稳定。
4. 仅在尺度或层次明确冲突、整帧跳换、接缝明显或画面不可用时返修。

## 通过与返修

通过要求纹理连续、尺度和层次符合需求、动静状态正确且没有明显破图。返修使用“放大纹理块”“增加层次”“减慢演变”“保持静止”等视觉语言。

## 禁止事项

- 不输出随机来源、纹理数值网格、生成方法、计算过程或运行实现。
- 不要求逐像素复现，不把正常细颗粒和轻微编码噪声判为失败。
- 不把静止需求误判为卡死，也不把动态纹理的自然形变判为闪烁。
- 不输出服务器路径、资源或授权信息。
