# 轨道遮罩自检规则

## 输入契约

输入包括用户原始要求、自检 JSON 和最终成片关键帧合成图。JSON 顶层仅接受 `file_name`、`original_request`、`summary`、`metadata`。

## 核心原则

必须从最终画面确认哪些区域被保留、隐藏或处于过渡边界。遮罩输入存在本身不能证明最终合成正确。

## 自检视图字段及含义

- `retained_picture_ratio`：最终保留画面的观察占比。
- `hidden_picture_ratio`：最终隐藏画面的观察占比。
- `transition_picture_ratio`：半透明或边缘过渡区域占比。
- `boundary_appearance`：遮罩边界平稳或复杂的实际表现。
- `retained_area_appearance`：保留区域与隐藏区域的主次关系。
- `keyframe_contact_sheet`：来自最终成片、按时间合并的关键帧视觉证据。

## 关键帧检查规则

检查遮罩覆盖最明显、边界变化和首尾时刻，观察保留区是否正确、隐藏区是否漏出、边界是否跳动破碎。按遮罩形态变化动态选帧。

## 用户要求到证据的映射

保留或反相要求映射保留/隐藏主次；软边或硬边映射过渡区与边界表现；跟随要求映射跨帧边界连续性；主体露出要求映射保留区域。

## 判定流程

先确认保留与隐藏关系，再核对边界及过渡，随后跨帧检查跟随稳定性、漏边和闪动，最后比对用户描述。

## 通过与返修原则

保留/隐藏关系正确、边界连续且跨帧稳定时通过。遮罩反向、范围错误、漏边、破洞、边界明显抖动或完全未生效时返修。

## 禁止事项

不得因存在遮罩输入而直接通过，不得把原素材透明区当作最终遮罩证据，不得披露内部计算、路径、资源或抽帧安排。
