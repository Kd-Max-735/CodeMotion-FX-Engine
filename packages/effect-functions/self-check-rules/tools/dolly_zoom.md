# dolly_zoom 自检规则

## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `direction` | 推拉方向 |
| `travelDistance` | 移动距离 |
| `initialTargetDistance` | 初始主体距离 |
| `initialFovDegrees` | 初始视场角 |
| `duration` | 镜头时长 |
| `easing` | 缓动方式 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

输入为一份顶层仅含 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及全部从最终 MP4 抽取的 `keyframe_contact_sheet`。

## 核心原则

- 推拉变焦的关键事实是中央主体投影大小基本稳定，同时外围背景产生明显不同的展开或收拢。
- 普通数字放大、普通推镜、全画面同幅缩放或裁切不能冒充推拉变焦。
- 检查镜头空间变化、中央主体稳定、方向、起终关系和画面连续性。
- 用户要求往返时必须看到空间变化达到峰值后折返；单向要求不强制折返。

## 自检视图字段及含义

- `summary.description`：实际背景空间变化与中央主体稳定性。
- `metadata.effect.镜头空间变化`：背景向外展开、向中心收拢或无法确认。
- `metadata.effect.效果强度`：轻微、中等或明显。
- `metadata.effect.中央主体`：投影大小基本稳定或大小变化明显。
- `metadata.effect.起终关系`：单向推进或中途折返。
- `metadata.effect.误判保护`：中央与外围同幅缩放未作为推拉变焦证据。

## 关键帧检查规则

- 单向镜头选择起始、外围空间变化明显的中间帧、峰值和结束；往返镜头增加折返点与返回状态，数量不固定。
- 对比中央主体轮廓在起始、峰值和结束帧中的大小与完整性，同时观察外围背景的相对距离和透视变化。
- 背景向外展开与向中心收拢必须由连续帧顺序判断，不能只凭结束帧猜方向。
- 检查中央保护区域到外围是否平滑过渡，不得出现硬边、主体部件复制、折叠、撕裂或跳切。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 前推、背景拉开 | “镜头空间变化”和起始至峰值帧 |
| 后拉、背景压缩 | 背景向中心收拢的连续关键帧 |
| 主体保持大小 | “中央主体”和起始/峰值/结束对比 |
| 轻微、明显或强烈 | “效果强度”和外围变化幅度 |
| 先推后拉或先拉后推 | “起终关系”、峰值和折返关键帧 |
| 平滑、无重影或撕裂 | “画面连续性”和主体边缘/外围关键帧 |

## 判定流程

1. 提取方向、强度、单向或往返、主体稳定和连续性要求。
2. 确认中央主体与外围背景存在差异化空间变化。
3. 用时间顺序判断展开、收拢和折返关系。
4. 检查主体大小、完整性和过渡连续性。
5. 排除普通缩放或裁切后给出结论。

## 通过与返修原则

中央主体大小基本稳定、背景按要求展开或收拢、起终关系正确且无明显复制撕裂时通过。返修使用“让中央主体更稳定”“增强外围空间拉伸”“修正镜头方向”“消除主体重影”等语言。

## 误判保护

- 中央和外围同幅放大或缩小只是普通缩放。
- 仅有裁切范围变化不能证明空间压缩或扩张。
- 主体自身运动不能当成投影补偿。
- 往返镜头回到接近起始状态是正常结果，不应误判为效果消失。

## 禁止事项

- 不输出镜头位置、视角、距离、内部设置、几何关系、资源或实现信息。
- 不以输入方向证明成片方向。
- 不从单帧判定推拉变焦。
- 不要求展示目标数据或中间相机状态。
