# depth_of_field 自检规则

## 输入契约

验收只接收自检 JSON 和一张 `keyframe_contact_sheet`。JSON 顶层严格为 `file_name`、`original_request`、`summary`、`metadata`；关键帧均来自最终 MP4。

## 核心原则

- 景深验收关注实际清晰焦点、焦内外层次、焦点稳定或转移以及深度边缘质量。
- 不读取深度资源，不以焦点声明证明画面已对焦。
- 低纹理区域天然缺少细节，不能仅因其不锐利就判为失焦。
- 全画面均匀模糊、压缩噪声或运动模糊不能冒充有焦内外层次的景深。

## 自检视图字段及含义

- `summary.description`：最终画面实际清晰区域与景深层次。
- `summary.key_information`：包括“特效类型”“可见程度”“清晰焦点”“焦内外层次”“焦点稳定性”“边缘表现”。
- `metadata.effect.清晰焦点`：清晰细节主要所在的用户可理解画面区域。
- `metadata.effect.焦内外层次`：差异较弱、层次清楚或反差强。
- `metadata.effect.焦点稳定性`：稳定或发生转移。
- `metadata.effect.误判保护`：低纹理区域未直接作为失焦证据。
- `metadata.quality` 与 `metadata.keyframe_evidence`：视频质量和焦点起始、变化、结束证据。

## 关键帧检查规则

- 静态景深选择焦点最能辨认的代表帧及前中后稳定帧；发生追焦时加入每次真正改变清晰主体或深度层的关键时刻，数量不固定。
- 检查焦内区域是否保留可用细节，焦外区域是否自然柔化，而非整幅画面同样模糊。
- 在焦内外交界处检查光晕、串色、硬切模糊边界和主体轮廓被侵蚀。
- 若画面缺少纹理或前后景不可区分，应保留“无法可靠确认”，不能猜焦点。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 对焦近处、中景、远处或指定主体 | “清晰焦点”和关键帧中实际细节 |
| 浅景深、背景稍虚或强烈虚化 | “焦内外层次”与同帧清晰/模糊区域对照 |
| 保住发丝或复杂轮廓 | “边缘表现”和主体边缘关键帧 |
| 焦点稳定 | 前中后焦点区域一致 |
| 从一处追焦到另一处 | 起始、转移中间和结束关键帧 |
| 散景高光自然 | 焦外亮点关键帧，不以普通过曝代替 |

## 判定流程

1. 提取对焦对象、景深强弱、追焦和边缘要求。
2. 确认画面有足够纹理支持清晰度判断。
3. 核对实际清晰焦点和焦内外差异。
4. 检查焦点跨帧稳定或转移关系。
5. 检查边缘光晕、硬切和全画面误模糊。

## 通过与返修原则

实际焦点符合用户要求、焦内外层次自然、焦点关系正确且边缘无明显破坏时通过。返修使用“把清晰焦点移到人物”“减弱背景虚化”“保留主体边缘细节”等语言。

## 误判保护

- 天空、墙面等低纹理区域不应自动判为焦外。
- 运动拖影和全局柔焦不等于景深。
- 焦外高光增强不等于过曝故障，除非细节不可用。
- 用户要求全景较清晰时，焦内外差异弱不必失败。

## 禁止事项

- 不输出深度信息、焦点数值、模糊计算、内部设置、资源或实现细节。
- 不以输入焦点证明成片对焦正确。
- 不从单一低纹理区域推断景深。
- 不要求读取或展示深度图。
