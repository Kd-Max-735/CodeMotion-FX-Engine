# slide 自检规则

## 输入契约和核心原则

验收输入只有顶层为 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及最终 MP4 生成的 `keyframe_contact_sheet`。

检查画面从何方向进入、起始偏移、移动幅度、划入速度、超调回弹和最终落位。方向必须从最终画面的时序位置变化判断，不能由文字声明或预期位移推断。

## 自检视图字段

- `file_name`：最终视频文件名。
- `original_request`：用户原话。
- `summary.description`：用进入方向、位移幅度、节奏、超调和落位描述结果。
- `summary.key_information`：实际划入方向、位移幅度、超调回弹和节奏。
- `summary.missing_information`：无法可靠观察的事实。
- `metadata.media`：最终视频媒体事实。
- `metadata.quality`：黑帧、冻结、闪变、突切与尺寸一致性。
- `metadata.keyframe_evidence`：起始位置、划入中段、位移极值、回弹和稳定落位证据。

## 关键帧合成图

按时间检查划入起点、中段、接近落点、超调极值、回弹和结束画面。关键帧数量随实际是否有超调而变化。起始阶段允许主体部分位于画外，这是划入语义的一部分；稳定后仍被大量裁切则属于问题。

用主体中心、轮廓和背景参照判断左右上下方向。超调必须发生在接近最终落点之后，并随后反向回到稳定位置，不能把起点最远位置误写为超调。

## 用户要求与证据

| 用户要求 | 首选证据 |
| --- | --- |
| 从左、右、上、下进入 | 起始位置、中段和结束位置 |
| 自定义斜向进入 | 横纵位置同时变化的连续关键帧 |
| 位移明显或轻微 | 起始与稳定落位的实际距离 |
| 快速或慢速 | 中间阶段时间与“划入节奏” |
| 带超调和回弹 | 接近落点、越过落点、反向回到落点 |
| 不要回弹 | 位置应单向接近并直接稳定 |
| 最终完整可见 | 稳定落位与结束画面边缘 |

## 判定流程

1. 提取方向、位移、快慢、超调回弹和落位要求。
2. 确认最终视频和位置阶段证据可用。
3. 判断实际进入方向与起终位置。
4. 核对位移幅度、节奏、超调和回弹。
5. 检查稳定后裁切、突跳、闪变、冻结和错误漂移。
6. 明确匹配时通过，明确冲突时返修。

## 通过与返修原则

返修使用“改从右侧进入”“增大起始偏移”“放慢划入”“减少超调”“增加一次轻微回弹”“让最终位置完整可见并停稳”等视觉语言。

## 禁止事项

- 不输出函数参数、位移公式、采样计划、算法、后端或资源信息。
- 不以预期方向或调用成功证明实际方向正确。
- 不把起点画外裁切误判为交付缺陷，也不忽略稳定后的持续裁切。
- 不把随机晃动或循环漂浮当成方向划入。
- 不输出路径、URL 或身份信息。
