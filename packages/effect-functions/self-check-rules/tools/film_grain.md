# 胶片颗粒自检规则

## 输入契约

输入包括用户原始要求、自检 JSON 和最终成片关键帧合成图。JSON 顶层仅接受 `file_name`、`original_request`、`summary`、`metadata`。

## 核心原则

胶片颗粒是目标视觉效果，不得把正常颗粒直接判为噪声故障。必须从最终成片确认颗粒的可见度、尺度、颜色和时间变化。

## 自检视图字段及含义

- `grain_visibility`：实际颗粒可见程度。
- `grain_scale`、`grain_color`：颗粒粗细与黑白或彩色表现。
- `grain_motion`：颗粒在时间上的固定、缓变或活跃变化。
- `picture_detail_retention`：颗粒之下原画细节的可辨程度。
- `keyframe_contact_sheet`：来自最终成片、按时间合并的关键帧视觉证据。

## 关键帧检查规则

至少比较不同时刻的平坦区域、暗部和主体细节，辨别颗粒是否自然变化、是否冻结成贴图或出现块状压缩。动态选取能体现时间变化的帧。

## 用户要求到证据的映射

“细腻/粗粝”映射颗粒尺度；“黑白/彩色”映射颗粒颜色；“活跃/稳定”映射时间变化；“保留细节”映射主体细节保持。

## 判定流程

先确认颗粒真实可见，再核对尺度与颜色，随后跨帧检查颗粒运动和均匀性，最后区分目标颗粒与块状、条带、破帧等异常。

## 通过与返修原则

颗粒表现符合要求、时间行为自然且主体仍可辨时通过。颗粒缺失、冻结、成片闪烁、严重压盖主体或出现非目标块状损伤时返修。

## 禁止事项

不得把正常颗粒当作故障噪声，不得仅凭设置证明效果存在，不得输出内部计算、路径、资源或抽帧安排。
