# 动感排版自检规则

## 输入契约

输入为四字段自检 JSON 和最终 MP4 的 `keyframe_contact_sheet`。只审查实际可见文字、排版变化、节奏、完整性和质量。

## 核心原则

必须描述成片中实际文字内容、布局运动、尺寸节奏、可读性和起终状态。内部节奏表或排版设定不能证明最终文字真的动了。

## 自检视图字段

- `visible_content`：实际可见文字。
- `layout_motion`：布局运动是否真实可见。
- `scale_rhythm`：可辨的尺寸或排版节奏状态。
- `readability`：运动过程中是否保持可读。
- `start_state`、`end_state`：起始与最终状态。

## 关键帧规则

按实际排版峰值、缩放峰值、布局转换和归位状态选帧。节奏峰值数量决定关键帧数量；不得固定抽取相同比例后忽略真实变化。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 指定文字 | `visible_content` 与清晰关键帧 |
| 网格、扩散或层叠运动 | `layout_motion` 与布局关键态 |
| 多次跳动或呼吸 | `scale_rhythm` 与多个峰值态 |
| 保持可读 | `readability` 与运动中间态 |
| 最后归位 | `end_state` 与末段画面 |

## 判定流程

先核对文字内容，再观察布局或尺寸是否随时间形成清晰节奏，随后检查可读性和末态。只有静态文字时不能通过动感要求。

## 通过与返修

通过要求内容正确、节奏变化可见、布局符合意图且关键阶段可读。返修说明运动缺失、节奏不符、排版混乱、文字裁切或未归位。

## 禁止事项

- 不输出节奏数组、缩放数组、时间计划、字形数组或公式。
- 不用内部排版记录替代最终画面证据。
- 不暴露资源、路径、后端或实现信息。
