# chalk_stroke 自检规则

<!-- self-check-parameter-contract:start -->
## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `grain` | 粉笔颗粒 |
| `scatter` | 散粉程度 |
| `opacity` | 描边不透明度 |
| `progress` | 描边进度 |
| `color` | 描边颜色 |
| `strokeWidth` | 描边宽度 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。
<!-- self-check-parameter-contract:end -->

## 输入契约

只接收顶层为 `file_name`、`original_request`、`summary`、`metadata` 的自检 JSON，以及从最终 MP4 抽帧合成的一张 `keyframe_contact_sheet`。不得假设存在其他图像或运行上下文。

## 核心原则

- 验收粉笔描边的实际覆盖、颗粒、散粉、主笔迹连续性和描边阶段。
- 粉笔质感必须来自可见的明暗断续和粉尘边缘，不能用普通光滑描边冒充。
- 用户要求细腻粉笔时允许颗粒弱；用户要求粗粝时才要求明显断续和散粉。
- 最终 MP4 事实优先于任何声明或设置。

## 自检视图字段及含义

- `summary.description`：粉笔笔迹在最终画面中的总体描述。
- `metadata.effect.描边覆盖`：实际可见粉笔区域。
- `metadata.effect.粉笔颗粒`：细腻、自然颗粒或粗粝断续。
- `metadata.effect.散粉表现`：主笔迹外的离散粉尘程度。
- `metadata.effect.笔迹完整性`：主线是否仍可辨认。
- `metadata.media`、`metadata.quality`、`metadata.keyframe_evidence`：视频状态、基础质量和关键帧覆盖。

## 关键帧检查规则

- 抽帧数量随描边阶段变化。需要覆盖描边起始、实际增长、纹理最清楚的最大覆盖和结束状态；若成片静止，则使用前中后稳定帧。
- 在最大覆盖帧检查主笔迹是否清楚、颗粒是否附着于描边、散粉是否自然且未污染整幅画面。
- 跨帧检查描边覆盖是否连续增长或稳定保持，不得突然更换目标轮廓。
- 所有关键帧只能来自最终 MP4，合成图不得混入遮罩、源图或纹理素材。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 沿对象轮廓描边 | “描边覆盖”“笔迹完整性”和最大覆盖帧 |
| 在对象内部铺粉笔 | 覆盖位置和目标内部关键帧 |
| 细腻、自然、粗粝 | “粉笔颗粒”和纹理最清楚帧 |
| 散粉少或粉尘明显 | “散粉表现”和笔迹边缘关键帧 |
| 描到某一阶段或完整描边 | “描边阶段”、起始与结束关键帧 |
| 指定颜色与粗细 | 成片关键帧中的实际颜色和可见线宽 |

## 判定流程

1. 从用户需求提取对象、放置位置、颗粒、散粉、颜色和完成程度。
2. 检查媒体与关键帧证据完整性。
3. 对照自检事实检查粉笔覆盖、颗粒与连续性。
4. 用合成图排除普通光滑描边、整图噪声和目标外污染。
5. 汇总通过或返修结论。

## 通过与返修原则

粉笔主笔迹可辨、覆盖符合需求、颗粒与散粉符合用户用语且画面无明显损坏时通过。返修要指出可见问题，例如“减少散粉”“增强断续颗粒”“让主描边更连续”。

## 误判保护

- 画面本身的纹理或视频噪声不能作为粉笔颗粒证据。
- 少量自然断点不等于笔迹断裂。
- 细腻粉笔不要求大量散粉。
- 主体运动或镜头噪声不能证明描边进度。

## 禁止事项

- 不把算法、公式、后端、资源身份、路径或中间数据混入参数摘要。
- 不以输入设置证明成片符合要求。
- 不要求关键帧重复 JSON 中的内部数值。
- 不将主观“更好看”作为失败条件。
