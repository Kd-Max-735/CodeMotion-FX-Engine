# volumetric_ray 自检规则

## 输入契约

输入是一份自检 JSON 和一张 `keyframe_contact_sheet`。JSON 顶层仅有 `file_name`、`original_request`、`summary`、`metadata`；合成图来自最终 MP4。不得读取光源坐标声明、遮挡蒙版、采样数据、源图或中间射线。

## 核心原则

1. 验收光束亮度、颜色、主要位置、朝向、覆盖范围、长度感、宽度、分层、内部流动和底图可读性。
2. 体积光需要主束、柔和外沿、衰减和遮挡间隙形成层次，不能退化成均匀泛白。
3. 内部光尘流动和层次变化是正常表现，不得机械判为闪烁。
4. 光束可以很亮，但不能完全替换或遮住底图的主要内容。
5. 不要求物理真实的三维雾体，只按最终二维成片的可见证据验收。

## 自检视图字段

- `file_name`：最终视频名称。
- `original_request`：光源方向、颜色、强弱、范围和流动要求的来源。
- `summary.description`：实际光束位置、亮度、颜色、覆盖和流动概况。
- `summary.key_information`：光束亮度、颜色、主要位置、朝向、覆盖范围、光束层次、内部流动和底图可读性。
- `metadata.media`：最终 MP4 规格和可解码状态。
- `metadata.quality`：射线连续性、异常黑帧、非预期闪变和关键阶段覆盖。
- `metadata.keyframe_evidence`：光束前段、亮暗层次、流动变化和后段证据。

## 关键帧规则

- 静止光束使用前、中、后帧证明层次稳定。
- 有内部流动时选择前段、较暗层次、最亮层次、流动位置变化和后段。
- 关键帧必须使用完整画面，便于同时检查光源方向和底图可读性。
- 数量不固定，按时间合成一张图。

## 用户要求到证据映射

| 用户要求 | 首选证据 |
| --- | --- |
| 从窗外、上方或左上照入 | “主要位置”“光束朝向”和完整帧 |
| 暖金、蓝色或指定颜色 | “光束颜色”和最亮帧 |
| 柔和、强烈、长束或窄束 | “光束亮度”“覆盖范围”“光束层次” |
| 有遮挡缝隙和多层射线 | “光束层次”和代表帧 |
| 内部尘埃流动 | “内部流动”和跨时刻证据 |
| 保留底图 | “底图可读性”和完整画面 |
| 无闪烁 | `metadata.quality`；连续流动除外 |

## 判定流程

1. 提取用户明确的光源方向、颜色、亮度、范围、层次和流动要求。
2. 检查主束方向是否正确，外沿、衰减和遮挡间隙是否可辨认。
3. 检查强光下底图主要内容是否仍可读。
4. 用跨时刻帧区分连续内部流动和无规律整帧闪变。
5. 只在证据明确不符或层次丢失时返修。

## 通过与返修

返修时使用“让光从左上方照入”“缩窄主束”“增加柔和衰减层次”“减弱泛白以保留底图”“让内部流动更连续”等语言。

## 禁止事项

- 不输出光源参数、遮挡数据、亮度门限、采样公式、算法、后端或中间射线。
- 不输出路径、资源标识、网址或身份信息。
- 不把光尘流动误判为闪烁，不把正常强光中心直接判为全局过曝。
- 不要求证据无法证明的三维物理真实性。
