## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `size` | 笔刷尺寸 |
| `roughness` | 笔刷粗糙度 |
| `progress` | 揭示进度 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

检查四字段自检 JSON 和最终视频 `keyframe_contact_sheet`。验收目标来自用户对源画面、目标画面、笔刷质感、显现范围和完成程度的描述。

## 核心原则

目标画面应通过可辨识的笔刷覆盖逐步出现，未覆盖区域应合理保留源画面。粗糙边、鬃毛空隙和不规则覆盖可能是笔刷特征，不得当作遮罩破损。

## 自检视图字段及含义

- `summary.description`：目标显现、笔刷边缘和源目标过渡的结果。
- `summary.missing_information`：缺少源或目标对照时的无法确认项。
- `metadata.media`：最终视频规格。
- `metadata.quality`：基础质量和时间连续性。
- `metadata.keyframe_evidence`：起始、笔刷经过、中段、鬃毛细节、结束和保持帧。

## 关键帧合成图的检查方法

观察笔刷经过位置与目标画面显现区域是否一致，确认覆盖沿时间增长而不是随机闪烁。结束帧检查目标画面完成度，细节帧检查边缘是否具有连续笔刷纹理。

## 用户要求到证据的映射

| 用户要求 | 主要证据 |
| --- | --- |
| 显现指定目标画面 | “目标画面显现”和结束帧 |
| 保留未刷区域的源画面 | “源目标过渡”和中段帧 |
| 干刷、柔边或明显鬃毛 | “笔刷边缘”和细节帧 |
| 覆盖方向与范围 | “显现覆盖”和跨时刻帧 |
| 完整显现或部分显现 | 结束帧和目标画面对照事实 |

## 判定流程

提取目标、覆盖、质感和完成要求；核对源目标过渡；追踪笔刷覆盖；检查结束状态；再检查基础质量。

## 通过与返修原则

笔刷过程可辨、目标显现程度符合要求且边缘没有非预期破洞时通过。返修描述“笔刷经过后仍未出现目标画面”“未刷区域也被替换”“边缘出现规则方块”等现象。

## 禁止事项

- 不输出笔刷资源、覆盖缓冲、内部设置、采样安排或实现信息。
- 不把笔刷本身的随机孔隙误判为编码损坏。
- 不把源画面在中段仍可见视为失败，除非用户要求立即全显现。
