# sim_cloth 自检规则

## 重要参数契约

- `summary.key_information` 必须是对象；每个 key 都必须逐字等于本工具 Registry Schema 中真实存在的参数名。
- 这里只显示对最终视频变化有直接判断价值的重要参数：

| JSON key | 中文名称 |
| --- | --- |
| `resolution` | 布料分辨率 |
| `clothWidth` | 布面宽度 |
| `stiffness` | 布料刚度 |
| `damping` | 运动阻尼 |
| `gravity` | 重力 |
| `windStrength` | 风力 |
| `solverIterations` | 求解迭代次数 |

- 每项结构固定为 `{ "label": "中文名称", "value": 最终生效值 }`。`value` 来自补齐默认值、验证并标准化后真正用于渲染的参数，禁止猜测、改名或新增参数。
- `metadata.effect` 与 `metadata.observed_effect` 记录从最终 MP4 和关键帧得到的成片观察证据；它们不是参数，不得混入 `summary.key_information`。

## 输入契约

输入仅包含一份自检 JSON 和一张 `keyframe_contact_sheet`。JSON 顶层只能有 `file_name`、`original_request`、`summary`、`metadata`；合成图必须完全来自最终 MP4。

## 核心原则

- 布料模拟必须表现为布面局部之间不同步的连续非刚性形变，包括摆动、下垂或褶皱变化。
- 整幅画面平移、缩放、旋转或统一波纹不能证明布料模拟正确。
- 运动强弱、褶皱层次、锚定稳定和形变连续性均以成片事实为准。
- 不要求用户未提出的真实材质物理精度。

## 自检视图字段及含义

- `summary.description`：布面运动、褶皱和连续性的成片概述。
- `metadata.effect.布面运动`：轻微、自然或大幅摆动。
- `metadata.effect.褶皱表现`：平缓、层次可见或明暗强烈。
- `metadata.effect.形变连续性`：连续或存在突跳。
- `metadata.effect.误判保护`：说明整画面刚性运动未作为布料证据。
- `metadata.quality` 和 `metadata.keyframe_evidence`：基础画质与初始、峰值、反向或结束状态。

## 关键帧检查规则

- 抽帧数量由布面状态决定，至少覆盖初始形态、最大形变和结束；有反向风摆、次峰或稳定阶段时加入相应帧。
- 检查同一布面内部是否出现不同方向或不同幅度的连续运动，固定区域是否相对稳定。
- 最大形变帧检查褶皱是否连续、纹理是否随形变而非滑过布面、边缘是否拉裂。
- 结束帧检查是否保持合理布形，不能因模拟发散而消失、爆开或铺满画面。

## 用户要求到证据的映射

| 用户要求 | 证据 |
| --- | --- |
| 轻盈、厚重、柔软或硬挺 | “布面运动”“褶皱表现”和最大形变帧 |
| 微风、强风或无风下垂 | 初始、形变峰值、反向摆动与结束帧 |
| 固定上边、角点或其他部位 | “锚点稳定”和跨时刻对应区域 |
| 细腻或大褶皱 | “褶皱表现”和纹理清楚关键帧 |
| 快速停下或持续摆动 | 峰值后的关键帧序列 |
| 无撕裂、突跳、整图漂移 | “形变连续性”、`metadata.quality` 和关键帧 |

## 判定流程

1. 提取材质感、风摆、重量、固定区域和持续状态要求。
2. 确认成片存在非刚性局部形变。
3. 检查摆动强度、褶皱层次和锚定稳定。
4. 排除整图刚性运动与模拟发散。
5. 根据用户要求给出通过或可见返修意见。

## 通过与返修原则

布面形变连续、褶皱和摆动符合要求、固定区域合理且无拉裂或爆开时通过。返修使用“让上边保持固定”“减弱风摆”“增加自然褶皱”“消除形变突跳”等语言。

## 误判保护

- 整幅画面同步移动不算布料形变。
- 纹理自身明暗变化不自动等于褶皱。
- 厚重布料运动较小是合理表现。
- 轻微边缘编码抖动不等于布面撕裂。

## 禁止事项

- 不输出网格、约束、模拟步长、内部设置、资源或实现信息。
- 不用输入设置证明布料运动正确。
- 不把单帧弯曲形状当成完整模拟证据。
- 不以物理写实偏好覆盖用户风格需求。
